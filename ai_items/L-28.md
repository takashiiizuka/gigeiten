# L-28 スペーシングスケール（Spacing scale / 8pt grid）

- 分野：構成・レイアウト／目的：見た目・印象を整える
- 別名：なし
- 定義：余白や寸法に使う値の系列。8の倍数を基調にするものは8ptグリッドとも呼ばれる。
- 使う場面：余白の一貫性を作る。
- 注意：8という数値は普遍的な規格ではなく、4などの補助値も使われる。
- 用意する情報（分野共通）：読者、閲覧端末、本文量、図版、最も伝えたい結論。余白や区画の大きさを重要度と結びつけます。
- 出典：IBM Carbon — Spacing https://carbondesignsystem.com/elements/spacing/overview/
- 向いている媒体：資料・提案書（主）、スライド・講演（主）、LP・Webサイト（主）、画像・バナー（副）、図解・グラフ（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）
- v1の対応項目：L-03 8ポイントグリッド（対応：近い。8ポイントグリッドはスペーシングスケールの一種）
  - v1の説明：余白・サイズをすべて 8の倍数 （8/16/24/32/40/48/64…）に揃える約束。細かい調整には4ptの下位刻みを使い、文字の行送りは4ptの倍数に合わせます。Material Design、iOS、Bootstrap、IBM Carbon、Ant Design など主要なデザインシステムが採用しています。 8が選ばれる理由は、1×/1.5×/2×/3× といった画面倍率で割り切れて小数ピクセルが出ないため。 「余白がバラバラ」問題は、この一言でほぼ解決します。
  - v1の依頼例：余白は8ptグリッドに揃えて。使う値は 8 / 16 / 24 / 32 / 48 / 64 のみ、中間値は使わないで。
