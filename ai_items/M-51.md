# M-51 フローフィールド（Flow field）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：粒子・生成
- 別名：流れ場、生成アート
- 定義：ノイズなどで決めた流れの向きに沿って、粒子が線を描いていく表現。
- 使う場面：背景の生成アート、流れや風の表現。
- 注意：描画が重い。画面外では止め、静止画でも成り立つようにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Tyler Hobbs — Flow Fields https://www.tylerxhobbs.com/words/flow-fields
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：canvas が画面に入ったとき（停止ボタン、画面外、タブが非表示のときは止める）
- 変える値：粒子300個の位置。各点の向きを「ノイズ値 × 2π」で決め、1ステップ1pxずつ進めながら薄い線を重ねて描く（120ステップで別の位置から出直す）
- 時間の例：1フレーム2ステップ、900ステップ（約7.5秒）で描き終えて自動で止まる
- 動き方の例：なし（一定の速さで進む）
- 動きを減らす設定のとき：動きを見せず、同じ規則で描き終えた静止画を1枚表示する
- 技術：Canvas 2D
- 補足：ノイズの倍率（例：0.01）を小さくすると流れが大きくゆるやかになり、大きくすると細かく乱れる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<canvas class="mo-flowfield" width="480" height="270" aria-hidden="true"></canvas>
<button type="button" class="mo-flowfield-toggle">停止</button>
```

```css
.mo-flowfield { display: block; max-width: 100%; }
```

```js
const cv = document.querySelector('.mo-flowfield'), ctx = cv.getContext('2d'), W = cv.width, H = cv.height;
const btn = document.querySelector('.mo-flowfield-toggle');
const hash = (x, y) => { const s = Math.sin(x * 127.1 + y * 311.7) * 43758.5453; return s - Math.floor(s); };
function noise(x, y) { // 値ノイズ（0〜1）
  const i = Math.floor(x), j = Math.floor(y), fx = x - i, fy = y - j;
  const u = fx * fx * (3 - 2 * fx), v = fy * fy * (3 - 2 * fy);
  const a = hash(i, j), b = hash(i + 1, j), c = hash(i, j + 1), d = hash(i + 1, j + 1);
  return a + (b - a) * u + (c - a) * v + (a - b - c + d) * u * v;
}
const spawn = () => ({ x: Math.random() * W, y: Math.random() * H, age: 0 });
const pts = Array.from({ length: 300 }, spawn), MAX = 900; // MAX：描き終えるまでのステップ数
let steps = 0, running = true, visible = true, raf = 0;
ctx.fillStyle = '#fff'; ctx.fillRect(0, 0, W, H);
ctx.strokeStyle = 'rgba(30, 58, 138, 0.06)';
function step() {
  ctx.beginPath();
  for (const p of pts) {
    const angle = noise(p.x * 0.01, p.y * 0.01) * Math.PI * 2;
    ctx.moveTo(p.x, p.y);
    p.x += Math.cos(angle); p.y += Math.sin(angle);
    ctx.lineTo(p.x, p.y);
    if (++p.age > 120 || p.x < 0 || p.x > W || p.y < 0 || p.y > H) Object.assign(p, spawn());
  }
  ctx.stroke();
  steps++;
}
function loop() { step(); step(); if (steps < MAX) raf = requestAnimationFrame(loop); else btn.hidden = true; }
function sync() {
  cancelAnimationFrame(raf);
  if (running && visible && !document.hidden && steps < MAX) raf = requestAnimationFrame(loop);
}
if (matchMedia('(prefers-reduced-motion: reduce)').matches) {
  while (steps < MAX) step(); // 動きを見せず、描き終えた絵だけを出す
  btn.hidden = true;
} else {
  btn.addEventListener('click', () => { running = !running; btn.textContent = running ? '停止' : '再開'; sync(); });
  document.addEventListener('visibilitychange', sync);
  new IntersectionObserver(([e]) => { visible = e.isIntersecting; sync(); }).observe(cv);
}
```
