# M-17 スクロール駆動（Scroll-driven animation）

- 分野：動き・モーション／目的：手順・流れを説明する
- 動きの分類：スクロール
- 別名：なし
- 定義：スクロール位置などを進行度に対応させる方式。
- 使う場面：読了率や図解の段階的な説明。
- 注意：対応ブラウザと動きを抑えた代替表示を用意する。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — Scroll-driven animations https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Scroll-driven_animations
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：スクロール位置の変化（要素が表示領域を通過する進み具合が、そのまま再生位置になる）
- 変える値：工程を示すバーの transform: scaleX(0) → scaleX(1)
- 時間の例：時間ではなくスクロールの範囲で決まる（例：animation-range: entry 0% cover 50%）
- 動き方の例：スクロール量に比例（linear）
- 動きを減らす設定のとき：スクロールに連動する変化をやめ、完成した図を静的に表示する。未対応のブラウザでも同じ表示にする
- 技術：CSS
- 補足：animation の一括指定は animation-timeline を初期値に戻すため、animation-timeline はその後に書く。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-spacer">下へスクロールしてください</div>
<figure class="mo-fig">
  <div class="mo-bar"></div>
  <figcaption>受付 → 確認 → 発送</figcaption>
</figure>
<div class="mo-spacer"></div>
```

```css
.mo-spacer { height: 100vh; }
.mo-bar { height: 12px; background: #2b6cb0; transform-origin: left; }
@keyframes mo-grow { from { transform: scaleX(0); } }
@supports (animation-timeline: view()) {
  .mo-bar { animation: mo-grow linear both; animation-timeline: view(); animation-range: entry 0% cover 50%; }
}
@media (prefers-reduced-motion: reduce) {
  .mo-bar { animation: none; }
}
```
