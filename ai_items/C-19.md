# C-19 RGB（RGB color model）

- 分野：色・配色／目的：見た目・印象を整える
- 別名：なし
- 定義：赤・緑・青の光の成分を使う色の表し方。
- 使う場面：画面の色を指定する。
- 注意：数値は色空間やプロファイルと合わせて解釈する。
- 用意する情報（分野共通）：ブランド色、背景色、系列や状態の意味。文字と背景、隣接した系列を実際の色の組み合わせで確認します。
- 出典：MDN — CSS colors https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Colors
- 向いている媒体：LP・Webサイト（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）
- v1の対応項目：C-01 色空間（HEX / HSL / OKLCH）（対応：近い。色空間のうち、現行はRGBのみ独立項目）
  - v1の説明：HEX・RGB は機械向けの表記で、人間が調整しにくい。 HSL は色相・彩度・明度で直感的ですが、 明度が知覚的に均等でない （同じL=50%でも黄色は明るく、青は暗く見える）という致命的な弱点があります。 OKLCH は知覚的に均等な新しい色空間で、2023年から主要ブラウザで利用可能。 同じLの値なら、どの色相でも同じ明るさに見える ため、カラースケールの設計が桁違いに楽になります。sRGBを超えるDisplay P3の色も表現できます。
  - v1の依頼例：配色はOKLCHで定義して。明度Lを段階で固定し、色相Hだけ変えて系列色を作って。フォールバックにHEXも併記。
