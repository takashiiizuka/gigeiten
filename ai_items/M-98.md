# M-98 シームレスループ（Seamless loop）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：動きの原理
- 別名：ループアニメーション、無限ループ
- 定義：終わりと始まりを一致させ、継ぎ目なく繰り返す動き。
- 使う場面：背景の動き、ロゴの待機、GIFや短い映像。
- 注意：繰り返しは注意を引き続ける。5秒を超えるなら止める手段を付ける。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：GSAP — seamlessLoop https://gsap.com/docs/v3/HelperFunctions/helpers/seamlessLoop/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示されている間（ロゴの帯、背景）
- 変える値：同じ並びを2つ続けた帯の translateX 0 → -50%（ちょうど1並び分で、最初と最後の見た目が一致する）
- 時間の例：1周 8〜20秒（例は12秒）
- 動き方の例：等速（linear）
- 動きを減らす設定のとき：動かさず、最初のコマで静止する
- 技術：CSS + JavaScript
- 補足：5秒を超えて動き続けるため止めるボタンを付ける。間隔は margin ではなく各項目の padding で持たせると、半分の位置がちょうど1並び分になる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-marquee">
  <div class="mo-marquee-track"><span>ALPHA</span><span>BRAVO</span><span>CHARLIE</span><span>DELTA</span></div>
</div>
<button class="mo-marquee-btn" type="button">動きを止める</button>
```

```css
.mo-marquee{width:360px;overflow:hidden;border:1px solid #e2e8f0}
.mo-marquee-track{display:flex;width:max-content;animation:mo-marquee 12s linear infinite}
.mo-marquee-track span{padding:12px 24px;font-weight:700;color:#334155}
.mo-marquee.is-paused .mo-marquee-track{animation-play-state:paused}
/* 同じ並びを2つ続け、ちょうど1つ分（-50%）動かすと継ぎ目が出ない */
@keyframes mo-marquee{to{transform:translateX(-50%)}}
@media (prefers-reduced-motion:reduce){.mo-marquee-track{animation:none}.mo-marquee-btn{display:none}}
```

```js
const box=document.querySelector('.mo-marquee'),track=box.querySelector('.mo-marquee-track'),btn=document.querySelector('.mo-marquee-btn');
// 複製した側は読み上げが重ならないよう aria-hidden を付ける
[...track.children].forEach(n=>{const c=n.cloneNode(true);c.setAttribute('aria-hidden','true');track.append(c);});
btn.addEventListener('click',()=>{
  const paused=box.classList.toggle('is-paused');
  btn.textContent=paused?'動きを再開する':'動きを止める';
});
```
