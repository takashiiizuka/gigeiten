# M-05 スタガー（Stagger）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：出現・退場
- 別名：順番、遅延、時間差
- 定義：複数の要素を少しずつ時間差で動かすこと。
- 使う場面：項目の順序やまとまりの提示。
- 注意：項目数が増えても待ち時間が過大にならないようにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：GSAP — Staggers https://gsap.com/resources/getting-started/Staggers/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）
- v1の対応項目：M-05 スタッガー（対応：一致。名称で自動照合）
  - v1の依頼例：リストの登場は50msずつのスタッガーで。ただしずらすのは先頭6件までにして、全体で400msを超えないようにして。

## 作り方（例）

- きっかけ：一覧を表示したとき
- 変える値：各項目の opacity 0 → 1、translateY(8px) → 0 を、項目ごとに開始時刻をずらして再生する
- 時間の例：各項目 200〜300ms、間隔 30〜60ms。ずらしの合計は 300〜400ms 程度で頭打ちにする
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：時間差と移動をやめ、全項目を同時に表示する
- 技術：CSS + JavaScript
- 補足：項目数が増えても最後の項目が出るまでの時間が延びすぎないよう、遅延に上限を設ける。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<ul class="mo-list"><li>売上</li><li>在庫</li><li>顧客</li><li>注文</li><li>配送</li></ul>
```

```css
.mo-list li { animation: mo-rise 250ms cubic-bezier(0.2, 0, 0, 1) both;
  animation-delay: calc(var(--i, 0) * 50ms); }
@keyframes mo-rise { from { opacity: 0; transform: translateY(8px); } }
@media (prefers-reduced-motion: reduce) {
  .mo-list li { animation: none; }
}
```

```js
document.querySelectorAll('.mo-list li').forEach((li, i) => {
  li.style.setProperty('--i', Math.min(i, 6)); // 7項目目以降は同じ遅延にして待ち時間を抑える
});
```
