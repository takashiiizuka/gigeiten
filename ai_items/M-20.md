# M-20 データトランジション（Data transition）

- 分野：動き・モーション／目的：時間による変化を見せる
- 動きの分類：データ
- 別名：なし
- 定義：値や配置の変化を、グラフ要素の動きでつなぐ表現。
- 使う場面：期間や条件を変更した結果の理解。
- 注意：軸の変更と値の変更を混同させない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：D3 — Transitions https://d3js.org/d3-transition
- 向いている媒体：LP・Webサイト（主）、スライド・講演（主）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：期間や条件を切り替えたとき
- 変える値：各棒の高さ（transform: scaleY）を前の値から新しい値へ変える。軸の最大値は固定する
- 時間の例：300〜500ms
- 動き方の例：加減速（cubic-bezier(0.65, 0, 0.35, 1)）
- 動きを減らす設定のとき：補間を省き、新しい値の棒をその場で表示する
- 技術：CSS + JavaScript
- 補足：軸の範囲も変わる場合は、先に軸を切り替えてから値を動かすなど、軸の変化と値の変化を別の段階に分ける。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-range" type="button">2025年に切り替える</button>
<div class="mo-chart" role="img" aria-label="">
  <span class="mo-col"></span><span class="mo-col"></span><span class="mo-col"></span><span class="mo-col"></span>
</div>
```

```css
.mo-chart { display: flex; align-items: flex-end; gap: 12px; height: 160px; margin-top: 8px; border-bottom: 1px solid #555; }
.mo-col { width: 40px; height: 100%; background: #2b6cb0; transform-origin: bottom;
  transition: transform 400ms cubic-bezier(0.65, 0, 0.35, 1); }
@media (prefers-reduced-motion: reduce) {
  .mo-col { transition: none; }
}
```

```js
const data = { 2024: [40, 65, 50, 80], 2025: [55, 45, 70, 95] }; // 軸の最大値 100 は両年で共通
const cols = document.querySelectorAll('.mo-col');
const chart = document.querySelector('.mo-chart');
const btn = document.querySelector('.mo-range');
let year = 2024;
function render() {
  data[year].forEach((v, i) => { cols[i].style.transform = `scaleY(${v / 100})`; });
  chart.setAttribute('aria-label', `${year}年 四半期ごとの売上：${data[year].join('、')}`);
  btn.textContent = `${year === 2024 ? 2025 : 2024}年に切り替える`;
}
btn.addEventListener('click', () => { year = year === 2024 ? 2025 : 2024; render(); });
render();
```
