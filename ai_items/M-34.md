# M-34 文字ごとの時間差（Per-character stagger）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：文字
- 別名：スプリットテキスト、SplitText
- 定義：文字を1字ずつに分け、同じ動きを少しずつ時間をずらして当てる表現。
- 使う場面：タイトル、キャッチコピーの登場。
- 注意：分割した文字が読み上げで1字ずつ読まれないよう、元の文を残す。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：GSAP — SplitText https://gsap.com/docs/v3/Plugins/SplitText/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：要素が画面に入ったとき（IntersectionObserver で1回だけ）
- 変える値：各文字の translateY 0.6em → 0 と opacity 0 → 1
- 時間の例：1文字あたり400ms、文字ごとの時間差30ms（10文字で約0.7秒）
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：文字を分けずに全体をその場で表示する
- 技術：CSS + JavaScript
- 補足：時間差の合計は文字数に比例して長くなるため、長い文では時間差を小さくするか語ごとに分ける。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<h1 class="mo-stagger">時間差で現れる見出し</h1>
```

```css
.mo-stagger span {
  display: inline-block;
  white-space: pre;
  opacity: 0;
  transform: translateY(0.6em);
  transition: opacity 400ms, transform 400ms cubic-bezier(0.2, 0, 0, 1);
  transition-delay: calc(var(--i) * 30ms);
}
.mo-stagger.mo-in span { opacity: 1; transform: none; }
```

```js
const el = document.querySelector('.mo-stagger');
if (!matchMedia('(prefers-reduced-motion: reduce)').matches) {
  const text = el.textContent;
  el.setAttribute('aria-label', text); // 読み上げには元の文を渡す
  el.textContent = '';
  [...text].forEach((ch, i) => {
    const s = document.createElement('span');
    s.textContent = ch;
    s.setAttribute('aria-hidden', 'true');
    s.style.setProperty('--i', i);
    el.append(s);
  });
  new IntersectionObserver(([e], io) => {
    if (e.isIntersecting) { el.classList.add('mo-in'); io.disconnect(); }
  }).observe(el);
}
```
