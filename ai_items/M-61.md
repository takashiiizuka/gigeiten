# M-61 ズームトランジション（Zoom transition）

- 分野：動き・モーション／目的：手順・流れを説明する
- 動きの分類：画面の転換
- 別名：クロスズーム、ズームイン転換
- 定義：前の場面に飛び込むように拡大し、次の場面へ抜ける転換。
- 使う場面：階層を深く入る移動、場面の転換。
- 注意：拡大は酔いやすい。動きを減らす設定では切り替えにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Adobe — Applying transitions to clips (Premiere Elements) https://helpx.adobe.com/premiere-elements/desktop/applying-transitions/applying-transitions-clips.html
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：項目を開いて深く入るとき（戻るときは逆向き）
- 変える値：前の場面の scale 1 → 3 と opacity 1 → 0、次の場面の scale 0.6 → 1 と opacity 0 → 1（戻るときは拡大率を入れ替える）
- 時間の例：前の場面450ms、次の場面450ms（200ms遅れて開始）、全体650ms
- 動き方の例：前の場面は加速（cubic-bezier(0.4, 0, 1, 1)）、次の場面は減速（cubic-bezier(0, 0, 0.2, 1)）
- 動きを減らす設定のとき：拡大を省き、即時に切り替える
- 技術：JavaScript（Web Animations API）
- 補足：入るときは拡大、戻るときは縮小にそろえると、階層の上下が伝わる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-zoom">
  <section class="mo-zoom-scene">一覧</section>
  <section class="mo-zoom-scene" hidden>詳細</section>
</div>
<button type="button" class="mo-zoom-go">切り替える</button>
```

```css
.mo-zoom { position: relative; width: 360px; height: 200px; overflow: hidden; }
.mo-zoom-scene { position: absolute; inset: 0; display: grid; place-items: center; font: 700 28px sans-serif; background: #e2e8f0; }
.mo-zoom-scene + .mo-zoom-scene { background: #1e3a8a; color: #fff; }
.mo-zoom-scene[hidden] { display: none; }
```

```js
const [a, b] = document.querySelectorAll('.mo-zoom-scene');
let inB = false, busy = false;
document.querySelector('.mo-zoom-go').addEventListener('click', () => {
  if (busy) return;
  const from = inB ? b : a, to = inB ? a : b, deeper = !inB;
  inB = !inB;
  to.hidden = false;
  if (matchMedia('(prefers-reduced-motion: reduce)').matches) { from.hidden = true; return; }
  busy = true;
  const out = from.animate([{ transform: 'scale(1)', opacity: 1 }, { transform: `scale(${deeper ? 3 : 0.6})`, opacity: 0 }],
    { duration: 450, easing: 'cubic-bezier(0.4, 0, 1, 1)', fill: 'forwards' });
  const inn = to.animate([{ transform: `scale(${deeper ? 0.6 : 3})`, opacity: 0 }, { transform: 'scale(1)', opacity: 1 }],
    { duration: 450, delay: 200, easing: 'cubic-bezier(0, 0, 0.2, 1)', fill: 'backwards' });
  out.onfinish = () => { from.hidden = true; out.cancel(); };
  inn.onfinish = () => { busy = false; };
});
```
