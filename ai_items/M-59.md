# M-59 ブロックディゾルブ（Block dissolve）

- 分野：動き・モーション／目的：手順・流れを説明する
- 動きの分類：画面の転換
- 別名：ディゾルブ、ピクセル転換、ディザ
- 定義：場面が細かな区画ごとにランダムに消え、次の場面に入れ替わる転換。
- 使う場面：映像の場面転換、時間の経過。
- 注意：細かい粒が画面全体でちらつく。短い時間で終える。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Adobe — Transition effects in After Effects (Block Dissolve) https://helpx.adobe.com/after-effects/desktop/apply-effects-and-animation-presets/list-of-effects/transition-effects.html#block_dissolve_effect
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：「場面を切り替える」ボタンを押したとき
- 変える値：20px四方の区画ごとに、前の場面 → 次の場面へ置き換える（順番はランダム）
- 時間の例：600ms（180区画を一定の割合で置き換える）
- 動き方の例：線形（置き換えた区画の数が経過時間に比例）
- 動きを減らす設定のとき：区画に分けず、即時（または200msのクロスフェード）で切り替える
- 技術：Canvas 2D
- 補足：HTMLの場面どうしで使う場合は、単色の区画で覆ってから外す2段階にすると近い印象になる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<canvas class="mo-dissolve" width="360" height="200" role="img" aria-label="場面A"></canvas>
<button type="button" class="mo-dissolve-go">場面を切り替える</button>
```

```css
.mo-dissolve { max-width: 100%; }
```

```js
const cv = document.querySelector('.mo-dissolve'), ctx = cv.getContext('2d');
const W = cv.width, H = cv.height, S = 20; // S：区画の大きさ
function scene(bg, fg, label) { // 場面を画像として用意する（写真や映像のフレームでもよい）
  const c = Object.assign(document.createElement('canvas'), { width: W, height: H, label });
  const g = c.getContext('2d');
  g.fillStyle = bg; g.fillRect(0, 0, W, H);
  Object.assign(g, { fillStyle: fg, font: 'bold 32px sans-serif', textAlign: 'center', textBaseline: 'middle' });
  g.fillText(label, W / 2, H / 2);
  return c;
}
let from = scene('#e2e8f0', '#0f172a', '場面A'), to = scene('#1e3a8a', '#fff', '場面B'), busy = false;
const cells = [];
for (let y = 0; y < H; y += S) for (let x = 0; x < W; x += S) cells.push([x, y]);
ctx.drawImage(from, 0, 0);
document.querySelector('.mo-dissolve-go').addEventListener('click', () => {
  if (busy) return;
  busy = true;
  for (let i = cells.length - 1; i > 0; i--) { // 区画の順番を並べ替える
    const j = Math.floor(Math.random() * (i + 1));
    [cells[i], cells[j]] = [cells[j], cells[i]];
  }
  const dur = matchMedia('(prefers-reduced-motion: reduce)').matches ? 0 : 600;
  let t0;
  const loop = (now) => {
    t0 ??= now;
    const k = dur ? Math.min(1, (now - t0) / dur) : 1, n = Math.floor(k * cells.length);
    ctx.drawImage(to, 0, 0);
    for (let i = n; i < cells.length; i++) { const [x, y] = cells[i]; ctx.drawImage(from, x, y, S, S, x, y, S, S); }
    if (k < 1) return requestAnimationFrame(loop);
    [from, to] = [to, from];
    cv.setAttribute('aria-label', from.label);
    busy = false;
  };
  requestAnimationFrame(loop);
});
```
