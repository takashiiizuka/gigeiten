# M-84 ネオンの明滅（Neon flicker）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：質感・効果
- 別名：ネオンサイン、フリッカー
- 定義：ネオン管のように、光が不規則に一瞬弱まる表現。
- 使う場面：夜・ナイトライフ・レトロの演出。
- 注意：1秒に3回を超える点滅は避ける（WCAG 2.3.1）。大きな面積で点滅させない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：W3C WAI — Understanding Success Criterion 2.3.1: Three Flashes or Below Threshold https://www.w3.org/WAI/WCAG22/Understanding/three-flashes-or-below-threshold.html
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示されたとき（点灯の演出として1回）
- 変える値：opacity 0.15 → 1 で点灯した後、1 → 0.35 → 1 の一瞬の弱まりを2回。弱まる間は text-shadow の光を消す
- 時間の例：全体 1.6秒（弱まりは約0.7秒後と約1.4秒後）
- 動き方の例：段階的な切り替え（steps(1)）
- 動きを減らす設定のとき：明滅させず、点灯した状態で表示する
- 技術：CSS
- 補足：繰り返す場合も、どの1秒間でも明滅が3回を超えないことを、キーフレームの時刻から数えて確認する（WCAG 2.3.1）。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-night"><p class="mo-neon">OPEN LATE</p></div>
```

```css
.mo-night{padding:40px;background:#0b0b12;text-align:center}
.mo-neon{--glow:0 0 4px #ff4fa3,0 0 12px #ff4fa3,0 0 28px #ff1f8e;margin:0;font:700 48px/1 system-ui,sans-serif;color:#ffe4f1;text-shadow:var(--glow);animation:mo-flicker 1.6s steps(1) both}
/* 弱まるのは約0.7秒後と約1.4秒後の2回。どの1秒間でも明滅は3回を超えない */
@keyframes mo-flicker{
  0%{opacity:.15;text-shadow:none}
  6%{opacity:1;text-shadow:var(--glow)}
  44%{opacity:.35;text-shadow:none}
  47%{opacity:1;text-shadow:var(--glow)}
  88%{opacity:.35;text-shadow:none}
  91%,100%{opacity:1;text-shadow:var(--glow)}
}
@media (prefers-reduced-motion:reduce){.mo-neon{animation:none}}
```
