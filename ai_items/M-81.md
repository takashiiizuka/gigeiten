# M-81 シャイン（光の走査）（Shine sweep）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：質感・効果
- 別名：光沢、シマー、きらり
- 定義：金属や箔、ガラスの面を、斜めの光が横切る表現。
- 使う場面：特別なボタン、プレミアム感、ロゴ。
- 注意：繰り返しは間隔をあける。常時の光沢は注意をそらす。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：GitHub — facebookarchive/Shimmer https://github.com/facebookarchive/Shimmer
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：ボタンにポインターを重ねたとき、またはフォーカスしたとき
- 変える値：斜めの光の帯（白、不透明度 0.45）の translateX -100% → 100%
- 時間の例：600〜900ms。自動で繰り返す場合は間隔を 3〜6秒あける
- 動き方の例：ease-in-out
- 動きを減らす設定のとき：光を動かさず、ホバーとフォーカスでは背景色の変化だけにする
- 技術：CSS
- 補足：戻りには transition を付けず、光が一方向にだけ通るようにする。自動で繰り返し5秒を超える場合は止める手段を付ける。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<a class="mo-shine" href="#">プレミアム会員になる</a>
```

```css
.mo-shine{position:relative;display:inline-block;overflow:hidden;padding:14px 28px;border-radius:8px;background:#1f2937;color:#fde68a;font-weight:700;text-decoration:none}
.mo-shine::after{content:"";position:absolute;inset:0;background:linear-gradient(115deg,transparent 30%,rgb(255 255 255/.45) 50%,transparent 70%);transform:translateX(-100%);pointer-events:none}
.mo-shine:hover::after,.mo-shine:focus-visible::after{transform:translateX(100%);transition:transform 800ms ease-in-out}
@media (prefers-reduced-motion:reduce){
  .mo-shine::after{display:none}
  .mo-shine:hover,.mo-shine:focus-visible{background:#374151}
}
```
