# M-36 テキストスクランブル（Text scramble）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：文字
- 別名：デコード、シャッフル
- 定義：ランダムな文字が入れ替わりながら、最終の文字に確定していく表現。
- 使う場面：テクノロジー系の見出し、数値や暗号の演出。
- 注意：確定するまで読めない。短い語に限り、読み上げには最終の文字を渡す。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：GSAP — ScrambleText https://gsap.com/docs/v3/Plugins/ScrambleTextPlugin/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：要素が画面に入ったとき（ホバーやフォーカスで再生してもよい）
- 変える値：各文字を乱数の文字に置き換え、左から順に最終の文字へ確定させる
- 時間の例：全体で約1秒、文字の入れ替えは50msごと
- 動き方の例：線形（左から一定の速さで確定する）
- 動きを減らす設定のとき：入れ替えを行わず、最終の文字をそのまま表示する
- 技術：CSS + JavaScript
- 補足：等幅の書体にすると、入れ替え中に文字幅が変わらず行が揺れない。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<h2 class="mo-scramble" aria-label="SYSTEM ONLINE"><span aria-hidden="true">SYSTEM ONLINE</span></h2>
```

```css
.mo-scramble { font-family: ui-monospace, Menlo, Consolas, monospace; letter-spacing: 0.05em; }
```

```js
const box = document.querySelector('.mo-scramble');
const out = box.firstElementChild, final = out.textContent;
const pool = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789#%&';
function scramble(duration = 1000) {
  const start = performance.now();
  const id = setInterval(() => {
    const fixed = Math.floor(((performance.now() - start) / duration) * final.length);
    out.textContent = [...final].map((ch, i) =>
      i < fixed || ch === ' ' ? ch : pool[Math.floor(Math.random() * pool.length)]).join('');
    if (fixed >= final.length) clearInterval(id);
  }, 50);
}
if (!matchMedia('(prefers-reduced-motion: reduce)').matches) {
  new IntersectionObserver(([e], io) => {
    if (e.isIntersecting) { scramble(); io.disconnect(); }
  }).observe(box);
}
```
