# M-99 コマ送り（ステップ）（Stepped animation）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：動きの原理
- 別名：フレームアニメーション、steps()
- 定義：連続して動かさず、決まったコマ数で段階的に切り替える動き。
- 使う場面：スプライトアニメーション、時計の秒針、ドット絵風の表現。
- 注意：コマ数が少ないとぎこちなく見える。意図して使う。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — steps() https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/easing-function/steps
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示されている間（時計の秒針、スプライトの再生）
- 変える値：秒針の rotate 0 → 360deg を steps(60) で60コマに分ける（1コマ 6deg）
- 時間の例：秒針は1周 60秒（1コマ 1秒）。スプライトは1秒に 8〜12コマ
- 動き方の例：steps(60)
- 動きを減らす設定のとき：コマ送りを止め、最初のコマで静止する
- 技術：CSS + JavaScript
- 補足：スプライトでは、コマを横に並べた画像の background-position を steps(コマ数) で送る。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-clock" role="img" aria-label="1秒ごとに秒針が進む時計"><div class="mo-hand"></div></div>
<button class="mo-clock-btn" type="button">止める</button>
```

```css
.mo-clock{position:relative;width:120px;height:120px;border:3px solid #334155;border-radius:50%}
.mo-hand{position:absolute;left:calc(50% - 1px);bottom:50%;width:2px;height:50px;background:#dc2626;transform-origin:50% 100%;animation:mo-tick 60s steps(60) infinite}
.mo-clock.is-paused .mo-hand{animation-play-state:paused}
/* steps(60)：1周を60コマに分け、1秒に1コマ（6度）ずつ進める */
@keyframes mo-tick{to{transform:rotate(360deg)}}
@media (prefers-reduced-motion:reduce){.mo-hand{animation:none}.mo-clock-btn{display:none}}
```

```js
const clock=document.querySelector('.mo-clock'),btn=document.querySelector('.mo-clock-btn');
clock.querySelector('.mo-hand').style.animationDelay=`-${new Date().getSeconds()}s`; // 今の秒から始める
btn.addEventListener('click',()=>{
  const paused=clock.classList.toggle('is-paused');
  btn.textContent=paused?'再開する':'止める';
});
```
