# M-53 ワープ（星の流れ）（Starfield / warp）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：粒子・生成
- 別名：スターフィールド、ハイパースペース
- 定義：奥から手前へ粒子が流れ、速くなると光の筋に見える表現。
- 使う場面：場面転換、スピード感や未来感の演出。
- 注意：画面全体が動くので、酔いやすい人に配慮し短く使う。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：The Coding Train — Starfield in Processing https://thecodingtrain.com/challenges/1-starfield
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：「ワープ」ボタンを押したとき（場面転換の瞬間）
- 変える値：星の奥行き z の1フレームあたりの減少量（0.002 → 0.032 → 0.002）。前のフレームの位置から線を引き、速いほど長い光の筋にする
- 時間の例：1600ms で加速してから減速し、自動で止まる
- 動き方の例：sin² の山型（中央で最も速い）
- 動きを減らす設定のとき：星を流す動きを省き、次の場面へ直接（または短いフェードで）切り替える
- 技術：Canvas 2D
- 補足：画面全体が速く動く時間は短く（例：2秒以内）に抑える。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<canvas class="mo-warp" width="480" height="270" aria-hidden="true"></canvas>
<button type="button" class="mo-warp-go">ワープ</button>
```

```css
.mo-warp { display: block; max-width: 100%; }
```

```js
const cv = document.querySelector('.mo-warp'), ctx = cv.getContext('2d');
const W = cv.width, H = cv.height, F = W * 0.35; // F：遠近の強さ
const rand = () => Math.random() * 2 - 1;
const stars = Array.from({ length: 250 }, () => ({ x: rand(), y: rand(), z: 0.05 + Math.random() * 0.95 }));
function frame(speed) {
  ctx.fillStyle = '#020617';
  ctx.fillRect(0, 0, W, H);
  ctx.strokeStyle = ctx.fillStyle = '#e2e8f0';
  for (const s of stars) {
    const z0 = s.z;
    s.z -= speed;
    if (s.z < 0.05) { Object.assign(s, { x: rand(), y: rand(), z: 1 }); continue; }
    const w = 1.6 - s.z; // 手前ほど太く
    const x1 = W / 2 + (s.x / s.z) * F, y1 = H / 2 + (s.y / s.z) * F;
    ctx.lineWidth = w;
    ctx.beginPath();
    ctx.moveTo(W / 2 + (s.x / z0) * F, H / 2 + (s.y / z0) * F); // 前のフレームの位置から
    ctx.lineTo(x1, y1);
    ctx.stroke();
    ctx.fillRect(x1 - w / 2, y1 - w / 2, w, w);
  }
}
let busy = false;
frame(0);
document.querySelector('.mo-warp-go').addEventListener('click', () => {
  // 動きを減らす設定では星を流さず、ここで次の場面へ直接切り替える
  if (busy || matchMedia('(prefers-reduced-motion: reduce)').matches) return;
  busy = true;
  let t0;
  const loop = (now) => {
    t0 ??= now;
    const k = Math.min(1, (now - t0) / 1600);
    frame(0.002 + 0.03 * Math.sin(Math.PI * k) ** 2); // 中央で最も速い
    if (k < 1) requestAnimationFrame(loop); else busy = false;
  };
  requestAnimationFrame(loop);
});
```
