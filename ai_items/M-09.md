# M-09 線描画アニメーション（Line drawing animation）

- 分野：動き・モーション／目的：手順・流れを説明する
- 動きの分類：線・図形
- 別名：なし
- 定義：線が伸びて描かれるように見せる動き。
- 使う場面：手順や接続の順序を説明する。
- 注意：グラフでは描画速度をデータの速度と誤認させない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — stroke-dashoffset https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/stroke-dashoffset
- 向いている媒体：LP・Webサイト（主）、スライド・講演（主）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：図が画面に入ったとき
- 変える値：stroke-dashoffset: 1 → 0（pathLength="1" と stroke-dasharray: 1 で線の長さを 1 にそろえる）
- 時間の例：600〜1200ms（線が長いほど長め）
- 動き方の例：加減速（ease-in-out）
- 動きを減らす設定のとき：描かれる過程を省き、完成した線を最初から表示する
- 技術：SVG + JavaScript
- 補足：折れ線グラフに使う場合は、描画の速さがデータの変化の速さに見えないよう、軸と値を先に示してから線を描く。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<svg class="mo-draw" viewBox="0 0 300 100" width="300" height="100" role="img" aria-label="3つの工程をつなぐ線">
  <path d="M20 80 L100 30 L180 60 L280 20" pathLength="1" fill="none" stroke="#2b6cb0" stroke-width="4" stroke-linejoin="round"/>
</svg>
```

```css
.mo-draw path { stroke-dasharray: 1; stroke-dashoffset: 1; transition: stroke-dashoffset 900ms ease-in-out; }
.mo-draw.is-drawn path { stroke-dashoffset: 0; }
@media (prefers-reduced-motion: reduce) {
  .mo-draw path { stroke-dashoffset: 0; transition: none; }
}
```

```js
const io = new IntersectionObserver((entries) => {
  entries.forEach((e) => {
    if (!e.isIntersecting) return;
    e.target.classList.add('is-drawn');
    io.unobserve(e.target);
  });
}, { threshold: 0.5 });
document.querySelectorAll('.mo-draw').forEach((el) => io.observe(el));
```
