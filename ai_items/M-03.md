# M-03 スライドイン（Slide in）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：出現・退場
- 別名：なし
- 定義：位置を移動させながら表示する動き。
- 使う場面：パネルや関連情報の出現。
- 注意：大きな移動や多数の同時移動を避ける。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：IBM Carbon — Motion https://carbondesignsystem.com/elements/motion/overview/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：パネルを開く操作をしたとき
- 変える値：transform: translateX(100%) → translateX(0)（画面右端からのパネルの例）
- 時間の例：250〜300ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：移動をやめ、不透明度の短い変化だけでパネルを表示する
- 技術：CSS + JavaScript
- 補足：閉じている間は visibility: hidden にして、画面外のパネルにフォーカスが移らないようにする。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-open" type="button" aria-expanded="false">詳細を開く</button>
<aside class="mo-panel" aria-label="詳細">関連情報のパネル</aside>
```

```css
.mo-panel { position: fixed; top: 0; right: 0; width: 280px; height: 100%; padding: 16px; background: #fff; box-shadow: -4px 0 16px rgb(0 0 0 / 0.15);
  transform: translateX(100%); visibility: hidden;
  transition: transform 280ms cubic-bezier(0.2, 0, 0, 1), visibility 0s 280ms; }
.mo-panel.is-open { transform: none; visibility: visible; transition-delay: 0s; }
@media (prefers-reduced-motion: reduce) {
  .mo-panel { transform: none; opacity: 0; transition: opacity 150ms linear, visibility 0s 150ms; }
  .mo-panel.is-open { opacity: 1; }
}
```

```js
const btn = document.querySelector('.mo-open');
const panel = document.querySelector('.mo-panel');
btn.addEventListener('click', () => {
  const open = panel.classList.toggle('is-open');
  btn.setAttribute('aria-expanded', String(open));
});
```
