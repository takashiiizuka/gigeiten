# M-72 慣性（Inertia / momentum）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：操作への反応
- 別名：モメンタム、フリック
- 定義：指やポインターを離した後も、勢いを保ってから徐々に止まる動き。
- 使う場面：スクロール、カルーセル、地図の移動。
- 注意：止まる位置が予測しにくい。区切りの位置に吸い付かせる場合は明示する。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：GSAP — Inertia (InertiaPlugin) https://gsap.com/docs/v3/Plugins/InertiaPlugin/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：一覧をドラッグして離したとき。キーボードでは左右の矢印キーで同じ幅だけ動かす
- 変える値：translateX を離した時点の速さで動かし続け、1フレームごとに速さを 0.95 倍にして止める
- 時間の例：払った速さにより 0.5〜1.5秒程度
- 動き方の例：摩擦による減速（速さ × 0.95 / フレーム）
- 動きを減らす設定のとき：離した位置で止め、勢いを付けない
- 技術：CSS + JavaScript
- 補足：通常のスクロール（overflow: auto）ではOSが慣性を付けるため、自作は地図や独自の操作など、標準のスクロールで足りない場合にとどめる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-inertia" tabindex="0" role="region" aria-label="横に動かせる一覧。左右の矢印キーでも移動できます">
  <div class="mo-strip"><b>1</b><b>2</b><b>3</b><b>4</b><b>5</b><b>6</b><b>7</b><b>8</b></div>
</div>
```

```css
.mo-inertia{width:320px;overflow:hidden;border:1px solid #cbd5e1;border-radius:8px;touch-action:pan-y;cursor:grab;user-select:none}
.mo-inertia:focus-visible{outline:3px solid #2563eb}
.mo-strip{display:flex;gap:8px;width:max-content;padding:8px}
.mo-strip b{display:grid;place-items:center;width:96px;height:96px;border-radius:8px;background:#e0e7ff}
```

```js
const view=document.querySelector('.mo-inertia'),strip=view.querySelector('.mo-strip');
const reduce=matchMedia('(prefers-reduced-motion: reduce)').matches;
let x=0,v=0,lastX=0,lastT=0,drag=false,raf=0;
const minX=()=>Math.min(0,view.clientWidth-strip.offsetWidth);
function setX(nx){x=Math.max(minX(),Math.min(0,nx));strip.style.transform=`translateX(${x}px)`;}
function glide(){ // 1フレームごとに速さを 0.95 倍にする
  v*=.95;setX(x+v);
  raf=Math.abs(v)>.2&&x>minX()&&x<0?requestAnimationFrame(glide):0;
}
view.addEventListener('pointerdown',e=>{drag=true;v=0;cancelAnimationFrame(raf);lastX=e.clientX;lastT=e.timeStamp;view.setPointerCapture(e.pointerId);});
view.addEventListener('pointermove',e=>{
  if(!drag)return;
  const dx=e.clientX-lastX,dt=Math.max(1,e.timeStamp-lastT);
  v=dx/dt*16;setX(x+dx);lastX=e.clientX;lastT=e.timeStamp;
});
view.addEventListener('pointerup',e=>{
  drag=false;
  if(e.timeStamp-lastT>80)v=0; // 止めてから離したときは勢いを付けない
  if(!reduce&&v)glide();
});
view.addEventListener('pointercancel',()=>{drag=false;});
view.addEventListener('keydown',e=>{
  const d={ArrowLeft:104,ArrowRight:-104}[e.key];
  if(d){e.preventDefault();cancelAnimationFrame(raf);setX(x+d);}
});
```
