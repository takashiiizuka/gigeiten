# I-12 ラスター画像（Raster image / Bitmap）

- 分野：設計・実装の用語／目的：見た目・印象を整える
- 別名：なし
- 定義：画素の並びで表す画像。
- 使う場面：写真や質感のある画像。
- 注意：拡大時の解像度とファイル量を考える。
- 用意する情報（分野共通）：出力形式、対応環境、コンテンツ、再利用の範囲。基本の内容と追加機能を分けて考えます。
- 出典：MDN — Image file types https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Formats/Image_types
- 向いている媒体：LP・Webサイト（副）、画像・バナー（主）（AIの編集判断・未確認）
