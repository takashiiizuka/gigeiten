# M-56 ノイズの波（Noise-driven motion）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：粒子・生成
- 別名：パーリンノイズ、有機的な動き
- 定義：なめらかな乱数（パーリンノイズ等）で、線や形をゆっくり不規則に揺らす表現。
- 使う場面：背景の動き、有機的な印象の演出。
- 注意：背景として控えめにし、内容より目立たせない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：The Nature of Code — 0. Randomness https://natureofcode.com/random/#a-smoother-approach-with-perlin-noise
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示と同時（停止ボタン、画面外、タブが非表示のときは止める）
- 変える値：5本の線の各点の y。値ノイズ noise(x × 0.008, 時間) で上下に最大±30px動かす
- 時間の例：連続。ノイズの時間を1秒あたり0.25進める（1つの山が形を変えるのに約4秒）
- 動き方の例：ノイズの補間（smoothstep：3t² − 2t³）
- 動きを減らす設定のとき：波を止め、1フレームを静止画として表示する（再生ボタンで動かせる）
- 技術：Canvas 2D
- 補足：時間の進みを遅くするほど背景として落ち着き、線の色を文字より薄くすると内容の邪魔になりにくい。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<canvas class="mo-nwave" width="480" height="200" aria-hidden="true"></canvas>
<button type="button" class="mo-nwave-toggle">停止</button>
```

```css
.mo-nwave { display: block; max-width: 100%; background: #f0fdfa; }
```

```js
const cv = document.querySelector('.mo-nwave'), ctx = cv.getContext('2d'), W = cv.width, H = cv.height;
const btn = document.querySelector('.mo-nwave-toggle');
const hash = (x, y) => { const s = Math.sin(x * 127.1 + y * 311.7) * 43758.5453; return s - Math.floor(s); };
function noise(x, y) { // 値ノイズ（0〜1）
  const i = Math.floor(x), j = Math.floor(y), fx = x - i, fy = y - j;
  const u = fx * fx * (3 - 2 * fx), v = fy * fy * (3 - 2 * fy);
  const a = hash(i, j), b = hash(i + 1, j), c = hash(i, j + 1), d = hash(i + 1, j + 1);
  return a + (b - a) * u + (c - a) * v + (a - b - c + d) * u * v;
}
let t = 0, last = 0, raf = 0, visible = true;
let running = !matchMedia('(prefers-reduced-motion: reduce)').matches;
function draw() {
  ctx.clearRect(0, 0, W, H);
  for (let k = 0; k < 5; k++) {
    ctx.beginPath();
    ctx.strokeStyle = `rgba(15, 118, 110, ${0.25 + k * 0.15})`;
    for (let x = 0; x <= W; x += 6) {
      const y = H * (0.3 + k * 0.1) + (noise(x * 0.008, t + k * 3) - 0.5) * 60;
      if (x === 0) ctx.moveTo(x, y); else ctx.lineTo(x, y);
    }
    ctx.stroke();
  }
}
function loop(now) { t += (Math.min(50, now - (last || now)) / 1000) * 0.25; last = now; draw(); raf = requestAnimationFrame(loop); }
function sync() { cancelAnimationFrame(raf); last = 0; if (running && visible && !document.hidden) raf = requestAnimationFrame(loop); }
btn.textContent = running ? '停止' : '再生';
btn.addEventListener('click', () => { running = !running; btn.textContent = running ? '停止' : '再生'; sync(); });
document.addEventListener('visibilitychange', sync);
new IntersectionObserver(([e]) => { visible = e.isIntersecting; sync(); }).observe(cv);
draw();
```
