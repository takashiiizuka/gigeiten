# M-29 ブラーイン（Blur in）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：出現・退場
- 別名：ぼかしから出現、フォーカスイン
- 定義：ぼかした状態から、焦点が合うように現れる動き。
- 使う場面：見出しや写真の登場を、やわらかく見せる。
- 注意：ぼかしは描画の負荷が高い。文字をぼかしたまま長く待たせない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Apple Developer — BlurReplaceTransition https://developer.apple.com/documentation/swiftui/blurreplacetransition
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：見出しや写真が表示されるとき
- 変える値：filter: blur(8px) → blur(0)、opacity 0 → 1
- 時間の例：300〜500ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：ぼかしをやめ、150ms 程度の不透明度の変化だけにする
- 技術：CSS
- 補足：filter: blur() は描画の負荷が高いため、大きな面や多数の要素に同時に使わず、ぼけた文字を読ませる時間を短くする。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<h2 class="mo-blur">焦点が合うように現れる見出し</h2>
```

```css
.mo-blur { animation: mo-blur-in 400ms cubic-bezier(0.2, 0, 0, 1) both; }
@keyframes mo-blur-in { from { opacity: 0; filter: blur(8px); } }
@keyframes mo-fade-in { from { opacity: 0; } }
@media (prefers-reduced-motion: reduce) {
  .mo-blur { animation: mo-fade-in 150ms linear both; }
}
```
