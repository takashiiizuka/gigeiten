# A-10 ターゲットサイズ（Target size）

- 分野：アクセシビリティ／目的：読みやすさ・使いやすさを守る
- 別名：なし
- 定義：押せる領域の大きさ。WCAG 2.2には最小サイズの基準がある。
- 使う場面：小さなボタンやリンクの操作性。
- 注意：AA（2.5.8）は24×24 CSS px以上で、間隔などの例外がある。44×44はAAA（2.5.5）。
- 用意する情報（分野共通）：対象の内容と操作、利用環境、見えるラベル、フォーカス順。見た目だけでなく操作と意味も確認します。
- 出典：W3C — Target Size (Minimum) https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html
