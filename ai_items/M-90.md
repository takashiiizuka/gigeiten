# M-90 棒の伸長（Bar grow-in）

- 分野：動き・モーション／目的：大小・差を比較する
- 動きの分類：データ
- 別名：グラフのアニメーション
- 定義：棒が基準の線から、時間差で伸びて現れる表現。
- 使う場面：資料・LPのグラフの登場。
- 注意：伸びきった後の値が正しいことを確認する。動かない版でも読めるようにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：D3 — Transitions https://d3js.org/d3-transition
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：グラフが画面に入ったとき（1回だけ）
- 変える値：各棒の scaleY 0 → 1（transform-origin は下端）。棒ごとに開始を 80ms ずつ遅らせる
- 時間の例：1本 500〜700ms、全体で 1秒前後
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：伸ばさず、完成したグラフを最初から表示する
- 技術：CSS + JavaScript
- 補足：縮めた初期状態は JavaScript で付けるクラスの下に書き、スクリプトが動かない場合も完成したグラフが見えるようにする。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<figure class="mo-bars" role="img" aria-label="月別の売上（万円）：4月40、5月65、6月90、7月55">
  <div class="mo-bar" style="--v:40;--i:0"><span>40</span></div>
  <div class="mo-bar" style="--v:65;--i:1"><span>65</span></div>
  <div class="mo-bar" style="--v:90;--i:2"><span>90</span></div>
  <div class="mo-bar" style="--v:55;--i:3"><span>55</span></div>
</figure>
```

```css
.mo-bars{display:flex;align-items:flex-end;gap:16px;height:180px;margin:0;padding:0 12px;border-bottom:2px solid #334155}
.mo-bar{position:relative;width:40px;height:calc(var(--v)*1%);background:#2563eb;transform-origin:50% 100%}
.mo-bar span{position:absolute;bottom:100%;left:0;right:0;text-align:center;font-size:12px}
.mo-bars.is-ready .mo-bar{transform:scaleY(0);transition:transform 600ms cubic-bezier(.2,0,0,1) calc(var(--i)*80ms)}
.mo-bars.is-ready.is-in .mo-bar{transform:scaleY(1)}
```

```js
const chart=document.querySelector('.mo-bars');
if(!matchMedia('(prefers-reduced-motion: reduce)').matches){
  chart.classList.add('is-ready'); // スクリプトが動かないときは、完成した棒がそのまま見える
  new IntersectionObserver((entries,io)=>{
    if(entries[0].isIntersecting){chart.classList.add('is-in');io.disconnect();}
  },{threshold:.5}).observe(chart);
}
```
