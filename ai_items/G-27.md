# G-27 ピラミッドストラクチャー（Pyramid structure (Pyramid Principle)）

- 分野：関係・工程の図解／目的：構成・関係を整理する
- 別名：ピラミッド原則、ピラミッド構造
- 定義：要約する主張を上に置き、その下に理由や根拠を階層化する構成。
- 使う場面：論理的な説明や提案。
- 注意：図が三角形なら論理が成立するわけではない。
- 用意する情報（分野共通）：登場する要素、要素間の関係、順序、判断条件、担当。線や矢印に何を意味させるかを決めます。
- 早見表の分類：分解したい
- 出典：Barbara Minto — Pyramid Principle / SCQ https://www.barbaraminto.com/
- 向いている媒体：資料・提案書（主）、スライド・講演（主）、LP・Webサイト（副）、図解・グラフ（主）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）
- v1の対応項目：D-02 ピラミッドストラクチャー / SCQA / MECE（対応：近い。v1は複数の概念を1項目にまとめていた）
  - v1の説明：元McKinseyのバーバラ・ミントが1970年代に体系化した論理構成法。 頂点に結論を置き、その下に相互排他・全体網羅（MECE）な根拠を並べる 。考えるときは下から積み上げ、伝えるときは上から降ろす、が要諦です。 SCQA は導入部の型： 状況（Situation） 読者が同意する現状 → 複雑化（Complication） その現状を揺るがす変化 → 疑問（Question） そこから生じる問い → 答え（Answer） 本論の結論。 MECE ＝Mutually Exclusive, Collectively Exhaustive。分類が重複せず、漏れもない状態。
  - v1の依頼例：構成はピラミッドストラクチャーで。冒頭はSCQA（状況→複雑化→問い→答え）、本論は結論を先に置いてMECEな3本の根拠で支える形にして。
