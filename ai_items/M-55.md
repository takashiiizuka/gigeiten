# M-55 降る粒子（Falling particles）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：粒子・生成
- 別名：雪、雨、パーティクル
- 定義：大きさと速さの違う粒子が、揺れながら落ちる表現。
- 使う場面：季節の演出（雪・雨・花びら）、背景。
- 注意：文字の上を粒子が横切ると読みにくい。量と範囲を絞る。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Adobe — Using simulation effects in After Effects (Particle Playground) https://helpx.adobe.com/after-effects/desktop/apply-effects-and-animation-presets/list-of-effects/simulation-effects.html#particle_playground_effect
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示と同時（停止ボタン、画面外、タブが非表示のときは止める）
- 変える値：粒子70個の y（半径に比例した速さで落ちる）と x（sin で左右に±8px揺れる）
- 時間の例：連続。落ちる速さは1秒あたり20〜70px、揺れの周期は約4秒
- 動き方の例：等速の落下と sin の揺れ
- 動きを減らす設定のとき：粒子を動かさず、静止画として表示する（再生ボタンで動かせる）
- 技術：Canvas 2D
- 補足：粒子の大きさと速さを連動させると、奥行きがあるように見える。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<canvas class="mo-snow" width="480" height="270" aria-hidden="true"></canvas>
<button type="button" class="mo-snow-toggle">停止</button>
```

```css
.mo-snow { display: block; max-width: 100%; background: #1e293b; }
```

```js
const cv = document.querySelector('.mo-snow'), ctx = cv.getContext('2d'), W = cv.width, H = cv.height;
const btn = document.querySelector('.mo-snow-toggle');
const flakes = Array.from({ length: 70 }, () => ({
  x: Math.random() * W, y: Math.random() * H, r: 1 + Math.random() * 2.5, phase: Math.random() * Math.PI * 2
}));
let running = !matchMedia('(prefers-reduced-motion: reduce)').matches, visible = true, raf = 0, last = 0;
function draw() {
  ctx.clearRect(0, 0, W, H);
  ctx.fillStyle = 'rgba(255, 255, 255, 0.85)';
  for (const f of flakes) {
    ctx.beginPath();
    ctx.arc(f.x + Math.sin(f.phase) * 8, f.y, f.r, 0, Math.PI * 2); // 左右に±8px揺らす
    ctx.fill();
  }
}
function loop(now) {
  const dt = Math.min(50, now - (last || now)) / 1000; // 前のフレームからの秒数
  last = now;
  for (const f of flakes) {
    f.y += f.r * 20 * dt; // 大きい粒ほど速く落ちる
    f.phase += dt * 1.5;
    if (f.y > H + 5) { f.y = -5; f.x = Math.random() * W; }
  }
  draw();
  raf = requestAnimationFrame(loop);
}
function sync() { // 停止中・画面外・タブが非表示のときは描かない
  cancelAnimationFrame(raf); last = 0;
  if (running && visible && !document.hidden) raf = requestAnimationFrame(loop);
}
btn.textContent = running ? '停止' : '再生';
btn.addEventListener('click', () => { running = !running; btn.textContent = running ? '停止' : '再生'; sync(); });
document.addEventListener('visibilitychange', sync);
new IntersectionObserver(([e]) => { visible = e.isIntersecting; sync(); }).observe(cv);
draw();
```
