# M-47 粒子への分解（Particle disintegration）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：粒子・生成
- 別名：ディスインテグレート、散る、崩れる
- 定義：形が端から粒子に分かれ、散っていく表現。
- 使う場面：ロゴの退場、消える・変わることの演出。
- 注意：消える意味を持つので、残すべき情報には使わない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Adobe — Using simulation effects in After Effects https://helpx.adobe.com/after-effects/desktop/apply-effects-and-animation-presets/list-of-effects/simulation-effects.html#layer_exploder_and_particle_exploder
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：「分解する」ボタンを押したとき（実際の画面では、要素が退場するとき）
- 変える値：各粒子の位置（右上へ流れる）と opacity 1 → 0。左端の粒子から順に動き出す
- 時間の例：粒子ごとに1000ms、左端から右端まで開始を0〜600msずらす（全体で約1.7秒）
- 動き方の例：線形（一定の速さで流れ、同じ割合で薄くなる）
- 動きを減らす設定のとき：粒子に分けず、形全体を200msで薄くして消す
- 技術：Canvas 2D
- 補足：画素を読み取る間隔（例：3px）を広げると粒子が減り、描画が軽くなる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<canvas class="mo-dust" width="480" height="160" role="img" aria-label="ATLAS"></canvas>
<button type="button" class="mo-dust-go">分解する</button>
```

```css
.mo-dust { max-width: 100%; }
```

```js
const cv = document.querySelector('.mo-dust'), ctx = cv.getContext('2d'), W = cv.width, H = cv.height;
const btn = document.querySelector('.mo-dust-go');
let gone = false, busy = false;
function drawShape() {
  ctx.clearRect(0, 0, W, H);
  Object.assign(ctx, { fillStyle: '#1e3a8a', font: 'bold 110px sans-serif', textAlign: 'center', textBaseline: 'middle' });
  ctx.fillText('ATLAS', W / 2, H / 2);
}
function scatter() {
  const data = ctx.getImageData(0, 0, W, H).data, ps = [];
  for (let y = 0; y < H; y += 3) for (let x = 0; x < W; x += 3) {
    if (data[(y * W + x) * 4 + 3] > 128) {
      ps.push({ x, y, vx: 40 + Math.random() * 80, vy: -Math.random() * 60, delay: (x / W) * 600 });
    }
  }
  let t0;
  const loop = (now) => {
    const t = now - (t0 ??= now); // 開始からの経過（ミリ秒）
    ctx.clearRect(0, 0, W, H);
    for (const p of ps) {
      const k = Math.max(0, t - p.delay) / 1000; // 動き出してからの秒数
      ctx.globalAlpha = Math.max(0, 1 - k);
      ctx.fillRect(p.x + p.vx * k, p.y + p.vy * k, 3, 3);
    }
    ctx.globalAlpha = 1;
    if (t < 1700) requestAnimationFrame(loop); else busy = false;
  };
  requestAnimationFrame(loop);
}
drawShape();
btn.addEventListener('click', () => {
  if (busy) return;
  gone = !gone;
  btn.textContent = gone ? '元に戻す' : '分解する';
  if (!gone) { cv.getAnimations().forEach((a) => a.cancel()); drawShape(); }
  else if (matchMedia('(prefers-reduced-motion: reduce)').matches) {
    cv.animate([{ opacity: 1 }, { opacity: 0 }], { duration: 200, fill: 'forwards' }); // 薄くして消すだけ
  } else { busy = true; scatter(); }
});
```
