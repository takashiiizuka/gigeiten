# M-75 スワイプで閉じる（Swipe to dismiss）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：操作への反応
- 別名：スワイプ削除
- 定義：横に払うと項目が外へ抜けて消え、残りが詰まる操作と表示。
- 使う場面：通知、メールの一覧、カード。
- 注意：取り消せるようにする。払う以外の方法でも同じ操作ができるようにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Android Developers — Swipe to dismiss or update https://developer.android.com/develop/ui/compose/touch-input/user-interactions/swipe-to-dismiss
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：項目を横に払ったとき（幅の35%を超えて離す）。キーボードでは各項目の「閉じる」ボタン
- 変える値：払う間は translateX を指に追従。離したら translateX を幅の 110% まで動かして opacity 1 → 0、続けて高さと余白を 0 にして残りを詰める
- 時間の例：抜ける 200〜250ms、詰める 200ms
- 動き方の例：抜けるときは加速（cubic-bezier(0.3, 0, 1, 1)）、詰めるときは ease
- 動きを減らす設定のとき：横に抜ける動きと詰める動きを省き、項目をすぐに消して「取り消す」を表示する
- 技術：JavaScript（Web Animations API）
- 補足：消した直後に「取り消す」を出してフォーカスをそこへ移すと、キーボードでもすぐに戻せる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<ul class="mo-swipe">
  <li><span>資料が共有されました</span><button type="button" aria-label="この通知を閉じる">×</button></li>
  <li><span>会議が10分後に始まります</span><button type="button" aria-label="この通知を閉じる">×</button></li>
</ul>
<p class="mo-swipe-status" aria-live="polite"></p>
```

```css
.mo-swipe{width:320px;margin:0;padding:0;list-style:none}
.mo-swipe li{box-sizing:border-box;display:flex;justify-content:space-between;align-items:center;margin-bottom:8px;padding:12px;border:1px solid #cbd5e1;border-radius:8px;background:#fff;overflow:hidden;touch-action:pan-y;user-select:none}
.mo-swipe button{border:0;background:none;font-size:18px;cursor:pointer}
```

```js
const list=document.querySelector('.mo-swipe'),status=document.querySelector('.mo-swipe-status');
const reduce=matchMedia('(prefers-reduced-motion: reduce)').matches;
async function dismiss(li,dir){
  if(li.dataset.out)return;li.dataset.out='1';
  if(!reduce){
    await li.animate({transform:`translateX(${dir*110}%)`,opacity:0},{duration:220,easing:'cubic-bezier(.3,0,1,1)',fill:'forwards'}).finished;
    await li.animate({height:[li.offsetHeight+'px','0px'],paddingBlock:['12px','0px'],marginBottom:['8px','0px'],borderWidth:['1px','0px']},{duration:200,fill:'forwards'}).finished;
  }
  const next=li.nextElementSibling;
  li.getAnimations().forEach(a=>a.cancel());li.style.transform='';delete li.dataset.out;li.remove();
  status.innerHTML='1件の通知を閉じました。<button type="button">取り消す</button>';
  const undo=status.querySelector('button');undo.focus();
  undo.onclick=()=>{list.insertBefore(li,next&&next.parentNode===list?next:null);status.textContent='元に戻しました。';li.querySelector('button').focus();};
}
list.addEventListener('click',e=>{const b=e.target.closest('button');if(b)dismiss(b.closest('li'),1);});
list.addEventListener('pointerdown',e=>{
  const li=e.target.closest('li');if(!li||e.target.closest('button'))return;
  const x0=e.clientX;li.setPointerCapture(e.pointerId);li.style.transition='none';
  li.onpointermove=ev=>{li.style.transform=`translateX(${ev.clientX-x0}px)`;};
  li.onpointerup=li.onpointercancel=ev=>{
    li.onpointermove=li.onpointerup=li.onpointercancel=null;
    const dx=ev.clientX-x0;
    if(Math.abs(dx)>li.offsetWidth*.35)return dismiss(li,Math.sign(dx));
    li.style.transition=reduce?'':'transform 200ms ease-out';li.style.transform=''; // しきい値未満なら元へ戻す
  };
});
```
