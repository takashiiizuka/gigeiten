# M-37 キネティックタイポグラフィ（Kinetic typography）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：文字
- 別名：モーションタイポグラフィ、動く文字
- 定義：語の意味やリズムに合わせて、文字の大きさ・位置・速さを変えて動かす表現。
- 使う場面：ブランド映像、会社紹介、音楽に合わせた映像。
- 注意：読み切れる時間を残す。字幕として使う場合は表示時間を確保する。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Wikipedia — Kinetic typography https://en.wikipedia.org/wiki/Kinetic_typography
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示したときと「もう一度再生」ボタンを押したとき
- 変える値：語ごとに別の動きを当てる。「速く、」は translateX -120% → 0、「強く、」は scale 2.4 → 1、「確かに。」は translateY 60% → 0（いずれも opacity 0 → 1）
- 時間の例：250ms、500ms、1200ms（語の間に500msの間を置き、全体で約3秒）
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）と、少し行き過ぎて戻る動き（cubic-bezier(0.3, 1.4, 0.5, 1)）
- 動きを減らす設定のとき：動きを省き、全文を最初から表示する
- 技術：JavaScript（Web Animations API）
- 補足：最後の語が止まってから読み切れる時間を残し、自動の再生は5秒以内に収める。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<h2 class="mo-kinetic" aria-label="速く、強く、確かに。">
  <span class="mo-word" aria-hidden="true">速く、</span><span class="mo-word" aria-hidden="true">強く、</span><span class="mo-word" aria-hidden="true">確かに。</span>
</h2>
<button type="button" class="mo-replay">もう一度再生</button>
```

```css
.mo-kinetic { font-size: 40px; }
.mo-word { display: inline-block; }
```

```js
const words = document.querySelectorAll('.mo-word');
const out = 'cubic-bezier(0.2, 0, 0, 1)';
const plans = [
  { from: 'translateX(-120%)', duration: 250, easing: out },                        // 速く：短く横から
  { from: 'scale(2.4)', duration: 500, easing: 'cubic-bezier(0.3, 1.4, 0.5, 1)' }, // 強く：大きく
  { from: 'translateY(60%)', duration: 1200, easing: out }                          // 確かに：ゆっくり
];
function play() {
  if (matchMedia('(prefers-reduced-motion: reduce)').matches) return;
  let delay = 0;
  words.forEach((w, i) => {
    const p = plans[i];
    w.animate([{ transform: p.from, opacity: 0 }, { transform: 'none', opacity: 1 }],
      { duration: p.duration, easing: p.easing, delay, fill: 'backwards' });
    delay += p.duration + 500;
  });
}
play();
document.querySelector('.mo-replay').addEventListener('click', play);
```
