# M-07 マスクリビール（Mask reveal）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：出現・退場
- 別名：リビール、リヴィール
- 定義：マスクなどの可視領域を変え、内容を現す表現。
- 使う場面：図版や見出しの出現。
- 注意：隠れている間も読み上げ順を適切にする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — clip-path https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/clip-path
- 向いている媒体：LP・Webサイト（主）、スライド・講演（主）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：見出しや図版が画面に入ったとき
- 変える値：内側の要素の clip-path: inset(0 100% 0 0) → inset(0 0 0 0)（左から右へ可視領域を広げる）
- 時間の例：400〜600ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：可視領域の変化をやめ、最初から全体を表示する
- 技術：CSS + JavaScript
- 補足：Chrome では監視対象自身の clip-path が交差の計算に含まれ、隠した状態の割合が 0 になるため、隠す指定は内側の要素に付けて外側の要素を監視する。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<h2 class="mo-reveal"><span>見出しが左から現れます</span></h2>
```

```css
.mo-reveal span { display: inline-block; clip-path: inset(0 100% 0 0); transition: clip-path 500ms cubic-bezier(0.2, 0, 0, 1); }
.mo-reveal.is-visible span { clip-path: inset(0 0 0 0); }
@media (prefers-reduced-motion: reduce) {
  .mo-reveal span { clip-path: none; transition: none; }
}
```

```js
const io = new IntersectionObserver((entries) => {
  entries.forEach((e) => {
    if (!e.isIntersecting) return;
    e.target.classList.add('is-visible');
    io.unobserve(e.target);
  });
}, { threshold: 0.5 });
document.querySelectorAll('.mo-reveal').forEach((el) => io.observe(el));
```
