# M-33 タイプライター（Typewriter）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：文字
- 別名：タイピング、1文字ずつ
- 定義：文字を1字ずつ打ち込むように順に表示する動き。
- 使う場面：見出しの導入、会話や入力の再現。
- 注意：全文が出るまで読めない。長い文には使わず、読み上げでは全文が伝わるようにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：GSAP — Text https://gsap.com/docs/v3/Plugins/TextPlugin/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：見出しが表示されるとき
- 変える値：表示する文字数を 0 → 全文字数へ 1 字ずつ増やす
- 時間の例：1 字あたり 40〜80ms（全体で 1〜2 秒以内に収める）
- 動き方の例：等速（一定間隔で 1 字ずつ）
- 動きを減らす設定のとき：全文を最初から表示する
- 技術：CSS + JavaScript
- 補足：読み上げ用に全文を別に置き、打ち込み中の文字は aria-hidden にする。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<h2 class="mo-type"><span class="mo-sr">記録から、次の一手を考える。</span><span class="mo-typed" aria-hidden="true">記録から、次の一手を考える。</span></h2>
```

```css
.mo-type { min-height: 1.5em; }
.mo-sr { position: absolute; width: 1px; height: 1px; overflow: hidden; clip-path: inset(50%); white-space: nowrap; }
.mo-typed.is-typing::after { content: ""; display: inline-block; width: 2px; height: 1em; margin-left: 2px; background: currentColor; vertical-align: -0.1em; }
```

```js
const el = document.querySelector('.mo-typed');
const chars = [...el.textContent]; // サロゲートペアを分割しない
if (!matchMedia('(prefers-reduced-motion: reduce)').matches) {
  let i = 0;
  el.textContent = '';
  el.classList.add('is-typing'); // 入力中だけカーソルを出す（点滅はさせない）
  const timer = setInterval(() => {
    el.textContent = chars.slice(0, ++i).join('');
    if (i >= chars.length) { clearInterval(timer); el.classList.remove('is-typing'); }
  }, 60);
}
```
