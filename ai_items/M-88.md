# M-88 カードフリップ（Card flip）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：3D・カメラ
- 別名：裏返し、フリップカード
- 定義：カードを縦軸で回し、表から裏へ返す動き。
- 使う場面：問題と答え、表と詳細の切り替え。
- 注意：裏の内容も読み上げやキーボードで届くようにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：David DeSandro — Card Flip (Intro to CSS 3D transforms) https://3dtransforms.desandro.com/card-flip
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：カードを押したとき（クリック、タップ、Enter、Space）
- 変える値：内側の rotateY 0 → 180deg。裏面は最初から rotateY(180deg) にし、両面に backface-visibility: hidden
- 時間の例：400〜600ms
- 動き方の例：標準（cubic-bezier(0.4, 0, 0.2, 1)）
- 動きを減らす設定のとき：回転させず、表と裏を即時に切り替える
- 技術：CSS + JavaScript
- 補足：カードを button にし、見えていない面に aria-hidden を付け替えると、キーボードと読み上げでも裏の内容に届く。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-flip" type="button">
  <span class="mo-flip-inner">
    <span class="mo-flip-face">問題：日本の首都は</span>
    <span class="mo-flip-face mo-flip-back" aria-hidden="true">答え：東京</span>
  </span>
</button>
```

```css
.mo-flip{width:260px;height:160px;padding:0;border:0;background:none;font:inherit;perspective:800px;cursor:pointer}
.mo-flip:focus-visible{outline:3px solid #2563eb;outline-offset:4px}
.mo-flip-inner{position:relative;display:block;width:100%;height:100%;transform-style:preserve-3d;transition:transform 500ms cubic-bezier(.4,0,.2,1)}
.mo-flip.is-flipped .mo-flip-inner{transform:rotateY(180deg)}
.mo-flip-face{position:absolute;inset:0;display:grid;place-items:center;border-radius:12px;background:#1e3a8a;color:#fff;backface-visibility:hidden}
.mo-flip-back{background:#fef3c7;color:#78350f;transform:rotateY(180deg)}
@media (prefers-reduced-motion:reduce){.mo-flip-inner{transition:none}}
```

```js
document.querySelectorAll('.mo-flip').forEach(card=>{
  const [front,back]=card.querySelectorAll('.mo-flip-face');
  card.addEventListener('click',()=>{
    const flipped=card.classList.toggle('is-flipped');
    front.setAttribute('aria-hidden',String(flipped)); // 見えている面だけを読み上げる
    back.setAttribute('aria-hidden',String(!flipped));
  });
});
```
