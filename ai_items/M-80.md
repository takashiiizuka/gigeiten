# M-80 グリッチ（Glitch）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：質感・効果
- 別名：ノイズ、バグ風
- 定義：一瞬だけ横にずれたり色が分かれたりする、乱れのような表現。
- 使う場面：テクノロジーや音楽の演出、注目を集める見出し。
- 注意：激しい点滅にしない（1秒に3回以下）。読ませる本文には使わない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：CSS-Tricks — Glitch Effect on Text / Images / SVG https://css-tricks.com/glitch-effect-text-images-svg/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：見出しが画面に入ったとき、またはポインターを重ねたとき（1回ずつ）
- 変える値：文字の複製2枚（赤・青）を translateX ±2〜3px ずらし、clip-path: inset() で見せる横の帯の位置を3回切り替える
- 時間の例：1回 0.3〜0.5秒。次の再生まで2秒以上あける
- 動き方の例：段階的な切り替え（steps(1)）
- 動きを減らす設定のとき：ずらさず、通常の見出しとして表示する
- 技術：CSS + JavaScript
- 補足：複製は content の代替テキストを空（/ ""）にして、読み上げが重ならないようにする。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<h1 class="mo-glitch" data-text="SIGNAL">SIGNAL</h1>
```

```css
.mo-glitch{position:relative;display:inline-block;margin:0;font:700 56px/1.1 system-ui,sans-serif}
.mo-glitch::before,.mo-glitch::after{content:attr(data-text) / "";position:absolute;inset:0;opacity:0;pointer-events:none}
.mo-glitch::before{color:#ef4444}
.mo-glitch::after{color:#3b82f6}
.mo-glitch.is-on::before{animation:mo-glitch-a 450ms steps(1)}
.mo-glitch.is-on::after{animation:mo-glitch-b 450ms steps(1)}
@keyframes mo-glitch-a{0%{opacity:.8;transform:translateX(-3px);clip-path:inset(10% 0 60% 0)}33%{transform:translateX(3px);clip-path:inset(55% 0 20% 0)}66%{transform:translateX(-2px);clip-path:inset(30% 0 45% 0)}}
@keyframes mo-glitch-b{0%{opacity:.8;transform:translateX(3px);clip-path:inset(60% 0 10% 0)}33%{transform:translateX(-3px);clip-path:inset(20% 0 55% 0)}66%{transform:translateX(2px);clip-path:inset(45% 0 30% 0)}}
```

```js
const el=document.querySelector('.mo-glitch');
const reduce=matchMedia('(prefers-reduced-motion: reduce)').matches;
let last=-Infinity;
function play(){ // 1回0.45秒。次まで2秒以上あけ、点滅が1秒に3回を超えないようにする
  const now=performance.now();
  if(reduce||now-last<2000)return;
  last=now;
  el.classList.remove('is-on');void el.offsetWidth;el.classList.add('is-on');
}
new IntersectionObserver(entries=>{if(entries[0].isIntersecting)play();}).observe(el);
el.addEventListener('pointerenter',play);
```
