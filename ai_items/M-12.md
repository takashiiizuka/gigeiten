# M-12 FLIP（First, Last, Invert, Play）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：画面の転換
- 別名：なし
- 定義：レイアウト変更前後の位置差を変形で補い、動きとして再生する手法。
- 使う場面：並び替えなどの位置変化。
- 注意：変形の scale で補うため、途中で文字や角丸がゆがむことがある。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：GSAP — Flip https://gsap.com/docs/v3/Plugins/Flip/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：並び替えや追加で、レイアウトが変わったとき
- 変える値：変更前の位置（First）と変更後の位置（Last）の差を transform: translate() で打ち消し（Invert）、0 へ戻す（Play）
- 時間の例：200〜350ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：位置の補間を省き、新しい並びをその場で表示する
- 技術：JavaScript（Web Animations API）
- 補足：大きさも変わる場合に scale で補うと文字や角丸がゆがむため、位置の差だけを補うか、中身に逆の scale をかけて補正する。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-sort" type="button">逆順に並べる</button>
<ul class="mo-flip"><li>1</li><li>2</li><li>3</li><li>4</li><li>5</li></ul>
```

```css
.mo-flip { display: flex; gap: 8px; padding: 0; list-style: none; }
.mo-flip li { display: grid; place-items: center; width: 48px; height: 48px; background: #dde7f3; border-radius: 6px; }
```

```js
const list = document.querySelector('.mo-flip');
const reduce = matchMedia('(prefers-reduced-motion: reduce)');
document.querySelector('.mo-sort').addEventListener('click', () => {
  const items = [...list.children];
  const first = new Map(items.map((el) => [el, el.getBoundingClientRect()])); // First
  items.reverse().forEach((el) => list.appendChild(el)); // Last：並びを変える
  if (reduce.matches) return;
  items.forEach((el) => {
    const f = first.get(el), l = el.getBoundingClientRect();
    const dx = f.left - l.left, dy = f.top - l.top; // Invert
    if (dx || dy) el.animate([{ transform: `translate(${dx}px, ${dy}px)` }, { transform: 'none' }],
      { duration: 300, easing: 'cubic-bezier(0.2, 0, 0, 1)' }); // Play
  });
});
```
