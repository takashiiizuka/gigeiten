# M-24 マイクロインタラクション（Microinteraction）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：操作への反応
- 別名：なし
- 定義：一つの小さな目的に対する操作と反応のまとまり。
- 使う場面：保存・切り替え・入力への応答。
- 注意：装飾的なアニメーションだけを指すわけではない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：NN/g — Microinteractions https://www.nngroup.com/articles/microinteractions/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）
- v1の対応項目：M-04 マイクロインタラクション（対応：一致。名称で自動照合）
  - v1の依頼例：ボタンは押下時に scale(.94)・120ms、完了で色と文言を変更。チェックはstroke-dashoffsetで線を描く。動きだけでなく文言でも状態が変わるようにして。

## 作り方（例）

- きっかけ：利用者の操作（例：お気に入りボタンを押す）
- 変える値：ボタンの状態（aria-pressed）、アイコンの色、アイコンの scale 1 → 1.25 → 1
- 時間の例：150〜250ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：拡大をやめ、色と押下状態の切り替えだけで状態を伝える
- 技術：CSS + JavaScript
- 補足：きっかけ、規則（何が変わるか）、反応、繰り返し時のふるまいをまとめて設計し、状態は色や動き以外（aria-pressed など）でも伝える。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-fav" type="button" aria-pressed="false"><span class="mo-icon" aria-hidden="true">♥</span>お気に入り</button>
```

```css
.mo-fav { display: inline-flex; gap: 6px; align-items: center; padding: 8px 14px; border: 1px solid #889; border-radius: 20px; background: #fff; font: inherit; }
.mo-icon { color: #889; transition: color 150ms; }
.mo-fav[aria-pressed="true"] .mo-icon { color: #d6336c; animation: mo-pulse 220ms cubic-bezier(0.2, 0, 0, 1); }
@keyframes mo-pulse { 50% { transform: scale(1.25); } }
@media (prefers-reduced-motion: reduce) {
  .mo-fav[aria-pressed="true"] .mo-icon { animation: none; }
}
```

```js
const fav = document.querySelector('.mo-fav');
fav.addEventListener('click', () => {
  fav.setAttribute('aria-pressed', String(fav.getAttribute('aria-pressed') !== 'true'));
});
```
