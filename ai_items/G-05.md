# G-05 ガントチャート（Gantt chart）

- 分野：関係・工程の図解／目的：手順・流れを説明する
- 別名：なし
- 定義：期間の軸に沿って作業の開始・終了を棒で示す図。
- 使う場面：予定や依存関係の管理。
- 注意：進捗率と経過時間を混同しない。
- 用意する情報（分野共通）：登場する要素、要素間の関係、順序、判断条件、担当。線や矢印に何を意味させるかを決めます。
- 早見表の分類：計画を見せたい
- 出典：ASQ — Quality tools https://asq.org/quality-resources/quality-tools
- 向いている媒体：資料・提案書（主）、スライド・講演（主）、LP・Webサイト（副）、図解・グラフ（主）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）
- v1の対応項目：D-13 ロードマップ / ガントチャート（対応：近い。ガントチャート。ロードマップはG-07）
  - v1の説明：ガントチャート は作業の開始・終了を横棒で示す工程表。 マイルストーン は期日を示す菱形の記号、 クリティカルパス は全体の期間を決める連鎖。 製品開発では、日付を約束しない Now / Next / Later 形式のロードマップも広く使われます。確定していない先の計画に具体的な日付を入れないための誠実な形式です。
  - v1の依頼例：計画はロードマップで。フェーズ帯＋マイルストーン菱形、四半期の縦グリッド。確定していない先は Now / Next / Later 表記にして日付を入れないで。
