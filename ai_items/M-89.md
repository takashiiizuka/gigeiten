# M-89 ターンテーブル（自動回転）（Turntable / auto-rotate）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：3D・カメラ
- 別名：オートローテート、360度表示
- 定義：立体を一定の速さで回し、全方向から見せる表現。
- 使う場面：製品や立体モデルの紹介。
- 注意：自動で回り続けるなら止める手段を付ける。操作で回せるとなおよい。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：model-viewer — auto-rotate https://modelviewer.dev/docs/index.html#entrydocs-stagingandcameras-attributes-autoRotate
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示されたとき自動で回り始める。ボタンで止め、ドラッグや左右の矢印キーでも回せる
- 変える値：rotateY 0 → 360deg を繰り返す（rotateX -12deg で少し上から見せる）
- 時間の例：1周 12〜20秒（例は16秒）
- 動き方の例：等速（linear）
- 動きを減らす設定のとき：自動では回さず、正面で静止する。ドラッグと矢印キーでの操作は残す
- 技術：CSS + JavaScript
- 補足：操作を始めたら自動回転を止め、利用者が見たい角度のまま止まるようにする。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-tt" tabindex="0" role="img" aria-label="製品の立体表示。左右の矢印キーで回せます">
  <div class="mo-tt-obj"><span>前</span><span>右</span><span>後</span><span>左</span></div>
</div>
<button class="mo-tt-btn" type="button">回転を止める</button>
```

```js
const stage=document.querySelector('.mo-tt'),obj=stage.querySelector('.mo-tt-obj'),btn=document.querySelector('.mo-tt-btn');
let angle=0,raf=0,prev=0,dragX=null;
const render=()=>{obj.style.transform=`rotateX(-12deg) rotateY(${angle}deg)`;};
function tick(t){ // 1周16秒
  if(prev)angle+=(t-prev)*360/16000;
  prev=t;render();raf=requestAnimationFrame(tick);
}
function setSpin(on){
  cancelAnimationFrame(raf);raf=0;prev=0;
  if(on)raf=requestAnimationFrame(tick);
  btn.textContent=on?'回転を止める':'回転を始める';
}
btn.addEventListener('click',()=>setSpin(!raf));
// 操作を始めたら自動回転を止める
stage.addEventListener('pointerdown',e=>{setSpin(false);dragX=e.clientX;stage.setPointerCapture(e.pointerId);});
stage.addEventListener('pointermove',e=>{if(dragX===null)return;angle+=(e.clientX-dragX)*.5;dragX=e.clientX;render();});
stage.addEventListener('pointerup',()=>{dragX=null;});
stage.addEventListener('keydown',e=>{
  const d={ArrowLeft:-15,ArrowRight:15}[e.key];
  if(d){e.preventDefault();setSpin(false);angle+=d;render();}
});
render();
setSpin(!matchMedia('(prefers-reduced-motion: reduce)').matches);
```
