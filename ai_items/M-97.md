# M-97 弧の軌道（Arcs）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：動きの原理
- 別名：アーク
- 定義：自然な動きは直線ではなく弧を描く、という原理。
- 使う場面：投げる・移る動き、要素の移動。
- 注意：弧の大きさで印象が変わる。画面の他の動きと向きをそろえる。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Adobe — 12 Principles of Animation https://www.adobe.com/creativecloud/animation/discover/principles-of-animation.html
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：要素を別の場所へ移すとき（商品をカートに入れる）
- 変える値：横の translateX 0 → 250px と、縦の translateY 0 → -80px → 0 を入れ子の要素で同時に動かし、軌道を弧にする
- 時間の例：500〜800ms（例は650ms）
- 動き方の例：横は等速（linear）、縦は上昇 ease-out・下降 ease-in
- 動きを減らす設定のとき：弧の移動を省き、カートの数だけを更新する
- 技術：JavaScript（Web Animations API）
- 補足：横と縦を入れ子の要素に分けると、それぞれに別の速さの変化を付けられる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-arc">
  <div class="mo-arc-x"><div class="mo-arc-y"></div></div>
  <div class="mo-arc-cart">カート <b>0</b></div>
</div>
<button class="mo-arc-go" type="button">カートに入れる</button>
```

```css
.mo-arc{position:relative;width:340px;height:140px;border-bottom:1px solid #cbd5e1}
.mo-arc-x{position:absolute;left:16px;bottom:12px}
.mo-arc-y{width:24px;height:24px;border-radius:50%;background:#f97316}
.mo-arc-cart{position:absolute;right:8px;bottom:8px;padding:6px 10px;border:1px solid #94a3b8;border-radius:6px;font-size:14px}
```

```js
const x=document.querySelector('.mo-arc-x'),y=x.querySelector('.mo-arc-y'),count=document.querySelector('.mo-arc-cart b');
const add=()=>{count.textContent=Number(count.textContent)+1;};
document.querySelector('.mo-arc-go').addEventListener('click',()=>{
  if(matchMedia('(prefers-reduced-motion: reduce)').matches)return add(); // 弧を省き、数だけ更新する
  // 横は等速、縦は上がって下がる。2つを重ねると軌道が弧になる
  x.animate({transform:['translateX(0)','translateX(250px)']},{duration:650,easing:'linear'});
  y.animate([{transform:'translateY(0)',easing:'ease-out'},{transform:'translateY(-80px)',easing:'ease-in'},{transform:'translateY(0)'}],{duration:650})
    .finished.then(add);
});
```
