# M-62 共有軸の遷移（Shared axis）

- 分野：動き・モーション／目的：手順・流れを説明する
- 動きの分類：画面の転換
- 別名：シェアードアクシス
- 定義：前後の関係がある画面を、同じ軸の上で押し出すように切り替える遷移。
- 使う場面：手順の前後、タブの左右の移動。
- 注意：軸の向き（左右・上下・奥行き）を画面の関係と一致させる。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Google Material Design (M2) — The motion system https://m2.material.io/design/motion/the-motion-system.html
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：「進む」「戻る」ボタンを押したとき
- 変える値：前の画面の translateX 0 → -30px と opacity 1 → 0、次の画面の translateX 30px → 0 と opacity 0 → 1（戻るときは符号を逆にする）
- 時間の例：300ms（前の画面は最初の30%で消え、次の画面は30%以降に現れる）
- 動き方の例：標準（cubic-bezier(0.4, 0, 0.2, 1)）
- 動きを減らす設定のとき：横の移動を省き、即時（または短いクロスフェード）で切り替える
- 技術：JavaScript（Web Animations API）
- 補足：上下の関係なら translateY、親子の関係なら scale を軸にし、同じ画面群では同じ軸を使い続ける。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-axis">
  <section class="mo-axis-page">手順1</section>
  <section class="mo-axis-page" hidden>手順2</section>
  <section class="mo-axis-page" hidden>手順3</section>
</div>
<button type="button" class="mo-axis-btn" data-dir="-1">戻る</button>
<button type="button" class="mo-axis-btn" data-dir="1">進む</button>
```

```css
.mo-axis { position: relative; width: 360px; height: 200px; overflow: hidden; }
.mo-axis-page { position: absolute; inset: 0; display: grid; place-items: center; font: 700 28px sans-serif; background: #f1f5f9; }
.mo-axis-page[hidden] { display: none; }
```

```js
const pages = [...document.querySelectorAll('.mo-axis-page')];
let cur = 0, busy = false;
document.querySelectorAll('.mo-axis-btn').forEach((btn) => btn.addEventListener('click', () => {
  const dir = Number(btn.dataset.dir), next = cur + dir;
  if (busy || next < 0 || next >= pages.length) return;
  const from = pages[cur], to = pages[next];
  cur = next;
  to.hidden = false;
  if (matchMedia('(prefers-reduced-motion: reduce)').matches) { from.hidden = true; return; }
  busy = true;
  const opt = { duration: 300, easing: 'cubic-bezier(0.4, 0, 0.2, 1)' };
  const out = from.animate([
    { transform: 'none', opacity: 1 }, { opacity: 0, offset: 0.3 }, { transform: `translateX(${-30 * dir}px)`, opacity: 0 }
  ], { ...opt, fill: 'forwards' });
  to.animate([
    { transform: `translateX(${30 * dir}px)`, opacity: 0 }, { opacity: 0, offset: 0.3 }, { transform: 'none', opacity: 1 }
  ], opt);
  out.onfinish = () => { from.hidden = true; out.cancel(); busy = false; };
}));
```
