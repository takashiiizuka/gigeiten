# M-48 バースト（弾ける粒子）（Particle burst）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：粒子・生成
- 別名：いいねの弾け、エクスプロージョン
- 定義：押した瞬間に、中心から粒子が弾けて消える表現。
- 使う場面：いいね、お気に入り、完了などの短い反応。
- 注意：0.5秒前後で終える。毎回の操作に付けると煩わしい。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：mo.js — Burst https://mojs.github.io/tutorials/burst/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：ボタンを押して「オン」にしたとき（オフに戻すときは出さない）
- 変える値：10個の粒子の translate 0 → 外側へ半径28〜40px、scale 1 → 0.8 → 0、opacity 1 → 1 → 0（外側に届いてから小さくなって消える）
- 時間の例：500ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：粒子を出さず、ボタンの色と押された状態の表示だけを変える
- 技術：JavaScript（Web Animations API）
- 補足：粒子には pointer-events: none を付け、動きが終わったら要素を取り除く。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button type="button" class="mo-like" aria-pressed="false">いいね</button>
```

```css
.mo-like { position: relative; padding: 8px 16px; border: 1px solid #e11d48; border-radius: 999px; background: #fff; color: #be123c; }
.mo-like[aria-pressed="true"] { background: #e11d48; color: #fff; }
.mo-spark {
  position: absolute; left: 50%; top: 50%; width: 8px; height: 8px; margin: -4px;
  border-radius: 50%; background: #e11d48; pointer-events: none;
}
```

```js
const btn = document.querySelector('.mo-like');
btn.addEventListener('click', () => {
  const on = btn.getAttribute('aria-pressed') !== 'true';
  btn.setAttribute('aria-pressed', on);
  if (!on || matchMedia('(prefers-reduced-motion: reduce)').matches) return;
  for (let i = 0; i < 10; i++) {
    const s = document.createElement('span');
    s.className = 'mo-spark';
    s.setAttribute('aria-hidden', 'true');
    btn.append(s);
    const a = (i / 10) * Math.PI * 2, r = 28 + Math.random() * 12, x = Math.cos(a) * r, y = Math.sin(a) * r;
    s.animate([
      { transform: 'translate(0, 0) scale(1)', opacity: 1 },
      { transform: `translate(${x}px, ${y}px) scale(0.8)`, opacity: 1, offset: 0.7 },
      { transform: `translate(${x * 1.15}px, ${y * 1.15}px) scale(0)`, opacity: 0 }
    ], { duration: 500, easing: 'cubic-bezier(0.2, 0, 0, 1)' }).onfinish = () => s.remove();
  }
});
```
