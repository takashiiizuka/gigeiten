# M-86 ケン・バーンズ効果（Ken Burns effect）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：3D・カメラ
- 別名：パン・ズーム、スライドショー
- 定義：静止画を、ゆっくり拡大・移動させて動きを与える表現。
- 使う場面：写真を使った映像、スライドショー、記録映像。
- 注意：拡大で画像が粗くならないか確認する。人物の顔を切らない位置に動かす。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Apple Support — Add the Ken Burns effect in iMovie on Mac https://support.apple.com/guide/imovie/add-the-ken-burns-effect-movc6e02f503/mac
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：写真が表示されたとき（スライドショーの各コマ）
- 変える値：scale 1 → 1.15 と translate 0 → (-3%, -2%)
- 時間の例：1コマ 6〜10秒
- 動き方の例：等速（linear）
- 動きを減らす設定のとき：動かさず、写真を静止表示する
- 技術：CSS + JavaScript
- 補足：transform-origin を顔や主題の位置に合わせ、拡大の終わりでも主題が枠から切れないようにする。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<figure class="mo-kb">
  <div class="mo-kb-photo" role="img" aria-label="夕方の海辺の写真"></div>
</figure>
<button class="mo-kb-btn" type="button">動きを止める</button>
```

```css
.mo-kb{width:360px;aspect-ratio:3/2;margin:0;overflow:hidden;border-radius:8px}
/* 実際は img に object-fit: cover を指定して同じ animation を付ける */
.mo-kb-photo{width:100%;height:100%;background:radial-gradient(circle at 38% 38%,#fde68a 0 9%,transparent 10%),linear-gradient(#fb923c,#7c3aed 58%,#1e3a8a 58%);transform-origin:40% 40%;animation:mo-kb 8s linear both}
.mo-kb.is-paused .mo-kb-photo{animation-play-state:paused}
@keyframes mo-kb{from{transform:scale(1) translate(0,0)}to{transform:scale(1.15) translate(-3%,-2%)}}
@media (prefers-reduced-motion:reduce){.mo-kb-photo{animation:none}.mo-kb-btn{display:none}}
```

```js
const kb=document.querySelector('.mo-kb'),btn=document.querySelector('.mo-kb-btn');
btn.addEventListener('click',()=>{
  const paused=kb.classList.toggle('is-paused');
  btn.textContent=paused?'動きを再開する':'動きを止める';
});
kb.addEventListener('animationend',()=>{btn.hidden=true;}); // 8秒で止まったらボタンを隠す
```
