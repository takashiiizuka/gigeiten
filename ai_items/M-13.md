# M-13 スプリング（Spring animation）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：動きの原理
- 別名：なし
- 定義：ばねの応答を模した動き。減衰などで挙動が変わる。
- 使う場面：直接操作に対する応答。
- 注意：全てのスプリングが同じ時間で止まるわけではない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Motion — Transitions https://motion.dev/docs/animate#spring
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）
- v1の対応項目：M-03 オーバーシュート / スプリング（対応：近い。v1は複数の概念を1項目にまとめていた）
  - v1の説明：目標位置をわずかに 行き過ぎてから戻る 動き。物理的な弾みを模したもので、 楽しさ・軽さ が出ます。 cubic-bezier の第2値を1より大きくすると作れます（例： .34, 1.56, .64, 1 ）。 使いどころ：トグルのつまみ、チェックの出現、成功の通知。 業務システムの画面遷移や、金額を扱う操作では避ける ——ふざけて見えるうえ、繰り返すと鬱陶しくなります。
  - v1の依頼例：トグルとチェックの出現だけ軽いオーバーシュート（cubic-bezier(.34,1.4,.64,1)）を入れて。それ以外は素直なease-outで。

## 作り方（例）

- きっかけ：ドラッグを離したときやスイッチを押したときなど、直接操作の直後
- 変える値：位置（translateX）を、ばねの式で目標値へ近づける
- 時間の例：時間は指定せず、剛性・減衰・質量から結果として決まる（例：剛性 180、減衰 12、質量 1、移動量 200px で約 0.9 秒）
- 動き方の例：ばねの運動方程式で決める（減衰を小さくすると揺れが増え、止まるまでの時間も延びる）
- 動きを減らす設定のとき：揺れをやめ、目標の位置にその場で移す（短い減速の移動に置き換える方法もある）
- 技術：JavaScript（Web Animations API）
- 補足：CSS だけで使う場合は、同じ計算結果を linear() の点列に変換してイージングとして指定する方法もある。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-go" type="button">移動する</button> <output class="mo-time"></output>
<div class="mo-ball"></div>
```

```css
.mo-ball { width: 40px; height: 40px; margin-top: 12px; border-radius: 50%; background: #2b6cb0; }
```

```js
const ball = document.querySelector('.mo-ball');
const time = document.querySelector('.mo-time');
const reduce = matchMedia('(prefers-reduced-motion: reduce)');
let pos = 0;
// ばねの式を 1/60 秒ごとに計算し、キーフレームの列にする
function springFrames(from, to, k = 180, c = 12, m = 1) {
  let x = from, v = 0;
  const frames = [];
  for (let i = 0; i < 600; i++) {
    v += ((-k * (x - to) - c * v) / m) / 60;
    x += v / 60;
    frames.push({ transform: `translateX(${x}px)` });
    if (Math.abs(x - to) < 0.5 && Math.abs(v) < 5) break;
  }
  frames.push({ transform: `translateX(${to}px)` });
  return frames;
}
document.querySelector('.mo-go').addEventListener('click', () => {
  const to = pos === 0 ? 200 : 0;
  ball.style.transform = `translateX(${to}px)`;
  if (!reduce.matches) {
    const frames = springFrames(pos, to);
    const ms = Math.round((frames.length - 1) * 1000 / 60);
    ball.animate(frames, { duration: ms });
    time.textContent = `止まるまで ${ms}ms`;
  }
  pos = to;
});
```
