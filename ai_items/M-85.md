# M-85 フィルムグレイン（Film grain）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：質感・効果
- 別名：ノイズ、粒子感
- 定義：細かな粒を毎コマ変えて重ね、フィルムのような質感を足す表現。
- 使う場面：写真・映像の質感づくり、平坦な色面の補い。
- 注意：粒が強いと文字や細部が読みにくい。圧縮で粒が崩れないか確認する。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Adobe — Apply Noise and Grain effects in After Effects https://helpx.adobe.com/after-effects/desktop/apply-effects-and-animation-presets/list-of-effects/noise-grain-effects.html#add_grain_effect
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示されている間（背景の質感として）
- 変える値：Canvas に描いた灰色の粒を毎コマ描き直し、不透明度 0.08〜0.12 で重ねる
- 時間の例：1秒に 8〜12コマ
- 動き方の例：なし（コマごとに切り替える）
- 動きを減らす設定のとき：粒を1枚だけ描いて静止させる
- 技術：Canvas 2D
- 補足：5秒を超えて動き続けるため止めるボタンを付け、文字は粒より手前に置く。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-film">
  <canvas class="mo-grain" aria-hidden="true"></canvas>
  <h2 class="mo-film-title">フィルムの質感</h2>
</div>
<button class="mo-grain-btn" type="button">粒の動きを止める</button>
```

```css
.mo-film{position:relative;overflow:hidden;padding:64px 24px;background:#d6c7a8;color:#2b2118}
.mo-grain{position:absolute;inset:0;width:100%;height:100%;opacity:.12;pointer-events:none}
.mo-film-title{position:relative;margin:0}
```

```js
const cv=document.querySelector('.mo-grain'),ctx=cv.getContext('2d');
const btn=document.querySelector('.mo-grain-btn');
const reduce=matchMedia('(prefers-reduced-motion: reduce)').matches;
// 表示サイズの半分で描いて引き伸ばすと、粒が2px程度になる
cv.width=Math.max(1,cv.clientWidth/2|0);cv.height=Math.max(1,cv.clientHeight/2|0);
const img=ctx.createImageData(cv.width,cv.height);
function draw(){
  const d=img.data;
  for(let i=0;i<d.length;i+=4){d[i]=d[i+1]=d[i+2]=Math.random()*255|0;d[i+3]=255;}
  ctx.putImageData(img,0,0);
}
let timer=0;
function setPlaying(on){
  clearInterval(timer);
  timer=on?setInterval(draw,100):0; // 1秒に10コマ
  btn.textContent=on?'粒の動きを止める':'粒の動きを再開する';
}
draw();
if(reduce)btn.hidden=true;else setPlaying(true);
btn.addEventListener('click',()=>setPlaying(!timer));
```
