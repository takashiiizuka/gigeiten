# M-96 フォロースルー（Follow-through）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：動きの原理
- 別名：オーバーラッピングアクション、遅れ
- 定義：本体が止まっても、ついてくる部分は遅れて動き、揺れて止まる原理。
- 使う場面：複数の要素がまとまって動く場面、柔らかい物の動き。
- 注意：揺れが長いと落ち着かない。止まるまでの時間を短く保つ。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Adobe — 12 Principles of Animation https://www.adobe.com/creativecloud/animation/discover/principles-of-animation.html
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：本体が移動して止まったとき
- 変える値：本体は translateX 0 → 220px。付属の部分は rotate で、動き出しに後ろへ 14deg 遅れ、止まった後に前へ 18deg 振れ、7deg、2deg と揺れて 0deg で止まる
- 時間の例：本体 400ms、付属の揺れは全体 900ms
- 動き方の例：本体は減速（cubic-bezier(0.2, 0, 0, 1)）、揺れは ease-in-out
- 動きを減らす設定のとき：揺れを省き、本体と付属の位置だけを変える
- 技術：JavaScript（Web Animations API）
- 補足：揺れの往復は2〜3回までにし、本体が止まってから0.5秒程度で収める。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-ft"><div class="mo-ft-body"><span class="mo-ft-tag"></span></div></div>
<button class="mo-ft-go" type="button">動かす</button>
```

```css
.mo-ft{width:320px;height:130px}
.mo-ft-body{position:relative;width:80px;height:56px;border-radius:8px;background:#2563eb}
.mo-ft-tag{position:absolute;top:100%;left:34px;width:12px;height:44px;border-radius:0 0 6px 6px;background:#f59e0b;transform-origin:50% 0}
```

```js
const body=document.querySelector('.mo-ft-body'),tag=body.querySelector('.mo-ft-tag');let x=0;
document.querySelector('.mo-ft-go').addEventListener('click',()=>{
  const from=x,dir=x?-1:1;x=x?0:220;
  body.style.transform=`translateX(${x}px)`;
  if(matchMedia('(prefers-reduced-motion: reduce)').matches)return; // 位置だけを変える
  body.animate({transform:[`translateX(${from}px)`,`translateX(${x}px)`]},{duration:400,easing:'cubic-bezier(.2,0,0,1)'});
  // 付属の部分：動き出しで後ろへ遅れ、本体が止まった後に前へ振れてから収まる
  tag.animate({rotate:['0deg',`${dir*14}deg`,`${-dir*18}deg`,`${dir*7}deg`,`${-dir*2}deg`,'0deg'],offset:[0,.2,.5,.7,.85,1],easing:'ease-in-out'},{duration:900});
});
```
