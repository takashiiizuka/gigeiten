# M-76 アイコンの切り替え（Icon transition）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：操作への反応
- 別名：アイコンモーフ、アニメーションアイコン
- 定義：状態が変わったことを、アイコンの形の変化で示す表現（メニュー⇔閉じる、再生⇔一時停止）。
- 使う場面：開閉・再生などの切り替えボタン。
- 注意：形の変化だけに頼らず、ラベルや読み上げ名も切り替える。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Apple Developer — SF Symbols https://developer.apple.com/sf-symbols/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：開閉ボタンを押したとき（クリック、タップ、Enter、Space）
- 変える値：3本線の上下の線を translateY ±6px と rotate ±45deg、中央の線を opacity 1 → 0
- 時間の例：200〜300ms
- 動き方の例：標準（cubic-bezier(0.4, 0, 0.2, 1)）
- 動きを減らす設定のとき：途中の変形を省き、3本線と×を即時に切り替える
- 技術：CSS + JavaScript
- 補足：開閉は aria-expanded で状態を伝え、再生⇔一時停止のように働きが変わるボタンでは aria-label を切り替える。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-menu" type="button" aria-expanded="false" aria-controls="mo-nav" aria-label="メニュー">
  <span></span><span></span><span></span>
</button>
<nav id="mo-nav" hidden><a href="#">ホーム</a>　<a href="#">製品</a></nav>
```

```css
.mo-menu{display:grid;gap:4px;place-content:center;width:44px;height:44px;border:0;border-radius:8px;background:#f1f5f9;cursor:pointer}
.mo-menu span{display:block;width:22px;height:2px;background:#111827;transition:transform 250ms cubic-bezier(.4,0,.2,1),opacity 150ms}
.mo-menu[aria-expanded="true"] span:nth-child(1){transform:translateY(6px) rotate(45deg)}
.mo-menu[aria-expanded="true"] span:nth-child(2){opacity:0}
.mo-menu[aria-expanded="true"] span:nth-child(3){transform:translateY(-6px) rotate(-45deg)}
@media (prefers-reduced-motion:reduce){.mo-menu span{transition:none}}
```

```js
const btn=document.querySelector('.mo-menu'),nav=document.getElementById('mo-nav');
btn.addEventListener('click',()=>{
  const open=btn.getAttribute('aria-expanded')!=='true';
  btn.setAttribute('aria-expanded',String(open)); // 読み上げでは開閉の状態として伝わる
  nav.hidden=!open;
});
```
