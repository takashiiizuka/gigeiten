# M-14 オーバーシュート（Overshoot）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：動きの原理
- 別名：なし
- 定義：目標値を一度越えてから落ち着く動き。
- 使う場面：弾力感のある短い応答。
- 注意：位置や数値の最終値を誤認させない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — Easing functions https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/easing-function
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：スイッチの切り替えなど、操作に対する短い応答
- 変える値：つまみの位置 translateX(0) → translateX(20px)。途中で目標値をわずかに越えてから戻る
- 時間の例：250〜400ms
- 動き方の例：cubic-bezier(0.34, 1.56, 0.64, 1)（1つ目の制御点の y を 1 より大きくして行き過ぎを作る）
- 動きを減らす設定のとき：行き過ぎをなくし、減速のイージングで目標値に止める
- 技術：CSS
- 補足：行き過ぎの量は小さく抑え、数値やグラフの値など、最終値を読ませる要素には使わない。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<label class="mo-toggle"><input type="checkbox"><span class="mo-track"><span class="mo-thumb"></span></span>通知</label>
```

```css
.mo-toggle { display: inline-flex; gap: 8px; align-items: center; }
.mo-toggle input { position: absolute; opacity: 0; }
.mo-track { box-sizing: border-box; width: 48px; height: 28px; padding: 3px; border-radius: 14px; background: #767676; }
.mo-thumb { display: block; width: 22px; height: 22px; border-radius: 50%; background: #fff;
  transition: transform 350ms cubic-bezier(0.34, 1.56, 0.64, 1); }
input:checked + .mo-track { background: #2b6cb0; }
input:checked + .mo-track .mo-thumb { transform: translateX(20px); }
input:focus-visible + .mo-track { outline: 2px solid #2b6cb0; outline-offset: 2px; }
@media (prefers-reduced-motion: reduce) {
  .mo-thumb { transition: transform 150ms cubic-bezier(0.2, 0, 0, 1); }
}
```
