# M-63 フェードスルー（Fade through）

- 分野：動き・モーション／目的：手順・流れを説明する
- 動きの分類：画面の転換
- 別名：フェードスルー遷移
- 定義：前の画面が消えきってから、次の画面が少し拡大しながら現れる遷移。
- 使う場面：関係の薄い画面どうしの切り替え（下部タブなど）。
- 注意：つながりを示したい画面には、共有要素の遷移を使う。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Google Material Design (M2) — The motion system https://m2.material.io/design/motion/the-motion-system.html
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：下部タブなど、関係の薄い画面へ移るとき
- 変える値：前の画面の opacity 1 → 0。消えきってから、次の画面の opacity 0 → 1 と scale 0.92 → 1
- 時間の例：前の画面90ms、次の画面210ms（前の画面が消えてから開始）、全体300ms
- 動き方の例：前の画面は加速（cubic-bezier(0.4, 0, 1, 1)）、次の画面は減速（cubic-bezier(0, 0, 0.2, 1)）
- 動きを減らす設定のとき：拡大を省き、不透明度だけで切り替える
- 技術：JavaScript（Web Animations API）
- 補足：前の画面が消えきってから次を出すため、2つの画面が重なって見える時間がない。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-ft">
  <section class="mo-ft-page">ホーム</section>
  <section class="mo-ft-page" hidden>検索</section>
  <section class="mo-ft-page" hidden>設定</section>
</div>
<nav class="mo-ft-tabs">
  <button type="button" aria-current="page">ホーム</button><button type="button">検索</button><button type="button">設定</button>
</nav>
```

```css
.mo-ft { position: relative; width: 360px; height: 200px; overflow: hidden; }
.mo-ft-page { position: absolute; inset: 0; display: grid; place-items: center; font: 700 28px sans-serif; background: #f1f5f9; }
.mo-ft-page[hidden] { display: none; }
.mo-ft-tabs [aria-current] { font-weight: 700; text-decoration: underline; }
```

```js
const pages = [...document.querySelectorAll('.mo-ft-page')];
const tabs = [...document.querySelectorAll('.mo-ft-tabs button')];
let cur = 0;
tabs.forEach((tab, i) => tab.addEventListener('click', () => {
  if (i === cur) return;
  const from = pages[cur], to = pages[i];
  tabs[cur].removeAttribute('aria-current');
  tab.setAttribute('aria-current', 'page');
  cur = i;
  pages.forEach((p) => { p.getAnimations().forEach((a) => a.cancel()); p.hidden = p !== from && p !== to; });
  const reduce = matchMedia('(prefers-reduced-motion: reduce)').matches;
  const out = from.animate([{ opacity: 1 }, { opacity: 0 }],
    { duration: 90, easing: 'cubic-bezier(0.4, 0, 1, 1)', fill: 'forwards' });
  out.onfinish = () => { from.hidden = true; out.cancel(); };
  to.animate([{ opacity: 0, transform: `scale(${reduce ? 1 : 0.92})` }, { opacity: 1, transform: 'scale(1)' }],
    { duration: 210, delay: 90, easing: 'cubic-bezier(0, 0, 0.2, 1)', fill: 'backwards' });
}));
```
