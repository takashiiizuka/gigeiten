# M-68 リップル（Ripple）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：操作への反応
- 別名：インクリップル、タッチフィードバック
- 定義：触れた位置から波紋が広がり、押したことを伝える反応。
- 使う場面：ボタン、リスト項目、カードなどの押下。
- 注意：波紋が文字の読みやすさを下げない濃さにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Google Material Design 3 — States: Applying states https://m3.material.io/foundations/interaction/states/applying-states
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：ボタンを押したとき（クリック、タップ、Enter、Space）
- 変える値：押した位置を中心に、波紋の円の scale 0 → 1 と opacity 0.35 → 0
- 時間の例：450〜600ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：波紋を出さず、押した状態の背景色だけを変える
- 技術：CSS + JavaScript
- 補足：キーボードで押したときは位置の情報がないため、ボタンの中央から広げる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-ripple" type="button">保存する</button>
```

```css
.mo-ripple{position:relative;overflow:hidden;padding:12px 24px;border:0;border-radius:8px;background:#2563eb;color:#fff;font:inherit;cursor:pointer}
.mo-ripple:active{background:#1d4ed8}
.mo-ripple-wave{position:absolute;border-radius:50%;background:#fff;opacity:.35;transform:scale(0);pointer-events:none;animation:mo-ripple 550ms cubic-bezier(.2,0,0,1) forwards}
@keyframes mo-ripple{to{transform:scale(1);opacity:0}}
```

```js
const reduce=matchMedia('(prefers-reduced-motion: reduce)');
document.querySelectorAll('.mo-ripple').forEach(btn=>{
  btn.addEventListener('click',e=>{
    if(reduce.matches)return; // 押した状態の色（:active）だけにする
    const r=btn.getBoundingClientRect(),size=Math.hypot(r.width,r.height)*2;
    // キーボードで押したとき（e.detail が 0）は中央から広げる
    const x=e.detail?e.clientX-r.left:r.width/2,y=e.detail?e.clientY-r.top:r.height/2;
    const wave=document.createElement('span');
    wave.className='mo-ripple-wave';
    wave.style.cssText=`width:${size}px;height:${size}px;left:${x-size/2}px;top:${y-size/2}px`;
    btn.append(wave);
    wave.addEventListener('animationend',()=>wave.remove());
  });
});
```
