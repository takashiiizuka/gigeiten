# M-27 退場トランジション（Exit transition）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：出現・退場
- 別名：なし
- 定義：要素がなくなる過程を動きでつなぐ表現。
- 使う場面：削除やパネルを閉じる操作。
- 注意：アニメーション中の二重操作やフォーカス喪失を防ぐ。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：IBM Carbon — Motion https://carbondesignsystem.com/elements/motion/overview/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：削除やパネルを閉じる操作をしたとき
- 変える値：opacity 1 → 0 と高さ（実寸 → 0）を同時に変え、後続の項目を詰める
- 時間の例：150〜250ms（登場より短め）
- 動き方の例：加速（cubic-bezier(0.3, 0, 1, 1)）
- 動きを減らす設定のとき：アニメーションを省き、すぐに取り除いてフォーカスを移す
- 技術：JavaScript（Web Animations API）
- 補足：退場中の要素は inert などで操作を受け付けないようにし、取り除いた後のフォーカスの移動先を決めておく。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<ul class="mo-todo" tabindex="-1" aria-label="やること">
  <li>請求書を送る <button type="button">削除</button></li>
  <li>在庫を確認する <button type="button">削除</button></li>
  <li>会議を設定する <button type="button">削除</button></li>
</ul>
```

```css
.mo-todo { width: 300px; padding: 0; list-style: none; }
.mo-todo li { display: flex; justify-content: space-between; align-items: center; height: 40px; overflow: hidden; }
```

```js
const reduce = matchMedia('(prefers-reduced-motion: reduce)');
const todo = document.querySelector('.mo-todo');
todo.addEventListener('click', async (e) => {
  const btn = e.target.closest('button');
  if (!btn) return;
  const li = btn.closest('li');
  const next = li.nextElementSibling || li.previousElementSibling;
  li.inert = true; // 退場中の二重操作を防ぐ
  if (!reduce.matches) {
    await li.animate([{ opacity: 1, height: `${li.offsetHeight}px` }, { opacity: 0, height: '0px' }],
      { duration: 200, easing: 'cubic-bezier(0.3, 0, 1, 1)' }).finished;
  }
  li.remove();
  (next ? next.querySelector('button') : todo).focus(); // フォーカスの行き先を決めておく
});
```
