# M-71 3Dチルト（Perspective tilt）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：操作への反応
- 別名：チルト、パララックスカード
- 定義：ポインターの位置に合わせて、カードを立体的に傾ける反応。
- 使う場面：商品カード、作品の一覧。
- 注意：傾きは小さく。タッチ操作や動きを減らす設定では止める。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：vanilla-tilt.js — A smooth 3D tilt javascript library https://micku7zu.github.io/vanilla-tilt.js/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：ポインターがカードの上を動いたとき
- 変える値：transform: perspective(800px) の rotateX / rotateY を、ポインターの位置に比例して ±6deg。離れたら 0deg に戻す
- 時間の例：追従 100〜150ms、戻り 300〜400ms
- 動き方の例：追従は ease-out、戻りは減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：傾けず、影の濃さの変化だけにする
- 技術：CSS + JavaScript
- 補足：傾きの有無にかかわらず、フォーカスでもホバーと同じ影を付け、キーボード操作でも選択中が分かるようにする。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<a class="mo-tilt" href="#">商品名<br>¥3,300</a>
```

```css
.mo-tilt{display:block;width:220px;margin:40px;padding:24px;border-radius:12px;background:#fff;color:#111827;text-decoration:none;box-shadow:0 2px 6px rgb(0 0 0/.15);transition:transform 350ms cubic-bezier(.2,0,0,1),box-shadow 200ms}
.mo-tilt:hover,.mo-tilt:focus-visible{box-shadow:0 12px 24px rgb(0 0 0/.22)}
```

```js
const card=document.querySelector('.mo-tilt');
const ok=matchMedia('(hover: hover) and (pointer: fine)').matches&&!matchMedia('(prefers-reduced-motion: reduce)').matches;
if(ok){
  card.addEventListener('pointermove',e=>{
    const r=card.getBoundingClientRect();
    const px=(e.clientX-r.left)/r.width-.5,py=(e.clientY-r.top)/r.height-.5; // -0.5〜0.5
    card.style.transition='transform 120ms ease-out,box-shadow 200ms';
    card.style.transform=`perspective(800px) rotateX(${-py*12}deg) rotateY(${px*12}deg)`;
  });
  card.addEventListener('pointerleave',()=>{card.style.transition='';card.style.transform='';});
}
```
