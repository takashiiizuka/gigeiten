# M-49 紙吹雪（Confetti）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：粒子・生成
- 別名：コンフェッティ、お祝い
- 定義：紙片が舞い上がり、回りながら落ちる表現。
- 使う場面：達成、購入完了、お祝いの画面。
- 注意：一度きりにする。操作の邪魔にならないよう、手前の要素を押せる状態に保つ。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：GitHub — catdad/canvas-confetti https://github.com/catdad/canvas-confetti
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：完了の操作をしたとき（1回だけ）
- 変える値：紙片120枚の位置（下の中央から打ち上げ、重力で落ちる）、回転、裏返り（縦方向の scale）、最後に opacity 1 → 0
- 時間の例：全体3秒（最後の500msで消える）
- 動き方の例：物理的な動き（重力 0.35px/フレーム²、落下速度の上限 4px/フレーム、横方向の減衰 0.99）
- 動きを減らす設定のとき：紙吹雪を出さず、完了のメッセージだけを表示する
- 技術：Canvas 2D
- 補足：重ねる canvas は pointer-events: none にして、下にあるボタンやリンクを押せる状態に保つ。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button type="button" class="mo-confetti-go">完了にする</button>
<p class="mo-done" role="status"></p>
<canvas class="mo-confetti" aria-hidden="true"></canvas>
```

```css
.mo-confetti { position: fixed; inset: 0; width: 100%; height: 100%; pointer-events: none; }
```

```js
const cv = document.querySelector('.mo-confetti'), ctx = cv.getContext('2d');
const colors = ['#ef4444', '#f59e0b', '#10b981', '#3b82f6', '#8b5cf6'];
function confetti() {
  const W = (cv.width = innerWidth), H = (cv.height = innerHeight);
  const ps = Array.from({ length: 120 }, () => ({
    x: W / 2, y: H, vx: (Math.random() - 0.5) * 14, vy: -(10 + Math.random() * 10),
    r: Math.random() * 6, vr: (Math.random() - 0.5) * 0.3, w: 6 + Math.random() * 6,
    c: colors[Math.floor(Math.random() * colors.length)]
  }));
  let t0, last;
  const loop = (now) => {
    t0 ??= now;
    const dt = Math.min(32, now - (last ?? now)) / 16.7, t = now - t0; // dt：60fps を1とした経過
    last = now;
    ctx.clearRect(0, 0, W, H);
    ctx.globalAlpha = Math.max(0, Math.min(1, (3000 - t) / 500)); // 最後の0.5秒で薄くする
    for (const p of ps) {
      p.vy = Math.min(p.vy + 0.35 * dt, 4); p.vx *= 0.99;
      p.x += p.vx * dt; p.y += p.vy * dt; p.r += p.vr * dt;
      ctx.save(); ctx.translate(p.x, p.y); ctx.rotate(p.r); ctx.scale(1, Math.cos(p.r * 2)); // 裏返り
      ctx.fillStyle = p.c; ctx.fillRect(-p.w / 2, -p.w / 4, p.w, p.w / 2); ctx.restore();
    }
    if (t < 3000) requestAnimationFrame(loop); else ctx.clearRect(0, 0, W, H);
  };
  requestAnimationFrame(loop);
}
document.querySelector('.mo-confetti-go').addEventListener('click', () => {
  document.querySelector('.mo-done').textContent = '完了しました';
  if (!matchMedia('(prefers-reduced-motion: reduce)').matches) confetti();
}, { once: true });
```
