# M-43 軌道運動（Orbit）

- 分野：動き・モーション／目的：構成・関係を整理する
- 動きの分類：線・図形
- 別名：周回、公転
- 定義：中心のまわりを、一定の軌道で回り続ける動き。
- 使う場面：中心と周辺の関係、エコシステムの説明。
- 注意：回り続ける要素は注意を引き続ける。止める手段を用意する。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：GSAP — MotionPath https://gsap.com/docs/v3/Plugins/MotionPathPlugin/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示と同時（停止ボタンで止まる）
- 変える値：腕の要素の rotate 0 → 360deg を繰り返し、衛星には逆向きの回転を付けて文字の向きを保つ
- 時間の例：1周12秒（2つの衛星は半周ずらして配置）
- 動き方の例：等速（linear）
- 動きを減らす設定のとき：回転させず、軌道上の位置に静止して配置する
- 技術：CSS + JavaScript
- 補足：周回する要素を増やすときは、--a に「360deg ÷ 個数」ずつずらした角度を指定する。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-orbit">
  <div class="mo-core"></div>
  <div class="mo-arm" style="--a: 0deg"><span class="mo-sat">A</span></div>
  <div class="mo-arm" style="--a: 180deg"><span class="mo-sat">B</span></div>
</div>
<button type="button" class="mo-orbit-toggle">回転を止める</button>
```

```css
.mo-orbit { position: relative; width: 200px; height: 200px; margin: 24px; border: 1px dashed #94a3b8; border-radius: 50%; }
.mo-core { position: absolute; inset: 75px; border-radius: 50%; background: #1e3a8a; }
.mo-arm { position: absolute; inset: 0; transform: rotate(var(--a)); animation: mo-spin 12s linear infinite; }
.mo-sat {
  position: absolute; top: -16px; left: 84px; width: 32px; height: 32px; border-radius: 50%;
  display: grid; place-items: center; background: #f59e0b; font: 600 14px sans-serif;
  transform: rotate(calc(var(--a) * -1)); animation: mo-keep 12s linear infinite;
}
.mo-orbit.mo-paused .mo-arm, .mo-orbit.mo-paused .mo-sat { animation-play-state: paused; }
@keyframes mo-spin { from { transform: rotate(var(--a)); } to { transform: rotate(calc(var(--a) + 360deg)); } }
@keyframes mo-keep { from { transform: rotate(calc(var(--a) * -1)); } to { transform: rotate(calc(var(--a) * -1 - 360deg)); } }
@media (prefers-reduced-motion: reduce) {
  .mo-arm, .mo-sat { animation: none; }
  .mo-orbit-toggle { display: none; }
}
```

```js
const orbit = document.querySelector('.mo-orbit');
const btn = document.querySelector('.mo-orbit-toggle');
btn.addEventListener('click', () => {
  const paused = orbit.classList.toggle('mo-paused');
  btn.textContent = paused ? '回転を再開' : '回転を止める';
});
```
