# M-46 粒子の集合（Particle assembly）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：粒子・生成
- 別名：パーティクル、粒子で形成、集まる
- 定義：ばらばらの粒子が集まって、文字や形になる表現。
- 使う場面：ロゴやタイトルの登場、多くの要素が一つにまとまる説明。
- 注意：粒子の数が多いと重くなる。完成した形を静止画でも用意する。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：The Coding Train — Steering Behaviors https://thecodingtrain.com/challenges/59-steering-behaviors
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：canvas が画面に入ったとき（1回だけ）
- 変える値：各粒子の位置を、ランダムな位置 → 文字の画素の位置へ
- 時間の例：粒子ごとに1400ms、開始のずれ0〜400ms（全体で約1.8秒）
- 動き方の例：減速（easeOutCubic：1 − (1 − t)³）
- 動きを減らす設定のとき：集まる動きを省き、完成した形をそのまま表示する
- 技術：Canvas 2D
- 補足：粒子の数は画素を読み取る間隔（例：4px）で調整でき、間隔を広げるほど軽くなる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<canvas class="mo-gather" width="480" height="160" role="img" aria-label="ATLAS"></canvas>
```

```css
.mo-gather { max-width: 100%; }
```

```js
const cv = document.querySelector('.mo-gather'), ctx = cv.getContext('2d'), W = cv.width, H = cv.height;
// 文字を一度描き、塗られた画素を粒子の目標位置にする
Object.assign(ctx, { font: 'bold 110px sans-serif', textAlign: 'center', textBaseline: 'middle' });
ctx.fillText('ATLAS', W / 2, H / 2);
const data = ctx.getImageData(0, 0, W, H).data, pts = [];
for (let y = 0; y < H; y += 4) for (let x = 0; x < W; x += 4) {
  if (data[(y * W + x) * 4 + 3] > 128) {
    pts.push({ tx: x, ty: y, sx: Math.random() * W, sy: Math.random() * H, delay: Math.random() * 400 });
  }
}
const DUR = 1400, ease = (t) => 1 - Math.pow(1 - t, 3);
function draw(t) {
  ctx.clearRect(0, 0, W, H);
  ctx.fillStyle = '#1e3a8a';
  for (const p of pts) {
    const k = ease(Math.min(1, Math.max(0, (t - p.delay) / DUR)));
    ctx.fillRect(p.sx + (p.tx - p.sx) * k, p.sy + (p.ty - p.sy) * k, 3, 3);
  }
}
function start() {
  if (matchMedia('(prefers-reduced-motion: reduce)').matches) return draw(Infinity); // 完成形だけ
  let t0;
  const loop = (now) => {
    t0 ??= now;
    draw(now - t0);
    if (now - t0 < DUR + 400) requestAnimationFrame(loop); // 全粒子が着いたら止める
  };
  requestAnimationFrame(loop);
}
draw(0);
new IntersectionObserver(([e], io) => {
  if (e.isIntersecting) { io.disconnect(); start(); }
}).observe(cv);
```
