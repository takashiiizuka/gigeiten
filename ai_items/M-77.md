# M-77 スピナー（Spinner）

- 分野：動き・モーション／目的：読みやすさ・使いやすさを守る
- 動きの分類：状態・読み込み
- 別名：ローディング、くるくる
- 定義：終わりの見えない待ち時間に、処理中であることを示す回る表示。
- 使う場面：短い読み込み（数秒）、送信中。
- 注意：長い処理では進み具合や残り時間を示す。待つ理由も文で添える。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：NN/g — Progress Indicators Make a Slow System Less Insufferable https://www.nngroup.com/articles/progress-indicators/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：処理を始めたとき（送信ボタンを押した後など）。すぐに終わる処理（目安 0.5秒未満）では出さない
- 変える値：円弧の rotate 0 → 360deg を繰り返す
- 時間の例：1回転 0.8〜1.2秒
- 動き方の例：等速（linear）
- 動きを減らす設定のとき：回転を止め、静止した印と「送信しています」の文字で示す
- 技術：CSS + JavaScript
- 補足：数秒を超える処理では、件数や割合などの進み具合と、待つ理由を文で示す。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-send" type="button">送信する</button>
<span class="mo-busy" role="status"></span>
```

```css
.mo-spinner{display:inline-block;width:18px;height:18px;margin-right:8px;vertical-align:middle;border:3px solid #cbd5e1;border-top-color:#2563eb;border-radius:50%;animation:mo-spin 1s linear infinite}
@keyframes mo-spin{to{transform:rotate(360deg)}}
@media (prefers-reduced-motion:reduce){.mo-spinner{animation:none}}
```

```js
const btn=document.querySelector('.mo-send'),busy=document.querySelector('.mo-busy');
btn.addEventListener('click',()=>{
  if(btn.getAttribute('aria-disabled'))return;
  btn.setAttribute('aria-disabled','true');
  busy.innerHTML='<span class="mo-spinner" aria-hidden="true"></span>送信しています';
  setTimeout(()=>{ // 実際は処理が終わったときに実行する
    busy.textContent='送信しました';
    btn.removeAttribute('aria-disabled');
  },2000);
});
```
