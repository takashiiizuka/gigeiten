# M-87 キューブ回転（Cube spin）

- 分野：動き・モーション／目的：手順・流れを説明する
- 動きの分類：3D・カメラ
- 別名：キューブトランジション、3D回転
- 定義：立方体を回すように、面ごとに場面を切り替える転換。
- 使う場面：プレゼンの場面転換、切り替えの演出。
- 注意：立体の回転は酔いやすい。短く、多用しない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Adobe — Applying transitions to clips (Premiere Elements) https://helpx.adobe.com/premiere-elements/desktop/applying-transitions/applying-transitions-clips.html
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：「次の場面へ」のボタンを押したとき
- 変える値：立方体の rotateY を1場面ごとに -90deg（各面は rotateY(90deg × n) translateZ(幅の半分) に配置）
- 時間の例：500〜800ms
- 動き方の例：標準（cubic-bezier(0.4, 0, 0.2, 1)）
- 動きを減らす設定のとき：回転させず、場面をすぐに切り替える
- 技術：CSS + JavaScript
- 補足：translateZ の値は面の幅の半分にそろえ、立方体全体を同じ量だけ奥へ下げると正面の面が元の大きさで見える。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-scene">
  <div class="mo-cube">
    <section class="mo-face">場面 1</section><section class="mo-face">場面 2</section>
    <section class="mo-face">場面 3</section><section class="mo-face">場面 4</section>
  </div>
</div>
<button class="mo-next" type="button">次の場面へ</button>
```

```css
.mo-scene{width:300px;height:180px;perspective:1000px}
.mo-cube{position:relative;width:100%;height:100%;transform-style:preserve-3d;transform:translateZ(-150px) rotateY(0deg);transition:transform 700ms cubic-bezier(.4,0,.2,1)}
.mo-face{position:absolute;inset:0;display:grid;place-items:center;color:#fff;font-size:24px;backface-visibility:hidden}
.mo-face:nth-child(1){background:#1d4ed8;transform:rotateY(0deg) translateZ(150px)}
.mo-face:nth-child(2){background:#7c3aed;transform:rotateY(90deg) translateZ(150px)}
.mo-face:nth-child(3){background:#0f766e;transform:rotateY(180deg) translateZ(150px)}
.mo-face:nth-child(4){background:#b45309;transform:rotateY(270deg) translateZ(150px)}
@media (prefers-reduced-motion:reduce){.mo-cube{transition:none}}
```

```js
const cube=document.querySelector('.mo-cube'),faces=[...cube.children];
let step=0;
function show(){
  cube.style.transform=`translateZ(-150px) rotateY(${-90*step}deg)`; // 同じ向きに回し続ける
  const front=((step%4)+4)%4;
  faces.forEach((f,i)=>{f.inert=i!==front;}); // 見えていない面は読み上げとフォーカスから外す
}
document.querySelector('.mo-next').addEventListener('click',()=>{step++;show();});
show();
```
