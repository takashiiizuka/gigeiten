# M-70 カーソル追従（Cursor follower）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：操作への反応
- 別名：カスタムカーソル、カーソルストーカー
- 定義：ポインターを、少し遅れて追いかける印を表示する表現。
- 使う場面：ブランドサイト、作品集の演出。
- 注意：標準のポインターを隠さない。操作の対象が分かりにくくならないようにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Codrops — Custom Cursor Effects https://tympanus.net/codrops/2019/01/31/custom-cursor-effects/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：ポインターを動かしたとき。キーボード操作ではフォーカスが移ったとき
- 変える値：追いかける円の translate を、毎フレーム、ポインターとの差の 18% ずつ近づける
- 時間の例：止めてから 0.3〜0.5秒ほどで追いつく程度
- 動き方の例：毎フレームの比例補間（近づくほど遅くなる）
- 動きを減らす設定のとき：印を表示せず、標準のポインターだけにする
- 技術：CSS + JavaScript
- 補足：標準のポインターを cursor: none で隠さず、印には pointer-events: none を付けて操作を妨げないようにする。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-follower" aria-hidden="true"></div>
<p><a href="#">作品を見る</a>　<a href="#">お問い合わせ</a></p>
```

```css
.mo-follower{position:fixed;left:0;top:0;width:28px;height:28px;margin:-14px 0 0 -14px;border:2px solid #2563eb;border-radius:50%;pointer-events:none;opacity:0;transition:opacity 200ms;z-index:10}
.mo-follower.is-on{opacity:1}
```

```js
const dot=document.querySelector('.mo-follower');
const ok=matchMedia('(pointer: fine)').matches&&!matchMedia('(prefers-reduced-motion: reduce)').matches;
let x=0,y=0,tx=0,ty=0,raf=0;
function tick(){
  x+=(tx-x)*.18;y+=(ty-y)*.18;
  dot.style.transform=`translate(${x}px,${y}px)`;
  raf=Math.hypot(tx-x,ty-y)>.1?requestAnimationFrame(tick):0;
}
function aim(nx,ny){
  if(!dot.classList.contains('is-on')){x=nx;y=ny;dot.classList.add('is-on');}
  tx=nx;ty=ny;
  if(!raf)raf=requestAnimationFrame(tick);
}
if(ok){
  addEventListener('pointermove',e=>aim(e.clientX,e.clientY));
  // キーボード操作では、フォーカスした要素へ印を移す
  addEventListener('focusin',e=>{const r=e.target.getBoundingClientRect();aim(r.left+r.width/2,r.top+r.height/2);});
  document.documentElement.addEventListener('mouseleave',()=>dot.classList.remove('is-on'));
}
```
