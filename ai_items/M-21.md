# M-21 イージング（Easing）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：動きの原理
- 別名：イーズ、速度、加速度
- 定義：時間の進み方に対して値がどう変化するかを決める関数。
- 使う場面：加速・減速の印象を調整する。
- 注意：CSSの既定値は ease で、等速ではない。登場は減速、退場は加速を基本にする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — Easing functions https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/easing-function
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）
- v1の対応項目：M-01 イージング（対応：一致。名称で自動照合）
  - v1の依頼例：登場は ease-out（cubic-bezier(0,0,.2,1)）、退場は ease-in、位置の移動は ease-in-out。linear は使わないで。

## 作り方（例）

- きっかけ：例：要素の登場と退場（比較のため同じ移動量・同じ時間で動かす）
- 変える値：時間に対する進み方（イージング関数）だけを変える
- 時間の例：例：比較のため 600ms にそろえる（実際の画面では 200〜300ms 程度から調整する）
- 動き方の例：登場は減速（cubic-bezier(0.2, 0, 0, 1)）、退場は加速（cubic-bezier(0.3, 0, 1, 1)）。既定の ease は cubic-bezier(0.25, 0.1, 0.25, 1)
- 動きを減らす設定のとき：移動をやめ、位置をその場で切り替える
- 技術：CSS + JavaScript
- 補足：transition-timing-function を省略すると ease になるため、等速にしたい場合は linear を明示する。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-run" type="button">動かす</button>
<div class="mo-easing">
  <p class="mo-lane"><span class="mo-dot" style="--ease: linear">等速 linear</span></p>
  <p class="mo-lane"><span class="mo-dot" style="--ease: ease">既定 ease</span></p>
  <p class="mo-lane"><span class="mo-dot" style="--ease: cubic-bezier(0.2, 0, 0, 1)">減速（登場向き）</span></p>
  <p class="mo-lane"><span class="mo-dot" style="--ease: cubic-bezier(0.3, 0, 1, 1)">加速（退場向き）</span></p>
</div>
```

```css
.mo-lane { width: 360px; margin: 6px 0; background: #f1f4f8; }
.mo-dot { display: inline-block; padding: 4px 8px; background: #2b6cb0; color: #fff; font-size: 12px;
  transition: transform 600ms var(--ease); }
.mo-easing.is-moved .mo-dot { transform: translateX(200px); }
@media (prefers-reduced-motion: reduce) {
  .mo-dot { transition: none; }
}
```

```js
const box = document.querySelector('.mo-easing');
document.querySelector('.mo-run').addEventListener('click', () => box.classList.toggle('is-moved'));
```
