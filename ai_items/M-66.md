# M-66 スクロリーテリング（Scrollytelling）

- 分野：動き・モーション／目的：時間による変化を見せる
- 動きの分類：スクロール
- 別名：スクロールで語る
- 定義：文章を読み進めると、横に固定した図や映像が段階ごとに変わる構成。
- 使う場面：データ報道、調査報告、製品の仕組みの説明。
- 注意：図だけ・文章だけでも意味が通るようにする。印刷や静止画の代替を用意する。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：The Pudding — How to implement scrollytelling with six different libraries https://pudding.cool/process/how-to-implement-scrollytelling/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：文章の各段落が画面の中央を越えたとき（IntersectionObserver）
- 変える値：横に固定した図（position: sticky）の棒の height を段落ごとの値へ（20% → 55% → 90%）変え、読んでいる段落の左に線を表示する
- 時間の例：図の変化600ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：図の変化を即時にし、段落ごとの切り替えだけを残す
- 技術：CSS + JavaScript
- 補足：狭い画面や印刷では、段落ごとに静止した図を挟む形に切り替える。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-sty">
  <figure class="mo-sty-fig" aria-hidden="true"><div class="mo-sty-bar"></div></figure>
  <div>
    <p class="mo-sty-step" data-value="20">1年目の利用者は20万人だった（数値は架空）。</p>
    <p class="mo-sty-step" data-value="55">2年目には55万人に増えた。</p>
    <p class="mo-sty-step" data-value="90">3年目には90万人に達した。</p>
  </div>
</div>
```

```css
.mo-sty { display: grid; grid-template-columns: 1fr 1fr; gap: 32px; }
.mo-sty-fig {
  position: sticky; top: 0; height: 100vh; margin: 0; box-sizing: border-box;
  display: flex; align-items: flex-end; padding-bottom: 20vh;
}
.mo-sty-bar { width: 80px; height: 20%; background: #1e3a8a; transition: height 600ms cubic-bezier(0.2, 0, 0, 1); }
.mo-sty-step { min-height: 80vh; margin: 0; display: flex; align-items: center; padding-left: 16px; border-left: 4px solid transparent; font-size: 20px; }
.mo-sty-step.mo-on { border-left-color: #1e3a8a; }
@media (prefers-reduced-motion: reduce) { .mo-sty-bar { transition: none; } }
```

```js
const bar = document.querySelector('.mo-sty-bar');
const steps = document.querySelectorAll('.mo-sty-step');
const io = new IntersectionObserver((entries) => {
  entries.forEach((e) => {
    if (!e.isIntersecting) return;
    steps.forEach((s) => s.classList.toggle('mo-on', s === e.target));
    bar.style.height = e.target.dataset.value + '%';
  });
}, { rootMargin: '-50% 0px -50% 0px' }); // 画面の中央の線にかかった段落を選ぶ
steps.forEach((s) => io.observe(s));
```
