# M-66 スクロリーテリング（Scrollytelling）

- 分野：動き・モーション／目的：時間による変化を見せる
- 動きの分類：スクロール
- 別名：スクロールで語る
- 定義：文章を読み進めると、横に固定した図や映像が段階ごとに変わる構成。
- 使う場面：データ報道、調査報告、製品の仕組みの説明。
- 注意：図だけ・文章だけでも意味が通るようにする。印刷や静止画の代替を用意する。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：The Pudding — How to implement scrollytelling with six different libraries https://pudding.cool/process/how-to-implement-scrollytelling/
