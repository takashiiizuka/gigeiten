# M-92 折れ線の描画（Line chart reveal）

- 分野：動き・モーション／目的：時間による変化を見せる
- 動きの分類：データ
- 別名：ラインアニメーション
- 定義：折れ線を、時間の順に描き進める表現。
- 使う場面：推移の説明、発表での段階的な提示。
- 注意：軸と単位を先に見せる。描き終えた状態でも読めるようにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：D3 — Transitions https://d3js.org/d3-transition
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：グラフが画面に入ったとき
- 変える値：折れ線の stroke-dashoffset 1 → 0（pathLength="1"、stroke-dasharray: 1）
- 時間の例：1000〜1500ms（軸を見せてから 300ms 後に開始）
- 動き方の例：等速（linear）
- 動きを減らす設定のとき：描き進めず、完成した折れ線を最初から表示する
- 技術：SVG + JavaScript
- 補足：線端を round にすると描く前の端に点が残るため、描く線は既定の butt のままにする。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<svg class="mo-line" viewBox="0 0 320 170" role="img" aria-label="会員数の推移（千人）：1月12、2月18、3月15、4月26、5月31、6月38">
  <g stroke="#94a3b8"><line x1="30" y1="150" x2="310" y2="150"/><line x1="30" y1="10" x2="30" y2="150"/></g>
  <g fill="#475569" font-size="11"><text x="0" y="12">千人</text><text x="292" y="166">月</text></g>
  <path class="mo-line-path" pathLength="1" d="M40 119L92 103L144 111L196 82L248 69L300 51"/>
</svg>
```

```css
.mo-line{width:100%;max-width:480px}
.mo-line-path{fill:none;stroke:#2563eb;stroke-width:3;stroke-linejoin:round;stroke-dasharray:1}
.mo-line.is-ready .mo-line-path{stroke-dashoffset:1}
.mo-line.is-ready.is-in .mo-line-path{stroke-dashoffset:0;transition:stroke-dashoffset 1200ms linear 300ms}
```

```js
const chart=document.querySelector('.mo-line');
if(!matchMedia('(prefers-reduced-motion: reduce)').matches){
  chart.classList.add('is-ready'); // 軸と単位は最初から見せ、線だけを描き進める
  new IntersectionObserver((entries,io)=>{
    if(entries[0].isIntersecting){chart.classList.add('is-in');io.disconnect();}
  },{threshold:.5}).observe(chart);
}
```
