# M-58 スプリット（分割の開き）（Split / barn doors）

- 分野：動き・モーション／目的：手順・流れを説明する
- 動きの分類：画面の転換
- 別名：観音開き、バーンドア
- 定義：画面が中央から分かれて開き、次の場面が現れる転換。
- 使う場面：場面の大きな切り替え、発表の演出。
- 注意：開く向きに意味を持たせるなら、全体でそろえる。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Adobe — Applying transitions to clips (Premiere Elements) https://helpx.adobe.com/premiere-elements/desktop/applying-transitions/applying-transitions-clips.html
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：「開く」ボタンを押したとき
- 変える値：前の場面を左右2枚に切り抜き（clip-path: inset）、左は translateX 0 → -50%、右は 0 → 50%
- 時間の例：800ms
- 動き方の例：加速してから減速（cubic-bezier(0.65, 0, 0.35, 1)）
- 動きを減らす設定のとき：開く動きを省き、前の場面を200msで薄くして消す
- 技術：CSS + JavaScript
- 補足：前の場面を2枚に複製して半分ずつ見せると中身ごと割れて見えるため、複製した側には aria-hidden を付ける。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-split">
  <section class="mo-split-next" inert>場面B</section>
  <div class="mo-door mo-door-l">場面A</div>
  <div class="mo-door mo-door-r" aria-hidden="true">場面A</div>
</div>
<button type="button" class="mo-split-go">開く</button>
```

```css
.mo-split { position: relative; width: 360px; height: 200px; overflow: hidden; }
.mo-split > * { position: absolute; inset: 0; display: grid; place-items: center; font: 700 28px sans-serif; }
.mo-split-next { background: #1e3a8a; color: #fff; }
.mo-door { background: #e2e8f0; transition: transform 800ms cubic-bezier(0.65, 0, 0.35, 1); }
.mo-door-l { clip-path: inset(0 50% 0 0); }
.mo-door-r { clip-path: inset(0 0 0 50%); }
.mo-split.mo-open .mo-door { pointer-events: none; }
.mo-split.mo-open .mo-door-l { transform: translateX(-50%); }
.mo-split.mo-open .mo-door-r { transform: translateX(50%); }
@media (prefers-reduced-motion: reduce) {
  .mo-door { transition: opacity 200ms; }
  .mo-split.mo-open .mo-door { transform: none; opacity: 0; }
}
```

```js
const split = document.querySelector('.mo-split');
const next = split.querySelector('.mo-split-next'), doorL = split.querySelector('.mo-door-l');
const btn = document.querySelector('.mo-split-go');
btn.addEventListener('click', () => {
  const open = split.classList.toggle('mo-open');
  next.inert = !open; // 見えていない場面は操作と読み上げの対象から外す
  doorL.inert = open;
  btn.textContent = open ? '閉じる' : '開く';
});
```
