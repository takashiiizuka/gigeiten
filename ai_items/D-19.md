# D-19 箱ひげ図（Box plot）

- 分野：データの図表／目的：ばらつき・分布を見る
- 別名：なし
- 定義：中央値・四分位範囲・ひげなどで分布を要約する図。
- 使う場面：複数集団のばらつき比較。
- 注意：ひげが最小最大とは限らない。定義を注記する。
- 用意する情報（分野共通）：比較する対象、元の数値、期間、単位、分母、欠測値、出典。比率なら合計と丸め方も確認します。
- 見本の読み方（架空の数値）：Aは例として、ひげ10–90・箱25–65・中央値45。Bはひげ20–85・箱40–70・中央値55。元標本の推定結果ではなく要素の説明用です。
- 出典：Observable Plot — Box mark https://observablehq.github.io/plot/marks/box
- 向いている媒体：資料・提案書（主）、スライド・講演（主）、LP・Webサイト（副）、画像・バナー（副）、図解・グラフ（主）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）
- v1の対応項目：G-21 箱ひげ図 / バイオリン（対応：近い。v1は複数の概念を1項目にまとめていた）
  - v1の説明：中央値・第1四分位（Q1）・第3四分位（Q3）・ひげ（範囲）・外れ値を1本にまとめた型。 複数グループの分布を並べて比較 できます。 バイオリンプロット は箱の代わりに分布の密度そのものを描いたもの。
  - v1の依頼例：グループ間の分布比較は箱ひげ図で。中央値・四分位・外れ値を明示し、可能なら実データ点も薄く重ねて。
