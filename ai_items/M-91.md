# M-91 バーチャートレース（Bar chart race）

- 分野：動き・モーション／目的：時間による変化を見せる
- 動きの分類：データ
- 別名：レースチャート
- 定義：順位の入れ替わりを、棒の伸び縮みと並び替えで時間に沿って見せる表現。
- 使う場面：市場シェアや人気の推移。
- 注意：途中の値が読み取りにくい。重要な時点は静止した図でも示す。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Flourish — Make a bar chart race without coding https://flourish.studio/visualisations/bar-chart-race/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：再生ボタンを押したとき
- 変える値：時点ごとに、棒の width（値に比例）と translateY（順位 × 行の高さ）を次の時点の値へ移す
- 時間の例：1時点あたり 800〜1200ms
- 動き方の例：等速（linear）で時点の間をつなぐ
- 動きを減らす設定のとき：棒の移動を省き、各時点の並びをそのまま切り替えて表示する
- 技術：CSS + JavaScript
- 補足：再生が5秒を超える場合は一時停止の手段を付け、重要な時点の値は静止した図や表でも示す。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-race-play" type="button">再生</button> <span class="mo-race-year" aria-live="polite"></span>
<div class="mo-race" role="img" aria-label="2021年から2024年のシェアの推移"></div>
```

```css
.mo-race{position:relative;width:360px;height:140px;margin-top:8px}
.mo-race div{position:absolute;top:0;left:0;box-sizing:border-box;height:28px;padding-left:8px;line-height:28px;color:#fff;font-size:13px;white-space:nowrap;transition:transform 900ms linear,width 900ms linear}
@media (prefers-reduced-motion:reduce){.mo-race div{transition:none}}
```

```js
const data={2021:{A:30,B:50,C:20,D:40},2022:{A:45,B:52,C:35,D:38},2023:{A:60,B:50,C:55,D:36},2024:{A:72,B:48,C:80,D:40}};
const colors={A:'#1d4ed8',B:'#b45309',C:'#0f766e',D:'#7c3aed'};
const box=document.querySelector('.mo-race'),yearEl=document.querySelector('.mo-race-year');
const years=Object.keys(data),rows={};
for(const k in colors){rows[k]=document.createElement('div');rows[k].style.background=colors[k];box.append(rows[k]);}
function show(y){
  const v=data[y],max=Math.max(...Object.values(v));
  Object.keys(v).sort((a,b)=>v[b]-v[a]).forEach((k,rank)=>{ // 順位で縦の位置、値で幅を決める
    rows[k].style.transform=`translateY(${rank*34}px)`;
    rows[k].style.width=`${v[k]/max*100}%`;
    rows[k].textContent=`${k}社 ${v[k]}`;
  });
  yearEl.textContent=`${y}年`;
}
let timer=0;
document.querySelector('.mo-race-play').addEventListener('click',()=>{
  clearInterval(timer);let i=0;show(years[i]);
  timer=setInterval(()=>{if(++i<years.length)show(years[i]);else clearInterval(timer);},1000);
});
show(years[0]);
```
