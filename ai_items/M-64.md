# M-64 ピン留め（Pinning）

- 分野：動き・モーション／目的：手順・流れを説明する
- 動きの分類：スクロール
- 別名：スクロール固定、スティッキー区間
- 定義：スクロールしても一定の区間は要素を固定し、その間に中身を切り替える表現。
- 使う場面：製品の特長の順番紹介、手順の説明。
- 注意：固定区間が長いとスクロールが空回りに感じる。区間の長さを抑える。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：GSAP — ScrollTrigger (pin) https://gsap.com/docs/v3/Plugins/ScrollTrigger/#pin
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：スクロール位置（区間の上端が画面の上端に達してから、区間の終わりまで）
- 変える値：パネルを position: sticky で固定し、進み具合に応じて表示する項目を切り替える（各項目の opacity 0 → 1 と translateY 16px → 0）
- 時間の例：固定区間は画面2つ分のスクロール（例：区間の高さ300vh）、項目の切り替えは400ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：固定をやめ、項目を縦に並べて通常のスクロールで読めるようにする
- 技術：CSS + JavaScript
- 補足：項目1つあたりのスクロール量を画面の半分から1画面分程度に抑えると、空回りの感じが出にくい。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<section class="mo-pin" aria-label="製品の特長">
  <div class="mo-pin-panel">
    <p class="mo-pin-item mo-on">特長1：軽い</p>
    <p class="mo-pin-item">特長2：静か</p>
    <p class="mo-pin-item">特長3：長持ち</p>
  </div>
</section>
```

```css
.mo-pin { height: 300vh; } /* 固定される区間は 300vh − 100vh */
.mo-pin-panel { position: sticky; top: 0; height: 100vh; display: grid; place-items: center; }
.mo-pin-item {
  grid-area: 1 / 1; margin: 0; font: 700 32px sans-serif; opacity: 0; transform: translateY(16px);
  transition: opacity 400ms, transform 400ms cubic-bezier(0.2, 0, 0, 1);
}
.mo-pin-item.mo-on { opacity: 1; transform: none; }
@media (prefers-reduced-motion: reduce) {
  .mo-pin { height: auto; }
  .mo-pin-panel { position: static; height: auto; display: block; }
  .mo-pin-item { margin: 1em 0; opacity: 1; transform: none; transition: none; }
}
```

```js
const pin = document.querySelector('.mo-pin');
const items = pin.querySelectorAll('.mo-pin-item');
function update() {
  const r = pin.getBoundingClientRect(), range = r.height - innerHeight;
  if (range <= 0) return; // 固定していないとき（動きを減らす設定など）は何もしない
  const p = Math.min(0.999, Math.max(0, -r.top / range)); // 固定区間の進み具合 0〜1
  const i = Math.floor(p * items.length);
  items.forEach((el, k) => el.classList.toggle('mo-on', k === i));
}
addEventListener('scroll', update, { passive: true });
update();
```
