# M-57 アイリス（Iris transition）

- 分野：動き・モーション／目的：手順・流れを説明する
- 動きの分類：画面の転換
- 別名：アイリスイン、円形ワイプ
- 定義：円形の窓が開いて（または閉じて）、場面が切り替わる転換。
- 使う場面：映像の場面転換、注目点への導入。
- 注意：古典的な印象が強い。多用しない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Adobe — Applying transitions to clips (Premiere Elements) https://helpx.adobe.com/premiere-elements/desktop/applying-transitions/applying-transitions-clips.html
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：「場面を切り替える」ボタンを押したとき
- 変える値：次の場面の clip-path: circle(0% at 50% 50%) → circle(75% at 50% 50%)（戻すときは逆向きに閉じる）
- 時間の例：700ms
- 動き方の例：標準（cubic-bezier(0.4, 0, 0.2, 1)）
- 動きを減らす設定のとき：円の開閉を省き、200msのクロスフェードで切り替える
- 技術：CSS + JavaScript
- 補足：円の中心（at 50% 50%）を押した位置や注目させたい点に合わせると、導入の意味が伝わりやすい。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-stage">
  <section class="mo-scene">場面A</section>
  <section class="mo-scene mo-scene-b" inert>場面B</section>
</div>
<button type="button" class="mo-iris-go">場面を切り替える</button>
```

```css
.mo-stage { position: relative; width: 360px; height: 200px; overflow: hidden; }
.mo-scene { position: absolute; inset: 0; display: grid; place-items: center; font: 700 28px sans-serif; background: #e2e8f0; }
.mo-scene-b {
  background: #1e3a8a; color: #fff;
  clip-path: circle(0% at 50% 50%);
  transition: clip-path 700ms cubic-bezier(0.4, 0, 0.2, 1);
}
.mo-stage.mo-show-b .mo-scene-b { clip-path: circle(75% at 50% 50%); }
@media (prefers-reduced-motion: reduce) {
  .mo-stage .mo-scene-b { clip-path: none; opacity: 0; transition: opacity 200ms; }
  .mo-stage.mo-show-b .mo-scene-b { opacity: 1; }
}
```

```js
const stage = document.querySelector('.mo-stage');
const [a, b] = stage.querySelectorAll('.mo-scene');
document.querySelector('.mo-iris-go').addEventListener('click', () => {
  const showB = stage.classList.toggle('mo-show-b');
  a.inert = showB; // 隠れている場面は操作と読み上げの対象から外す
  b.inert = !showB;
});
```
