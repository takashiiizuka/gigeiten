# M-41 流れる破線（Dash flow）

- 分野：動き・モーション／目的：手順・流れを説明する
- 動きの分類：線・図形
- 別名：マーチングアンツ、流れる線
- 定義：破線の模様を線に沿って流し、つながりや流れる向きを示す表現。
- 使う場面：データや作業の流れ、接続中の状態、選択範囲。
- 注意：向きの意味を凡例や矢印でも示す。速すぎるとちらつく。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — CanvasRenderingContext2D: lineDashOffset property https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/lineDashOffset#marching_ants
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示と同時（接続中など、状態が続く間）
- 変える値：破線（stroke-dasharray: 8 6）の stroke-dashoffset 0 → -14（破線1周期分）を繰り返す
- 時間の例：1周期600ms（1秒あたり約23px進む）
- 動き方の例：等速（linear）
- 動きを減らす設定のとき：破線を止めて表示し、流れる向きは矢印で示す
- 技術：CSS + JavaScript
- 補足：1周期の移動量を dasharray の合計と同じにすると、繰り返しの継ぎ目が見えない。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<svg class="mo-flow" viewBox="0 0 300 100" width="300" height="100" role="img" aria-label="AからBへデータが流れる">
  <marker id="mo-arrow" viewBox="0 0 10 10" refX="8" refY="5" markerWidth="6" markerHeight="6" orient="auto">
    <path d="M0 0L10 5L0 10z" fill="#2563eb"/>
  </marker>
  <path class="mo-dash" d="M20 80C100 10 200 10 280 60" fill="none" stroke="#2563eb" stroke-width="3" marker-end="url(#mo-arrow)"/>
</svg>
<button type="button" class="mo-flow-toggle">動きを止める</button>
```

```css
.mo-dash { stroke-dasharray: 8 6; animation: mo-dash 600ms linear infinite; }
.mo-flow.mo-paused .mo-dash { animation-play-state: paused; }
@keyframes mo-dash { to { stroke-dashoffset: -14; } }
@media (prefers-reduced-motion: reduce) {
  .mo-dash { animation: none; }
  .mo-flow-toggle { display: none; }
}
```

```js
const svg = document.querySelector('.mo-flow');
const btn = document.querySelector('.mo-flow-toggle');
btn.addEventListener('click', () => {
  const paused = svg.classList.toggle('mo-paused');
  btn.textContent = paused ? '動きを再開' : '動きを止める';
});
```
