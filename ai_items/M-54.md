# M-54 きらめき（Sparkle）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：粒子・生成
- 別名：キラキラ、トゥインクル
- 定義：小さな光が、ばらばらの間隔で瞬く表現。
- 使う場面：新着、特別感、ロゴの周り。
- 注意：強い点滅にしない。瞬く数を少なく保つ。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Josh W. Comeau — How to animate sparkle text in React https://www.joshwcomeau.com/react/animated-sparkles-in-react/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示したとき（新着が加わったときなど）
- 変える値：小さな星形の scale 0 → 1 → 0、rotate 0 → 90deg、opacity 0 → 1 → 0（位置はランダム）
- 時間の例：1つ800ms、出す間隔は400〜900msのランダム、約4秒で自動で止まる
- 動き方の例：ease-in-out
- 動きを減らす設定のとき：瞬きをやめ、星形を2つ静止して置く
- 技術：JavaScript（Web Animations API）
- 補足：同時に見える光を2〜3個に保ち、1秒に3回を超える明滅にしない（WCAG 2.3.1）。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<p class="mo-sparkle">新着</p>
```

```css
.mo-sparkle { position: relative; display: inline-block; padding: 16px 32px; font: 700 32px sans-serif; }
.mo-star {
  position: absolute; width: 14px; height: 14px; background: #f59e0b; pointer-events: none;
  transform: translate(-50%, -50%);
  clip-path: polygon(50% 0, 62% 38%, 100% 50%, 62% 62%, 50% 100%, 38% 62%, 0 50%, 38% 38%);
}
```

```js
const box = document.querySelector('.mo-sparkle');
function star(x, y) {
  const s = document.createElement('span');
  s.className = 'mo-star';
  s.setAttribute('aria-hidden', 'true');
  s.style.left = x + '%';
  s.style.top = y + '%';
  box.append(s);
  return s;
}
function twinkle() {
  const s = star(Math.random() * 100, Math.random() * 100);
  s.animate([
    { transform: 'translate(-50%, -50%) scale(0) rotate(0deg)', opacity: 0 },
    { transform: 'translate(-50%, -50%) scale(1) rotate(45deg)', opacity: 1, offset: 0.5 },
    { transform: 'translate(-50%, -50%) scale(0) rotate(90deg)', opacity: 0 }
  ], { duration: 800, easing: 'ease-in-out' }).onfinish = () => s.remove();
}
if (matchMedia('(prefers-reduced-motion: reduce)').matches) {
  star(8, 20); star(94, 78); // 静止した星を2つ置く
} else {
  const end = performance.now() + 3200; // 約4秒で自動的に止める
  (function next() { twinkle(); if (performance.now() < end) setTimeout(next, 400 + Math.random() * 500); })();
}
```
