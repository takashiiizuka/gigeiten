# M-10 モーフィング（Morphing）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：線・図形
- 別名：なし
- 定義：輪郭などを補間し、形を連続的に変える表現。
- 使う場面：関連する形や状態の連続性。
- 注意：全く異なる意味の対象を同一物に見せない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — Animatable CSS properties https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Animations/Animatable_properties
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：関連する二つの状態を切り替えるとき（例：再生と停止）
- 変える値：SVG の path の座標を、点の数と命令の並びが同じ別の形へ補間する
- 時間の例：200〜400ms
- 動き方の例：加減速（ease-in-out）
- 動きを減らす設定のとき：補間を省き、形をその場で切り替える
- 技術：SVG + JavaScript
- 補足：形の点の数と順序をそろえておくと、補間の途中で輪郭がねじれない。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-play" type="button" aria-label="再生">
  <svg viewBox="0 0 100 100" width="48" height="48" aria-hidden="true"><path d="M20 10L80 50L80 50L20 90Z" fill="currentColor"/></svg>
</button>
```

```js
const A = [20, 10, 80, 50, 80, 50, 20, 90]; // 再生：三角形（頂点を重ねて4点にそろえる）
const B = [20, 10, 80, 10, 80, 90, 20, 90]; // 停止：四角形
const btn = document.querySelector('.mo-play');
const shape = btn.querySelector('path');
const reduce = matchMedia('(prefers-reduced-motion: reduce)');
const toD = (p) => `M${p[0]} ${p[1]}L${p[2]} ${p[3]}L${p[4]} ${p[5]}L${p[6]} ${p[7]}Z`;
let playing = false, raf = 0;
btn.addEventListener('click', () => {
  playing = !playing;
  btn.setAttribute('aria-label', playing ? '停止' : '再生');
  const [from, to] = playing ? [A, B] : [B, A];
  cancelAnimationFrame(raf);
  if (reduce.matches) { shape.setAttribute('d', toD(to)); return; }
  const start = performance.now();
  const step = (now) => {
    const t = Math.min((now - start) / 300, 1);
    const e = t < 0.5 ? 2 * t * t : 1 - (2 - 2 * t) ** 2 / 2; // ease-in-out
    shape.setAttribute('d', toD(from.map((v, i) => v + (to[i] - v) * e)));
    if (t < 1) raf = requestAnimationFrame(step);
  };
  raf = requestAnimationFrame(step);
});
```
