# M-78 シマー（読み込みの光沢）（Shimmer）

- 分野：動き・モーション／目的：読みやすさ・使いやすさを守る
- 動きの分類：状態・読み込み
- 別名：スケルトンの光沢、ローディングシマー
- 定義：読み込み中の仮の形（スケルトンスクリーン）の上に、光の帯を流して待ちを示す動き。
- 使う場面：一覧やカードの読み込み。
- 注意：実際の配置と同じ形にする。光は控えめにし、読み込み後に配置がずれないようにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：NN/g — Skeleton Screens 101 https://www.nngroup.com/articles/skeleton-screens/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：読み込みを始めたときから、内容が表示されるまで
- 変える値：仮の形の上の光の帯の background-position 100% → -100%（background-size 200%）
- 時間の例：1回の通過 1.2〜1.6秒
- 動き方の例：等速（linear）
- 動きを減らす設定のとき：光の帯を流さず、灰色の仮の形を静止表示する
- 技術：CSS + JavaScript
- 補足：仮の形と実際の内容を同じ寸法にして、読み込み後に配置がずれないようにする。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-card" aria-busy="true">
  <div class="mo-skel mo-img"></div>
  <div class="mo-skel mo-line"></div>
  <div class="mo-skel mo-line mo-short"></div>
</div>
```

```css
.mo-card{width:280px;padding:12px;border:1px solid #e2e8f0;border-radius:8px}
.mo-img{height:140px;margin-bottom:12px;border-radius:6px}
.mo-line{height:14px;margin:0 0 10px;border-radius:4px;font-size:14px;line-height:14px}
.mo-short{width:60%}
.mo-skel{background:linear-gradient(90deg,#e2e8f0 40%,#f1f5f9 50%,#e2e8f0 60%) 0 0/200% 100%;animation:mo-shimmer 1.4s linear infinite}
@keyframes mo-shimmer{from{background-position:100% 0}to{background-position:-100% 0}}
@media (prefers-reduced-motion:reduce){.mo-skel{animation:none}}
```

```js
const card=document.querySelector('.mo-card');
setTimeout(()=>{ // 実際はデータを受け取ったときに実行する。仮の形と同じ寸法で置き換える
  card.innerHTML='<div class="mo-img" style="background:#bfdbfe"></div><p class="mo-line">商品名</p><p class="mo-line mo-short">¥3,300</p>';
  card.removeAttribute('aria-busy');
},3000);
```
