# M-26 フォーカス表示（Focus indicator）

- 分野：動き・モーション／目的：読みやすさ・使いやすさを守る
- 動きの分類：操作への反応
- 別名：なし
- 定義：キーボードなどの操作対象がどこかを示す見た目。
- 使う場面：位置を見失わず操作する。
- 注意：outlineを消したままにせず、背景と区別できる輪郭を必ず見せる。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：W3C — Focus Visible https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：キーボードなどで要素にフォーカスが移ったとき（:focus-visible）
- 変える値：outline を表示し、outline-offset を 0 → 3px へ広げる
- 時間の例：100〜150ms。輪郭そのものはフォーカスと同時に表示する
- 動き方の例：減速（ease-out）
- 動きを減らす設定のとき：広がる動きを省き、最終の輪郭を最初から表示する
- 技術：CSS
- 補足：box-shadow だけの輪郭は強制カラーモードで消えるため、輪郭の基本は outline で作り、背景との差が分かる色にする。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<p>Tab キーでフォーカスを移動してください。</p>
<button class="mo-btn" type="button">保存</button>
<a class="mo-btn" href="#top">キャンセル</a>
```

```css
.mo-btn { display: inline-block; padding: 8px 16px; border: 1px solid #2b6cb0; border-radius: 6px; background: #fff; color: #2b6cb0; font: inherit; text-decoration: none; }
.mo-btn:focus-visible { outline: 3px solid #1a4f8b; outline-offset: 3px; animation: mo-ring 120ms ease-out; }
@keyframes mo-ring { from { outline-offset: 0; } }
@media (prefers-reduced-motion: reduce) {
  .mo-btn:focus-visible { animation: none; }
}
```
