# M-02 フェードアウト（Fade out）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：出現・退場
- 別名：なし
- 定義：見えている要素を徐々に透明にする動き。
- 使う場面：不要になった補助情報の退場。
- 注意：見えなくした要素を操作対象として残さない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：IBM Carbon — Motion https://carbondesignsystem.com/elements/motion/overview/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：閉じるボタンを押したとき、または補助情報が不要になったとき
- 変える値：opacity 1 → 0。完了後に hidden を付けて操作対象から外す
- 時間の例：150〜200ms（出現より短め）
- 動き方の例：加速（cubic-bezier(0.3, 0, 1, 1)）
- 動きを減らす設定のとき：アニメーションを省き、すぐに hidden を付けて取り除く
- 技術：JavaScript（Web Animations API）
- 補足：opacity が 0 でも要素はクリックや読み上げの対象に残るため、完了後に hidden などで取り除き、フォーカスの移動先も決めておく。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<h2 class="mo-title" tabindex="-1">設定</h2>
<div class="mo-note">保存しました。<button class="mo-close" type="button">閉じる</button></div>
```

```css
.mo-note { display: flex; gap: 12px; align-items: center; width: fit-content; padding: 12px 16px; background: #eef3f8; border-radius: 8px; }
.mo-note[hidden] { display: none; }
```

```js
const note = document.querySelector('.mo-note');
const reduce = matchMedia('(prefers-reduced-motion: reduce)');
note.querySelector('.mo-close').addEventListener('click', async () => {
  note.inert = true; // 消えている途中の再操作を防ぐ
  if (!reduce.matches) {
    await note.animate([{ opacity: 1 }, { opacity: 0 }],
      { duration: 180, easing: 'cubic-bezier(0.3, 0, 1, 1)', fill: 'forwards' }).finished;
  }
  note.hidden = true; // 見えない要素を操作対象と読み上げから外す
  document.querySelector('.mo-title').focus();
});
```
