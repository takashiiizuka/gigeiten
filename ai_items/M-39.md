# M-39 マーカーの強調（Animated highlight）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：文字
- 別名：アンダーライン、手書きの注釈
- 定義：強調したい語に、あとから線やマーカーが引かれる表現。
- 使う場面：資料の結論、LPの要点。
- 注意：1画面に1〜2か所まで。色だけに頼らず、文でも強調を示す。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Rough Notation — RoughNotation https://roughnotation.com/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：強調する語が画面に入ったとき
- 変える値：マーカー（linear-gradient の背景）の background-size 0% → 100%（左から右へ）
- 時間の例：800ms（画面に入ってから200ms後に開始）
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：線を引く動きを省き、線を引いた状態で表示する
- 技術：CSS + JavaScript
- 補足：太字など色以外の手がかりも併用し、マーカーが見えない環境でも強調が伝わるようにする。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<p>結論は、<strong class="mo-mark">導入後3か月で問い合わせ件数が減った</strong>ことです。</p>
```

```css
.mo-mark {
  background: linear-gradient(transparent 60%, #ffe066 60%) left / 0% 100% no-repeat;
  transition: background-size 800ms cubic-bezier(0.2, 0, 0, 1) 200ms;
}
.mo-mark.mo-in { background-size: 100% 100%; }
@media (prefers-reduced-motion: reduce) {
  .mo-mark { transition: none; background-size: 100% 100%; }
}
```

```js
const io = new IntersectionObserver((entries) => {
  entries.forEach((e) => {
    if (e.isIntersecting) { e.target.classList.add('mo-in'); io.unobserve(e.target); }
  });
}, { rootMargin: '0px 0px -20% 0px' }); // 画面の下端より少し上に来てから引く
document.querySelectorAll('.mo-mark').forEach((el) => io.observe(el));
```
