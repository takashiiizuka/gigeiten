# M-11 共有要素トランジション（Shared-element transition）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：画面の転換
- 別名：なし
- 定義：画面間で同じ対象が連続して移動・変形するように見せる遷移。
- 使う場面：一覧から詳細への移動。
- 注意：内容の同一性とフォーカス移動を確保する。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — View transitions https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/View_transitions
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）
- v1の対応項目：M-07 共有要素トランジション（対応：一致。名称で自動照合）
  - v1の依頼例：一覧から詳細への遷移は共有要素トランジションで。サムネイルが拡大しながら移動する形にして、320ms・cubic-bezier(.2,0,0,1)で。

## 作り方（例）

- きっかけ：一覧の項目を選んで詳細を開くとき、詳細から一覧へ戻るとき
- 変える値：同じ対象（画像）の位置と大きさを、一覧での状態から詳細での状態へつなぐ
- 時間の例：250〜400ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：位置と大きさの補間を省き、画面をその場で切り替える
- 技術：CSS + JavaScript
- 補足：view-transition-name は表示中の要素の中で一意にし、一覧に複数の項目がある場合は選んだ項目にだけ名前を付ける。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<section class="mo-list"><button class="mo-item" type="button"><span class="mo-photo"></span>商品A</button></section>
<section class="mo-detail" hidden><span class="mo-photo"></span><h2 tabindex="-1">商品A</h2><button class="mo-back" type="button">一覧へ戻る</button></section>
```

```css
.mo-photo { display: block; background: #c9a36b; border-radius: 8px; view-transition-name: mo-photo; }
.mo-item .mo-photo { width: 80px; height: 60px; margin-bottom: 4px; }
.mo-detail .mo-photo { width: 320px; height: 200px; }
::view-transition-group(mo-photo) { animation-duration: 300ms; animation-timing-function: cubic-bezier(0.2, 0, 0, 1); }
@media (prefers-reduced-motion: reduce) {
  ::view-transition-group(*), ::view-transition-old(*), ::view-transition-new(*) { animation: none; }
}
```

```js
const list = document.querySelector('.mo-list');
const detail = document.querySelector('.mo-detail');
function swap(showDetail) {
  const update = () => {
    list.hidden = showDetail;
    detail.hidden = !showDetail;
    (showDetail ? detail.querySelector('h2') : list.querySelector('.mo-item')).focus(); // フォーカスも移す
  };
  if (document.startViewTransition) document.startViewTransition(update);
  else update(); // 未対応のブラウザでは即時に切り替える
}
document.querySelector('.mo-item').addEventListener('click', () => swap(true));
document.querySelector('.mo-back').addEventListener('click', () => swap(false));
```
