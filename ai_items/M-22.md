# M-22 デュレーション（Duration）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：動きの原理
- 別名：なし
- 定義：動きの開始から完了までの時間。
- 使う場面：速度感の指定。
- 注意：同じ時間でも移動距離が違えば印象は変わる。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：IBM Carbon — Motion https://carbondesignsystem.com/elements/motion/overview/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）
- v1の対応項目：M-02 デュレーション（対応：一致。名称で自動照合）
  - v1の依頼例：アニメーションの時間はホバー120ms、通常のUI遷移240ms、大きなパネルの出現320ms。距離に応じて変えて、全部同じ値にしないで。

## 作り方（例）

- きっかけ：例：要素を移動させるとき
- 変える値：移動距離に応じて duration を変える（例：80px で約 170ms、320px で約 310ms）
- 時間の例：小さな変化は 100〜200ms、パネルなど大きな変化は 250〜400ms を目安に始め、距離と大きさで調整する
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：移動をやめ、位置をその場で切り替える
- 技術：JavaScript（Web Animations API）
- 補足：同じ時間のままでは移動距離が長いほど速く見えるため、距離や大きさに応じて時間を少し延ばし、上限も決めておく。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-run" type="button">動かす</button> <output class="mo-log"></output>
<div class="mo-dot" data-dist="80"></div>
<div class="mo-dot" data-dist="320"></div>
```

```css
.mo-dot { width: 32px; height: 32px; margin: 8px 0; border-radius: 6px; background: #2b6cb0; }
```

```js
const reduce = matchMedia('(prefers-reduced-motion: reduce)');
const dots = document.querySelectorAll('.mo-dot');
const log = document.querySelector('.mo-log');
const durationFor = (px) => Math.round(Math.min(500, Math.max(150, 120 + px * 0.6))); // 距離から時間を決める例
let out = false;
document.querySelector('.mo-run').addEventListener('click', () => {
  out = !out;
  const text = [];
  dots.forEach((d) => {
    const dist = Number(d.dataset.dist);
    const from = getComputedStyle(d).transform;
    const to = out ? `translateX(${dist}px)` : 'none';
    const ms = durationFor(dist);
    d.style.transform = to;
    if (!reduce.matches) d.animate([{ transform: from }, { transform: to }], { duration: ms, easing: 'cubic-bezier(0.2, 0, 0, 1)' });
    text.push(`${dist}px：${ms}ms`);
  });
  log.textContent = text.join('／');
});
```
