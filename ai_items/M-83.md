# M-83 色収差（RGBずれ）（Chromatic aberration）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：質感・効果
- 別名：RGBスプリット、色ずれ
- 定義：赤・緑・青の成分を少しずらし、レンズのにじみのように見せる表現。
- 使う場面：映像的な質感、グリッチと組み合わせた演出。
- 注意：文字がにじんで読みにくくなる。短い時間か、飾りの部分だけにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Unity — Chromatic Aberration (URP) https://docs.unity3d.com/6000.0/Documentation/Manual/urp/post-processing-chromatic-aberration.html
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示されたときと、ポインターを重ねたとき
- 変える値：赤と青の text-shadow の横のずれ ±6px → 0（不透明度 0.8 → 0）
- 時間の例：400〜700ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：ずれを付けず、通常の文字を表示する
- 技術：JavaScript（Web Animations API）
- 補足：ずれを残したままにせず、揃った状態で止めて読みやすさを保つ。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<p class="mo-rgb">NIGHT TAPE</p>
```

```css
.mo-rgb{display:inline-block;margin:0;font:800 48px/1.1 system-ui,sans-serif;color:#111827}
```

```js
const el=document.querySelector('.mo-rgb');
const reduce=matchMedia('(prefers-reduced-motion: reduce)').matches;
function play(){ // ずれた状態から、0.6秒で揃った文字に戻す
  if(reduce)return;
  el.animate([
    {textShadow:'-6px 0 rgb(255 0 64 / .8), 6px 0 rgb(0 170 255 / .8)'},
    {textShadow:'0 0 rgb(255 0 64 / 0), 0 0 rgb(0 170 255 / 0)'}
  ],{duration:600,easing:'cubic-bezier(.2,0,0,1)'});
}
play();
el.addEventListener('pointerenter',play);
```
