# D-54 注釈つきグラフ（Annotated chart）

- 分野：データの図表／目的：読みやすさ・使いやすさを守る
- 別名：コールアウト、注釈、アノテーション、チャートと示唆、吹き出し
- 定義：グラフの中の注目すべき点に、短い説明と引き出し線を添えて、何が起きたかを直接示す表現。
- 使う場面：変化のきっかけや例外の値を、凡例や本文に頼らず伝える。
- 注意：注釈は少数に絞る。事実と解釈を分け、原因と言い切れないときは「同じ時期に」などと書く。
- 用意する情報：注目させたい点とその値、説明に使える出来事や根拠、時期。
- 見本の読み方（架空の数値）：1〜6月の指標で、4月の点に「価格を改定」の注釈を付けた架空例です。改定が伸びの原因だとは示していません。
- 出典：Datawrapper Academy — How to create text annotations https://www.datawrapper.de/academy/how-to-create-text-annotations
- 向いている媒体：資料・提案書（主）、スライド・講演（主）、LP・Webサイト（副）、画像・バナー（副）、図解・グラフ（主）（AIの編集判断・未確認）
