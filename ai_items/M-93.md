# M-93 円グラフの展開（Pie sweep）

- 分野：動き・モーション／目的：大小・差を比較する
- 動きの分類：データ
- 別名：ドーナツのアニメーション
- 定義：区分を順に広げ、全体に占める割合を見せる表現。
- 使う場面：構成比の説明。
- 注意：合計が100%になった状態で止める。区分の順と凡例の順をそろえる。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：D3 — Transitions https://d3js.org/d3-transition
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：グラフが画面に入ったとき
- 変える値：12時の位置から時計回りに、描く範囲の角度 0 → 360deg。区分は順に現れ、合計 100% で止める
- 時間の例：全体で 800〜1200ms
- 動き方の例：減速（1 − (1 − t)³）
- 動きを減らす設定のとき：広げず、完成した円グラフを最初から表示する
- 技術：Canvas 2D
- 補足：区分と凡例を同じ配列から作ると、並び順がずれない。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<figure class="mo-pie">
  <canvas width="200" height="200" role="img" aria-label="構成比：A社45%、B社30%、C社15%、その他10%"></canvas>
  <ul class="mo-legend"></ul>
</figure>
```

```css
.mo-pie{display:flex;align-items:center;gap:20px;margin:0}
.mo-legend{margin:0;padding:0;list-style:none;font-size:14px;line-height:1.8}
.mo-legend i{display:inline-block;width:10px;height:10px;margin-right:6px;border-radius:2px}
```

```js
const data=[['A社',45,'#1d4ed8'],['B社',30,'#0f766e'],['C社',15,'#b45309'],['その他',10,'#94a3b8']];
const cv=document.querySelector('.mo-pie canvas'),ctx=cv.getContext('2d');
// 凡例は区分と同じ配列から作り、並び順をそろえる
document.querySelector('.mo-legend').innerHTML=data.map(([n,v,c])=>`<li><i style="background:${c}"></i>${n} ${v}%</li>`).join('');
function draw(p){ // p：0〜1。全体のどこまで広げたか
  ctx.clearRect(0,0,200,200);
  let a=0;const lim=p*Math.PI*2;
  for(const [,v,c] of data){
    const s=a,e=Math.min(a+=v/100*Math.PI*2,lim);
    if(e<=s)break;
    ctx.beginPath();ctx.moveTo(100,100);ctx.arc(100,100,90,s-Math.PI/2,e-Math.PI/2);ctx.fillStyle=c;ctx.fill();
  }
}
function play(){
  const t0=performance.now();
  requestAnimationFrame(function frame(t){
    const k=Math.min(1,Math.max(0,(t-t0)/1000));
    draw(1-Math.pow(1-k,3)); // 減速。k が 1 のとき 100% を描いて止まる
    if(k<1)requestAnimationFrame(frame);
  });
}
if(matchMedia('(prefers-reduced-motion: reduce)').matches)draw(1);
else new IntersectionObserver((entries,io)=>{if(entries[0].isIntersecting){io.disconnect();play();}}).observe(cv);
```
