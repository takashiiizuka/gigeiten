# M-79 注目を促す動き（Attention seekers）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：状態・読み込み
- 別名：ハートビート、ウィグル、アテンションシーカー
- 定義：鼓動・揺れ・ゆっくりの明滅など、小さな動きで目を向けさせる表現。
- 使う場面：未読の数、操作をうながすボタン、ライブ配信中。
- 注意：1画面に1か所まで。1秒に3回を超える点滅はしない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Animate.css — A cross-browser library of CSS animations https://animate.style/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：未読の件数が増えたときなど、目を向けてほしい変化が起きたとき
- 変える値：バッジの scale 1 → 1.2 → 1 を3回（鼓動）
- 時間の例：1回 600〜800ms。回数を決めて止める
- 動き方の例：ease-in-out
- 動きを減らす設定のとき：動かさず、数字と色の静止した表示で示す
- 技術：CSS + JavaScript
- 補足：動かすのは1画面に1か所までにし、回数を決めて止める。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-bell" type="button">通知 <span class="mo-badge">3</span></button>
<button class="mo-add" type="button">新着を追加（動作確認用）</button>
```

```css
.mo-badge{display:inline-block;min-width:1.5em;padding:0 .4em;border-radius:999px;background:#dc2626;color:#fff;font-size:12px;line-height:1.5em;text-align:center}
.mo-badge.is-new{animation:mo-beat 700ms ease-in-out 3}
@keyframes mo-beat{0%,100%{transform:scale(1)}30%{transform:scale(1.2)}}
@media (prefers-reduced-motion:reduce){.mo-badge.is-new{animation:none}}
```

```js
const badge=document.querySelector('.mo-badge');
document.querySelector('.mo-add').addEventListener('click',()=>{
  badge.textContent=Number(badge.textContent)+1;
  badge.classList.remove('is-new');
  void badge.offsetWidth; // クラスを付け直して、もう一度動かす
  badge.classList.add('is-new');
});
```
