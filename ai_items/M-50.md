# M-50 点と線のネットワーク（Particle links）

- 分野：動き・モーション／目的：構成・関係を整理する
- 動きの分類：粒子・生成
- 別名：パーティクルリンク、星座
- 定義：漂う点が近づくと線でつながる表現。
- 使う場面：ネットワーク、つながり、テクノロジーの背景。
- 注意：背景に使うときは文字の読みやすさを先に確認する。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：tsParticles — Particles Links https://particles.js.org/options/particles-links
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示と同時（停止ボタン、画面外、タブが非表示のときは止める）
- 変える値：点の位置（一定の速さで漂い、端で跳ね返る）と、距離110px未満の点どうしを結ぶ線の不透明度（近いほど濃い）
- 時間の例：連続（点の移動は1フレームあたり0.3px以下）
- 動き方の例：等速（端で向きを反転）
- 動きを減らす設定のとき：点と線を動かさず、1フレームだけ描いた静止画にする（再生ボタンで動かせる）
- 技術：Canvas 2D
- 補足：点どうしの距離を毎フレーム総当たりで調べると計算量は点の数の2乗で増えるため、背景では60個前後から試す。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<canvas class="mo-net" width="480" height="270" aria-hidden="true"></canvas>
<button type="button" class="mo-net-toggle">停止</button>
```

```css
.mo-net { display: block; max-width: 100%; background: #f8fafc; }
```

```js
const cv = document.querySelector('.mo-net'), ctx = cv.getContext('2d');
const W = cv.width, H = cv.height, R = 110; // R：線でつなぐ距離
const btn = document.querySelector('.mo-net-toggle');
const pts = Array.from({ length: 60 }, () => ({
  x: Math.random() * W, y: Math.random() * H, vx: Math.random() - 0.5, vy: Math.random() - 0.5
}));
let running = !matchMedia('(prefers-reduced-motion: reduce)').matches, visible = true, raf = 0;
function draw() {
  ctx.clearRect(0, 0, W, H);
  for (let i = 0; i < pts.length; i++) for (let j = i + 1; j < pts.length; j++) {
    const a = pts[i], b = pts[j], d = Math.hypot(a.x - b.x, a.y - b.y);
    if (d > R) continue;
    ctx.strokeStyle = `rgba(37, 99, 235, ${(1 - d / R) * 0.6})`;
    ctx.beginPath(); ctx.moveTo(a.x, a.y); ctx.lineTo(b.x, b.y); ctx.stroke();
  }
  ctx.fillStyle = '#1d4ed8';
  for (const p of pts) ctx.fillRect(p.x - 1.5, p.y - 1.5, 3, 3);
}
function loop() {
  for (const p of pts) {
    p.x += p.vx * 0.6; p.y += p.vy * 0.6;
    if (p.x < 0 || p.x > W) p.vx *= -1;
    if (p.y < 0 || p.y > H) p.vy *= -1;
  }
  draw();
  raf = requestAnimationFrame(loop);
}
function sync() { // 停止中・画面外・タブが非表示のときは描かない
  cancelAnimationFrame(raf);
  if (running && visible && !document.hidden) raf = requestAnimationFrame(loop);
}
btn.textContent = running ? '停止' : '再生';
btn.addEventListener('click', () => { running = !running; btn.textContent = running ? '停止' : '再生'; sync(); });
document.addEventListener('visibilitychange', sync);
new IntersectionObserver(([e]) => { visible = e.isIntersecting; sync(); }).observe(cv);
draw();
```
