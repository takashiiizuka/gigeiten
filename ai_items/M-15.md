# M-15 パララックス（Parallax scrolling）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：スクロール
- 別名：なし
- 定義：スクロール時に要素ごとの移動量を変え、奥行きを感じさせる表現。
- 使う場面：物語的なページの演出。
- 注意：前庭感覚への負担に配慮し、抑制できるようにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：W3C — Understanding SC 2.3.3 Animation from Interactions https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）
- v1の対応項目：M-08 パララックス（視差）（対応：一致。名称で自動照合）
  - v1の依頼例：ヒーローの背景だけスクロール量0.3倍のパララックスに。本文領域は等速のまま。prefers-reduced-motionでは無効化して。

## 作り方（例）

- きっかけ：ページをスクロールしたとき
- 変える値：背景層の translateY を、スクロール量の一部（例：0.2 倍）だけ逆向きに加え、前景より遅く動かす
- 時間の例：時間は指定しない（スクロールに連動する）
- 動き方の例：スクロール量に比例（linear）
- 動きを減らす設定のとき：層ごとの速さの差をなくし、背景も前景と同じように通常のスクロールで動かす
- 技術：CSS + JavaScript
- 補足：OS の設定に加え、ページ内にも動きを止める手段を置くと、設定を知らない利用者も負担を避けられる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-stop" type="button" aria-pressed="false">背景の動きを止める</button>
<section class="mo-scene">
  <div class="mo-bg" aria-hidden="true"></div>
  <h2 class="mo-fg">前景の見出し</h2>
</section>
<div class="mo-spacer"></div>
```

```css
.mo-scene { position: relative; display: grid; place-items: center; height: 60vh; overflow: hidden; }
.mo-bg { position: absolute; inset: -20% 0; background: repeating-linear-gradient(45deg, #dce8f5 0 20px, #c5d8ee 20px 40px); }
.mo-fg { position: relative; padding: 8px 16px; background: #fff; }
.mo-spacer { height: 150vh; }
```

```js
const bg = document.querySelector('.mo-bg');
const btn = document.querySelector('.mo-stop');
let off = matchMedia('(prefers-reduced-motion: reduce)').matches; // 設定がオンなら最初から止める
let ticking = false;
function update() {
  ticking = false;
  const top = bg.parentElement.getBoundingClientRect().top;
  bg.style.transform = off ? 'none' : `translateY(${top * -0.2}px)`; // 背景は前景の 0.8 倍の速さ
  btn.setAttribute('aria-pressed', String(off));
}
addEventListener('scroll', () => {
  if (!ticking) { ticking = true; requestAnimationFrame(update); }
}, { passive: true });
btn.addEventListener('click', () => { off = !off; update(); });
update();
```
