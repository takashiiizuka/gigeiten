# M-69 マグネティック（Magnetic hover）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：操作への反応
- 別名：吸い付くボタン、マグネットボタン
- 定義：ポインターが近づくと、ボタンが引き寄せられるように動く反応。
- 使う場面：ブランドサイトの主要ボタン、遊びのある操作。
- 注意：タッチ操作では起きない。押せる範囲が動いて押しにくくならないようにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Codrops — Magnetic Buttons https://tympanus.net/codrops/2020/08/05/magnetic-buttons/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：ポインターがボタンの周囲（例：縁から60px以内）に入ったとき
- 変える値：ボタンの見た目の層の translate を、ポインターとの差の 0.3 倍（上限 ±12px）。離れたら 0 に戻す
- 時間の例：200〜350ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：動かさず、ホバーとフォーカスのときの色の変化だけにする
- 技術：CSS + JavaScript
- 補足：動かすのは内側の見た目だけにし、押せる範囲（button 本体）は元の位置に残す。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-magnet" type="button"><span class="mo-magnet-face">詳しく見る</span></button>
```

```css
.mo-magnet{margin:80px;padding:0;border:0;background:none;font:inherit;cursor:pointer}
.mo-magnet-face{display:inline-block;padding:14px 28px;border-radius:999px;background:#111827;color:#fff;transition:transform 250ms cubic-bezier(.2,0,0,1),background-color 150ms}
.mo-magnet:hover .mo-magnet-face,.mo-magnet:focus-visible .mo-magnet-face{background:#2563eb}
.mo-magnet:focus-visible{outline:none}
.mo-magnet:focus-visible .mo-magnet-face{outline:3px solid #93c5fd;outline-offset:3px}
```

```js
const btn=document.querySelector('.mo-magnet'),face=btn.querySelector('.mo-magnet-face');
const fine=matchMedia('(hover: hover) and (pointer: fine)').matches; // タッチ操作では動かさない
const reduce=matchMedia('(prefers-reduced-motion: reduce)').matches;
const clamp=v=>Math.max(-12,Math.min(12,v));
if(fine&&!reduce){
  document.addEventListener('pointermove',e=>{
    const r=btn.getBoundingClientRect();
    const dx=e.clientX-(r.left+r.width/2),dy=e.clientY-(r.top+r.height/2);
    const near=Math.abs(dx)<r.width/2+60&&Math.abs(dy)<r.height/2+60;
    face.style.transform=near?`translate(${clamp(dx*.3)}px,${clamp(dy*.3)}px)`:'';
  });
}
```
