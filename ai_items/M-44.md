# M-44 パルス（波紋）（Pulse / ping）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：線・図形
- 別名：波紋、レーダー、ピン
- 定義：輪が広がりながら消える波紋を、繰り返し出す表現。
- 使う場面：現在地、新着、録画中など、注目してほしい一点。
- 注意：1画面に1か所まで。点滅に近い速さにしない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Tailwind CSS — animation https://tailwindcss.com/docs/animation#adding-a-ping-animation
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示したとき、または新着が届くなど状態が変わったとき
- 変える値：点の後ろの輪の scale 1 → 2.8 と opacity 0.6 → 0
- 時間の例：1回1.5秒、3回で停止
- 動き方の例：減速（cubic-bezier(0, 0, 0.2, 1)）
- 動きを減らす設定のとき：波紋を出さず、点の色と「新着」の文字で示す
- 技術：CSS
- 補足：状態が続く間ずっと波紋を出す場合は、止める手段を付けるか、一定の回数で止める。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<p><span class="mo-ping" aria-hidden="true"></span>新着 3件</p>
```

```css
.mo-ping {
  position: relative; display: inline-block; width: 10px; height: 10px;
  margin-right: 8px; border-radius: 50%; background: #dc2626;
}
.mo-ping::after {
  content: ""; position: absolute; inset: 0; border-radius: 50%; background: #dc2626;
  opacity: 0; animation: mo-ping 1.5s cubic-bezier(0, 0, 0.2, 1) 3;
}
@keyframes mo-ping { from { transform: scale(1); opacity: 0.6; } to { transform: scale(2.8); opacity: 0; } }
@media (prefers-reduced-motion: reduce) { .mo-ping::after { animation: none; } }
```
