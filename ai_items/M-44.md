# M-44 パルス（波紋）（Pulse / ping）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：線・図形
- 別名：波紋、レーダー、ピン
- 定義：輪が広がりながら消える波紋を、繰り返し出す表現。
- 使う場面：現在地、新着、録画中など、注目してほしい一点。
- 注意：1画面に1か所まで。点滅に近い速さにしない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Tailwind CSS — animation https://tailwindcss.com/docs/animation#adding-a-ping-animation
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）
