# M-04 スケール（Scale transition）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：出現・退場
- 別名：なし
- 定義：大きさを連続的に変える動き。
- 使う場面：要素の出現や選択状態。
- 注意：内容の重要度や数値が変わったと誤認させない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — transform https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/transform
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：メニューやポップアップが出現するとき、または項目が選択されたとき
- 変える値：transform: scale(0.95) → scale(1)、opacity 0 → 1
- 時間の例：150〜250ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：拡大縮小をやめ、不透明度の変化だけで表示する
- 技術：CSS + JavaScript
- 補足：変化の幅は 0.9〜1 程度の小さな範囲にとどめ、transform-origin を出どころ（ボタンの位置）に合わせる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-trigger" type="button" aria-expanded="false">メニュー</button>
<ul class="mo-menu" hidden><li>編集</li><li>複製</li><li>削除</li></ul>
```

```css
.mo-menu { width: 160px; margin: 4px 0; padding: 8px 0; list-style: none; background: #fff; border: 1px solid #ccd; border-radius: 8px;
  transform-origin: top left; animation: mo-scale-in 200ms cubic-bezier(0.2, 0, 0, 1); }
.mo-menu li { padding: 6px 16px; }
@keyframes mo-scale-in { from { opacity: 0; transform: scale(0.95); } }
@keyframes mo-fade-only { from { opacity: 0; } }
@media (prefers-reduced-motion: reduce) {
  .mo-menu { animation-name: mo-fade-only; }
}
```

```js
const trigger = document.querySelector('.mo-trigger');
const menu = document.querySelector('.mo-menu');
trigger.addEventListener('click', () => {
  menu.hidden = !menu.hidden;
  trigger.setAttribute('aria-expanded', String(!menu.hidden));
});
```
