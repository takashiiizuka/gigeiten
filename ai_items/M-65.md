# M-65 横スクロール演出（Horizontal scroll section）

- 分野：動き・モーション／目的：手順・流れを説明する
- 動きの分類：スクロール
- 別名：横スクロール、水平スクロール
- 定義：縦のスクロールに合わせて、横に並んだ内容が進む表現。
- 使う場面：事例の一覧、年表、工程。
- 注意：縦に読む前提が崩れる。今どこにいるかを表示する。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：GSAP — ScrollTrigger (containerAnimation) https://gsap.com/docs/v3/Plugins/ScrollTrigger/#containerAnimation
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：スクロール位置（区間の上端が画面の上端に達してから、区間の終わりまで）
- 変える値：横に並べた帯の translateX 0 → −（帯の幅 − 画面の幅）を縦のスクロール量に比例させ、進み具合を棒の scaleX 0 → 1 で示す
- 時間の例：スクロール量に連動（例：区間の高さ400vh）
- 動き方の例：スクロールと1対1（線形）
- 動きを減らす設定のとき：固定をやめ、帯を通常の横スクロール（overflow-x: auto）で見せる
- 技術：CSS + JavaScript
- 補足：帯の中にリンクやボタンを置く場合は、キーボードで移動したときにその項目が画面内に来るかを確認する。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<section class="mo-hs" aria-label="事例">
  <div class="mo-hs-view">
    <div class="mo-hs-track">
      <article>事例1</article><article>事例2</article><article>事例3</article><article>事例4</article><article>事例5</article>
    </div>
    <div class="mo-hs-bar" aria-hidden="true"><span></span></div>
  </div>
</section>
```

```css
.mo-hs { height: 400vh; }
.mo-hs-view { position: sticky; top: 0; height: 100vh; overflow: hidden; display: flex; flex-direction: column; justify-content: center; }
.mo-hs-track { display: flex; gap: 24px; width: max-content; padding: 0 5vw; }
.mo-hs-track > article { flex: 0 0 60vw; height: 50vh; display: grid; place-items: center; background: #e2e8f0; font: 700 28px sans-serif; }
.mo-hs-bar { height: 4px; margin: 24px 5vw 0; background: #e2e8f0; }
.mo-hs-bar span { display: block; height: 100%; background: #1e3a8a; transform: scaleX(0); transform-origin: left; }
@media (prefers-reduced-motion: reduce) {
  .mo-hs { height: auto; }
  .mo-hs-view { position: static; height: auto; overflow-x: auto; }
  .mo-hs-bar { display: none; }
}
```

```js
const sec = document.querySelector('.mo-hs'), view = sec.querySelector('.mo-hs-view');
const track = sec.querySelector('.mo-hs-track'), bar = sec.querySelector('.mo-hs-bar span');
const reduce = matchMedia('(prefers-reduced-motion: reduce)');
function update() {
  if (reduce.matches) { track.style.transform = ''; return; }
  const r = sec.getBoundingClientRect();
  const p = Math.min(1, Math.max(0, -r.top / (r.height - innerHeight))); // 区間の進み具合 0〜1
  track.style.transform = `translateX(${-(track.scrollWidth - view.clientWidth) * p}px)`;
  bar.style.transform = `scaleX(${p})`; // 今どこにいるかを示す
}
addEventListener('scroll', update, { passive: true });
addEventListener('resize', update);
update();
```
