# M-06 クロスフェード（Crossfade）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：画面の転換
- 別名：なし
- 定義：一方を消しながら、もう一方を現す切り替え。
- 使う場面：同じ場所の内容の交換。
- 注意：途中で文字が重なって読みにくくなりやすい。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — View transitions https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/View_transitions
- 向いている媒体：LP・Webサイト（主）、スライド・講演（主）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：タブなどで、同じ場所の内容を切り替えるとき
- 変える値：旧内容の opacity 1 → 0 と、新内容の opacity 0 → 1 を同じ位置に重ねて再生する
- 時間の例：旧内容 100〜150ms、新内容 150〜250ms（新内容を 50〜100ms 遅らせて開始）
- 動き方の例：旧内容は加速（ease-in）、新内容は減速（ease-out）
- 動きを減らす設定のとき：時間差の演出をやめ、内容をその場で切り替える
- 技術：CSS + JavaScript
- 補足：旧内容を先に短く消し、新内容を少し遅らせて出すと、文字が重なって見える時間を短くできる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-tabs"><button type="button" data-i="0">概要</button> <button type="button" data-i="1">仕様</button></div>
<div class="mo-stage">
  <p class="mo-pane is-active">概要の文章です。製品の特徴を短く説明します。</p>
  <p class="mo-pane">仕様の文章です。寸法と重さを記載します。</p>
</div>
```

```css
.mo-stage { display: grid; }
.mo-pane { grid-area: 1 / 1; margin: 8px 0; opacity: 0; visibility: hidden;
  transition: opacity 120ms ease-in, visibility 0s 120ms; }
.mo-pane.is-active { opacity: 1; visibility: visible;
  transition: opacity 200ms ease-out 80ms, visibility 0s; }
@media (prefers-reduced-motion: reduce) {
  .mo-pane, .mo-pane.is-active { transition: none; }
}
```

```js
const panes = document.querySelectorAll('.mo-pane');
document.querySelectorAll('.mo-tabs button').forEach((b) => {
  b.addEventListener('click', () => {
    panes.forEach((p, i) => p.classList.toggle('is-active', i === Number(b.dataset.i)));
  });
});
```
