# M-82 流れるグラデーション（Animated gradient）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：質感・効果
- 別名：メッシュグラデーション、オーロラ
- 定義：色のにじみの位置を、ゆっくり動かし続ける表現。
- 使う場面：ヒーローの背景、ブランドの雰囲気づくり。
- 注意：文字の背景では明るさの差（コントラスト）が常に保たれるか確認する。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — @property https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@property
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示されている間（ヒーローの背景）
- 変える値：background-size 300% のグラデーションの background-position 0% 50% → 100% 50% を往復
- 時間の例：片道 15〜30秒
- 動き方の例：ease-in-out（往復）
- 動きを減らす設定のとき：動かさず、グラデーションを静止表示する
- 技術：CSS + JavaScript
- 補足：5秒を超えて動き続けるため止めるボタンを付け、グラデーションのどの色の上でも文字のコントラストを確認する。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<section class="mo-hero">
  <h1>ブランドの見出し</h1>
  <button class="mo-pause" type="button">背景の動きを止める</button>
</section>
```

```css
.mo-hero{padding:64px 24px;color:#fff;background:linear-gradient(120deg,#1e3a8a,#6d28d9,#0f766e,#1e3a8a) 0 50%/300% 300%;animation:mo-flow 20s ease-in-out infinite alternate}
.mo-hero.is-paused{animation-play-state:paused}
@keyframes mo-flow{to{background-position:100% 50%}}
@media (prefers-reduced-motion:reduce){.mo-hero{animation:none}.mo-pause{display:none}}
```

```js
const hero=document.querySelector('.mo-hero'),btn=hero.querySelector('.mo-pause');
btn.addEventListener('click',()=>{
  const paused=hero.classList.toggle('is-paused');
  btn.textContent=paused?'背景の動きを再開する':'背景の動きを止める';
});
```
