# M-32 バウンス（Bounce）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：出現・退場
- 別名：バウンド、跳ねる
- 定義：床で跳ねるように、速さを失いながら止まる動き。
- 使う場面：落ちてくる要素、楽しさを出したい場面。
- 注意：跳ねる回数が多いと待ち時間になる。業務画面では控えめにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：GSAP — Easing https://gsap.com/docs/v3/Eases/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：要素が上から落ちて表示されるとき
- 変える値：transform: translateY(-80px) → 0。着地後に 16px、4px と小さく 2 回跳ねて止まる
- 時間の例：600〜900ms
- 動き方の例：キーフレームごとに指定する（落下は加速 cubic-bezier(0.5, 0, 1, 1)、跳ね上がりは減速 cubic-bezier(0, 0, 0.5, 1)）
- 動きを減らす設定のとき：落下と跳ね返りをやめ、定位置にその場で表示する
- 技術：CSS
- 補足：跳ねる高さを回ごとに前の半分以下にし、回数を 1〜2 回にすると早く落ち着く。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-drop">新着</div>
```

```css
.mo-drop { display: inline-block; margin-top: 90px; padding: 8px 16px; background: #2b6cb0; color: #fff; border-radius: 6px;
  animation: mo-bounce 800ms both; }
@keyframes mo-bounce {
  0%   { transform: translateY(-80px); animation-timing-function: cubic-bezier(0.5, 0, 1, 1); }
  55%  { transform: translateY(0);     animation-timing-function: cubic-bezier(0, 0, 0.5, 1); }
  75%  { transform: translateY(-16px); animation-timing-function: cubic-bezier(0.5, 0, 1, 1); }
  90%  { transform: translateY(0);     animation-timing-function: cubic-bezier(0, 0, 0.5, 1); }
  95%  { transform: translateY(-4px);  animation-timing-function: cubic-bezier(0.5, 0, 1, 1); }
  100% { transform: translateY(0); }
}
@media (prefers-reduced-motion: reduce) {
  .mo-drop { animation: none; }
}
```
