# M-16 スクロールトリガー（Scroll-triggered animation）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：スクロール
- 別名：なし
- 定義：要素が見えたときなどの条件で動きを開始する方式。
- 使う場面：セクションの出現。
- 注意：スクロール位置が再生位置そのものを決める方式とは異なる。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — Intersection Observer https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）
- v1の対応項目：スクロールトリガー（対応：一致。名称で自動照合）
  - v1の依頼例：動きの指定：登場ease-out・退場ease-inで、ホバー120ms／UI遷移240ms／大きなパネル320ms。リストは50msずつのスタッガー（先頭6件まで）。動かすのはtransformとopacityだけ。読み込みはスケルトン。prefers-reduced-motionでは移動を止めてフェードのみにして。

## 作り方（例）

- きっかけ：要素が表示領域に一定の割合（例：20%）入ったとき
- 変える値：opacity 0 → 1、translateY(16px) → 0
- 時間の例：300〜500ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：移動と不透明度の変化をやめ、最初から表示した状態で置く
- 技術：CSS + JavaScript
- 補足：スクロールで決まるのは開始の時点だけで、その後の再生は時間で進む。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-spacer">下へスクロールしてください</div>
<section class="mo-section">スクロールで現れるセクション</section>
```

```css
.mo-spacer { height: 120vh; }
.mo-section { padding: 24px; background: #eef3f8; opacity: 0; transform: translateY(16px);
  transition: opacity 400ms cubic-bezier(0.2, 0, 0, 1), transform 400ms cubic-bezier(0.2, 0, 0, 1); }
.mo-section.is-in { opacity: 1; transform: none; }
@media (prefers-reduced-motion: reduce) {
  .mo-section { opacity: 1; transform: none; transition: none; }
}
```

```js
const io = new IntersectionObserver((entries) => {
  entries.forEach((e) => {
    if (!e.isIntersecting) return;
    e.target.classList.add('is-in');
    io.unobserve(e.target); // 一度表示したら監視をやめ、戻っても再生しない
  });
}, { threshold: 0.2 });
document.querySelectorAll('.mo-section').forEach((el) => io.observe(el));
```
