# L-11 スプリットレイアウト（Split-screen layout）

- 分野：構成・レイアウト／目的：大小・差を比較する
- 別名：なし
- 定義：画面を主に二つの領域に分ける構成。
- 使う場面：説明と図、課題と解決策を並べる。
- 注意：狭い画面では読む順序を決めて縦に並べる。
- 用意する情報（分野共通）：読者、閲覧端末、本文量、図版、最も伝えたい結論。余白や区画の大きさを重要度と結びつけます。
- 出典：MDN — CSS Grid layout https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Grid_layout
