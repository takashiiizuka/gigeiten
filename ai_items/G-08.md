# G-08 組織図（Organization chart）

- 分野：関係・工程の図解／目的：構成・関係を整理する
- 別名：体制図、指揮系統
- 定義：組織の部門や役割とその階層関係を示す図。
- 使う場面：責任範囲や報告関係の説明。
- 注意：非公式な協力関係は別の線などで区別する。
- 用意する情報（分野共通）：登場する要素、要素間の関係、順序、判断条件、担当。線や矢印に何を意味させるかを決めます。
- 早見表の分類：計画を見せたい
- 出典：Microsoft Support — Create an organization chart in Office by using SmartArt https://support.microsoft.com/en-us/office/graphics-visuals/create-an-organization-chart-in-office-by-using-smartart
- 向いている媒体：資料・提案書（主）、スライド・講演（主）、LP・Webサイト（副）、図解・グラフ（主）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）
