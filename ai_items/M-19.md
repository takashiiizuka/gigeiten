# M-19 カウントアップ（Count-up animation）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：データ
- 別名：なし
- 定義：数値を途中の値を経て目標値へ変える演出。
- 使う場面：数値更新への注意喚起。
- 注意：最終値をすぐ読める手段を用意し、架空の増加を実績と見せない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — CSS animations https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Animations
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：数値が画面に入ったとき、または値が更新されたとき
- 変える値：表示する数値を 0（または前回の値）から目標値まで、途中の値を経て変える
- 時間の例：600〜1000ms
- 動き方の例：減速（easeOutCubic：1 - (1 - t)^3）
- 動きを減らす設定のとき：途中の値を出さず、最終値をその場で表示する
- 技術：CSS + JavaScript
- 補足：最終値は読み上げ用の文字と HTML の初期値に入れておき、0 から数える演出を実績の推移のように見せない。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<p>今月の注文数 <span class="mo-sr">12,480件</span><span aria-hidden="true"><span class="mo-count" data-to="12480">12,480</span>件</span></p>
```

```css
.mo-count { font-variant-numeric: tabular-nums; }
.mo-sr { position: absolute; width: 1px; height: 1px; overflow: hidden; clip-path: inset(50%); white-space: nowrap; }
```

```js
const fmt = new Intl.NumberFormat('ja-JP');
const reduce = matchMedia('(prefers-reduced-motion: reduce)');
function countUp(el, dur = 800) {
  const to = Number(el.dataset.to);
  const start = performance.now();
  const step = (now) => {
    const t = Math.min((now - start) / dur, 1);
    el.textContent = fmt.format(Math.round(to * (1 - (1 - t) ** 3))); // 減速
    if (t < 1) requestAnimationFrame(step);
  };
  requestAnimationFrame(step);
}
const io = new IntersectionObserver((entries) => entries.forEach((e) => {
  if (!e.isIntersecting) return;
  countUp(e.target);
  io.unobserve(e.target);
}));
if (!reduce.matches) {
  document.querySelectorAll('.mo-count').forEach((el) => { el.textContent = '0'; io.observe(el); });
}
```
