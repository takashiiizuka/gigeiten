# M-95 予備動作（Anticipation）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：動きの原理
- 別名：アンティシペーション、溜め
- 定義：動く前に逆向きへ小さく溜め、これから動くことを予告する原理。
- 使う場面：大きな移動の前、ジャンプ、発射の演出。
- 注意：溜めが長いと反応が遅く感じる。操作への反応では短くする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Adobe — 12 Principles of Animation https://www.adobe.com/creativecloud/animation/discover/principles-of-animation.html
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：大きく移動させる操作をしたとき（送信、次へ）
- 変える値：進む向きと逆へ translateX 12px と scaleX 0.94 で溜め、その後 進む向きへ 220px
- 時間の例：溜め 120〜180ms、移動 300〜400ms（例は全体 520ms）
- 動き方の例：溜めは減速（cubic-bezier(0.2, 0, 0, 1)）、移動は cubic-bezier(0.5, 0, 0.2, 1)
- 動きを減らす設定のとき：溜めと移動を省き、位置を即時に切り替える
- 技術：JavaScript（Web Animations API）
- 補足：操作への反応では溜めを 150ms 前後に抑え、反応が遅く感じられないようにする。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-track"><div class="mo-box">送信</div></div>
<button class="mo-go" type="button">動かす</button>
```

```css
.mo-track{width:320px;padding:12px 0;border-bottom:1px solid #cbd5e1}
.mo-box{width:72px;padding:10px 0;border-radius:8px;background:#2563eb;color:#fff;text-align:center}
```

```js
const box=document.querySelector('.mo-box');let at=0;
document.querySelector('.mo-go').addEventListener('click',()=>{
  const from=at,to=at?0:220,back=to>from?-12:12;at=to;
  box.style.transform=`translateX(${to}px) scaleX(1)`;
  if(matchMedia('(prefers-reduced-motion: reduce)').matches)return; // 位置だけを変える
  box.animate([
    {transform:`translateX(${from}px) scaleX(1)`,easing:'cubic-bezier(.2,0,0,1)'},
    {transform:`translateX(${from+back}px) scaleX(.94)`,offset:.3,easing:'cubic-bezier(.5,0,.2,1)'}, // 逆向きに溜める
    {transform:`translateX(${to}px) scaleX(1)`}
  ],{duration:520});
});
```
