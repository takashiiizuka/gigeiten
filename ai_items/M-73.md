# M-73 シェイク（Shake）

- 分野：動き・モーション／目的：読みやすさ・使いやすさを守る
- 動きの分類：操作への反応
- 別名：首振り、横揺れ
- 定義：入力の誤りなどを、短い横揺れで知らせる動き。
- 使う場面：パスワードの誤り、入力エラー。
- 注意：揺れだけでは理由が分からない。誤りの内容を文で示す。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Animate.css — A cross-browser library of CSS animations https://animate.style/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：送信した入力に誤りがあったとき
- 変える値：入力欄の translateX 0 → -8px → 8px → -6px → 4px → 0
- 時間の例：300〜400ms
- 動き方の例：ease-in-out
- 動きを減らす設定のとき：揺らさず、枠の色とエラー文の表示だけにする
- 技術：CSS + JavaScript
- 補足：揺れは誤りの合図にとどめ、理由は文で示し、入力欄に aria-invalid と aria-describedby を付ける。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<form class="mo-form" novalidate>
  <label>パスワード <input class="mo-input" type="password" aria-describedby="mo-err"></label>
  <button>ログイン</button>
  <p id="mo-err" class="mo-err" role="alert"></p>
</form>
```

```css
.mo-input{padding:6px 8px;border:2px solid #94a3b8;border-radius:6px;font:inherit}
.mo-input[aria-invalid="true"]{border-color:#dc2626}
.mo-err{min-height:1.5em;color:#b91c1c}
.mo-shake{animation:mo-shake 360ms ease-in-out}
@keyframes mo-shake{20%{transform:translateX(-8px)}40%{transform:translateX(8px)}60%{transform:translateX(-6px)}80%{transform:translateX(4px)}}
@media (prefers-reduced-motion:reduce){.mo-shake{animation:none}}
```

```js
const form=document.querySelector('.mo-form'),input=form.querySelector('.mo-input'),err=form.querySelector('.mo-err');
form.addEventListener('submit',e=>{
  e.preventDefault();
  if(input.value.length>=8){err.textContent='';input.removeAttribute('aria-invalid');return;}
  err.textContent='パスワードは8文字以上で入力してください。';
  input.setAttribute('aria-invalid','true');
  input.classList.remove('mo-shake');
  void input.offsetWidth; // クラスを付け直して、もう一度揺らす
  input.classList.add('mo-shake');
});
```
