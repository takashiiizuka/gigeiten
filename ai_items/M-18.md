# M-18 進捗アニメーション（Progress animation）

- 分野：動き・モーション／目的：手順・流れを説明する
- 動きの分類：状態・読み込み
- 別名：なし
- 定義：進捗量の変化を連続的に見せる動き。
- 使う場面：処理の進行。
- 注意：実際の進捗とアニメーション上の補間を区別する。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — ARIA: progressbar role https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Reference/Roles/progressbar_role
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：処理の進捗値が更新されたとき
- 変える値：バーの transform: scaleX(前の値) → scaleX(新しい値)
- 時間の例：200〜300ms（進捗の更新間隔より短くする）
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：補間をやめ、更新のたびに値をそのまま反映する
- 技術：CSS + JavaScript
- 補足：補間は見た目だけに使い、数値の表示と aria-valuenow には実際の進捗を即時に入れる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-start" type="button">処理を開始</button>
<div class="mo-track" role="progressbar" aria-label="処理の進捗" aria-valuemin="0" aria-valuemax="100" aria-valuenow="0"><div class="mo-fill"></div></div>
<span class="mo-pct">0%</span>
```

```css
.mo-track { width: 280px; height: 8px; margin: 8px 0; background: #e2e8f0; border-radius: 4px; overflow: hidden; }
.mo-fill { height: 100%; background: #2b6cb0; transform: scaleX(0); transform-origin: left;
  transition: transform 250ms cubic-bezier(0.2, 0, 0, 1); }
@media (prefers-reduced-motion: reduce) {
  .mo-fill { transition: none; }
}
```

```js
const btn = document.querySelector('.mo-start');
const track = document.querySelector('.mo-track');
const pct = document.querySelector('.mo-pct');
function setProgress(v) { // v は実際の進捗（0〜100）。数値と属性には補間前の値を入れる
  track.setAttribute('aria-valuenow', v);
  pct.textContent = `${v}%`;
  track.firstElementChild.style.transform = `scaleX(${v / 100})`;
}
btn.addEventListener('click', () => {
  let v = 0;
  btn.disabled = true;
  setProgress(0);
  const timer = setInterval(() => { // 実際の処理の代わりに進捗を模擬する
    v = Math.min(100, v + 10 + Math.floor(Math.random() * 15));
    setProgress(v);
    if (v === 100) { clearInterval(timer); btn.disabled = false; }
  }, 400);
});
```
