# M-42 モーションパス（Motion path）

- 分野：動き・モーション／目的：手順・流れを説明する
- 動きの分類：線・図形
- 別名：パスアニメーション、経路に沿った動き
- 定義：決めた経路に沿って要素を動かし、向きも経路に合わせる表現。
- 使う場面：配送や移動の経路、手順のつながり。
- 注意：経路そのものも薄く見せると、動きの意味が伝わりやすい。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — offset-path https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/offset-path
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示したときと「経路を再生」ボタンを押したとき
- 変える値：offset-distance 0% → 100%（offset-path に経路を指定し、offset-rotate: auto で向きを経路に合わせる）
- 時間の例：2400ms
- 動き方の例：標準（cubic-bezier(0.4, 0, 0.2, 1)）
- 動きを減らす設定のとき：動かさず、終点に置いた状態と経路の線だけで示す
- 技術：CSS + JavaScript
- 補足：経路の座標は親要素の左上が原点になるため、下に敷く SVG の線と同じ数値を使うと線の上を正確に進む。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-route">
  <svg width="320" height="160" aria-hidden="true">
    <path d="M20 140C80 20 180 20 300 120" fill="none" stroke="#cbd5e1" stroke-width="2" stroke-dasharray="4 4"/>
  </svg>
  <div class="mo-mover" aria-hidden="true"></div>
</div>
<button type="button" class="mo-route-play">経路を再生</button>
```

```css
.mo-route { position: relative; width: 320px; height: 160px; }
.mo-route svg { position: absolute; inset: 0; }
.mo-mover {
  position: absolute; top: 0; left: 0; width: 24px; height: 16px;
  background: #2563eb; clip-path: polygon(0 0, 100% 50%, 0 100%);
  offset-path: path('M20 140C80 20 180 20 300 120');
  offset-rotate: auto;
  offset-distance: 100%; /* 動かないときは終点に置く */
}
```

```js
const mover = document.querySelector('.mo-mover');
function play() {
  if (matchMedia('(prefers-reduced-motion: reduce)').matches) return;
  mover.animate([{ offsetDistance: '0%' }, { offsetDistance: '100%' }],
    { duration: 2400, easing: 'cubic-bezier(0.4, 0, 0.2, 1)' });
}
play();
document.querySelector('.mo-route-play').addEventListener('click', play);
```
