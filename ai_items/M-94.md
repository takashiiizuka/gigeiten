# M-94 潰しと伸ばし（Squash and stretch）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：動きの原理
- 別名：スクワッシュ、アニメーションの12原則
- 定義：速さや当たりに応じて形を伸ばし・潰し、重さや弾力を伝える原理。
- 使う場面：ボタンの押下、弾むアイコン、キャラクターの動き。
- 注意：体積（面積）を保ったまま変形させる。業務画面では控えめにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Adobe — 12 Principles of Animation https://www.adobe.com/creativecloud/animation/discover/principles-of-animation.html
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：ボタンを押したとき（ボールが一度弾む）
- 変える値：踏み切りと着地で scale 1.25 × 0.8、上昇と落下の途中で scale 0.9 × 1.1。位置は translate 0 → -100px → 0
- 時間の例：1回の弾み 600〜800ms（例は700ms）
- 動き方の例：上昇は減速（ease-out）、落下は加速（ease-in）
- 動きを減らす設定のとき：変形と跳ねを省き、色を一度だけ変えて押したことを示す
- 技術：JavaScript（Web Animations API）
- 補足：位置と形を別々のアニメーションに分けると、それぞれの速さの変化を調整しやすい。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-floor"><div class="mo-ball"></div></div>
<button class="mo-bounce" type="button">弾ませる</button>
```

```css
.mo-floor{display:flex;align-items:flex-end;justify-content:center;width:140px;height:160px;border-bottom:2px solid #334155}
.mo-ball{width:48px;height:48px;border-radius:50%;background:#f97316;transform-origin:50% 100%}
```

```js
const ball=document.querySelector('.mo-ball');
const reduce=matchMedia('(prefers-reduced-motion: reduce)');
document.querySelector('.mo-bounce').addEventListener('click',()=>{
  if(reduce.matches){ball.animate({backgroundColor:['#c2410c','#f97316']},300);return;}
  const t={duration:700};
  // 位置：上がるときは減速、落ちるときは加速
  ball.animate([{translate:'0 0',offset:.1,easing:'ease-out'},{translate:'0 -100px',offset:.45,easing:'ease-in'},{translate:'0 0',offset:.85}],t);
  // 形：横と縦の倍率の積をほぼ1に保つ（1.25 × 0.8 = 1）
  ball.animate([{scale:'1 1'},{scale:'1.25 .8',offset:.1},{scale:'.9 1.1',offset:.2},{scale:'1 1',offset:.45},
    {scale:'.9 1.1',offset:.75},{scale:'1.25 .8',offset:.85},{scale:'1 1'}],t);
});
```
