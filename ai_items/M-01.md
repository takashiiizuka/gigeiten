# M-01 フェードイン（Fade in）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：出現・退場
- 別名：フェード、フェイド
- 定義：透明な状態から徐々に見えるようにする動き。
- 使う場面：新しい内容の出現。
- 注意：読ませる情報の表示を長く遅らせない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：IBM Carbon — Motion https://carbondesignsystem.com/elements/motion/overview/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（主）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：要素を表示するとき（ボタン操作や、hidden を外したとき）
- 変える値：opacity 0 → 1
- 時間の例：200〜300ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：アニメーションをやめ、その場で表示する。移動を伴わないため、150ms 以下の短い不透明度の変化だけ残す設計もある
- 技術：CSS + JavaScript
- 補足：読ませる文章に使う場合は時間を短くし、遅延と重ねて表示を待たせない。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-show" type="button">内容を表示</button>
<p class="mo-fade" hidden>新しい内容が表示されました。</p>
```

```css
.mo-fade { animation: mo-fade-in 250ms cubic-bezier(0.2, 0, 0, 1) both; }
@keyframes mo-fade-in { from { opacity: 0; } to { opacity: 1; } }
@media (prefers-reduced-motion: reduce) {
  .mo-fade { animation: none; }
}
```

```js
document.querySelector('.mo-show').addEventListener('click', () => {
  document.querySelector('.mo-fade').hidden = false; // 表示された時点でアニメーションが始まる
});
```
