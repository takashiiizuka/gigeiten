# M-38 マーキー（流れる文字）（Marquee / ticker）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：文字
- 別名：ティッカー、テロップ、電光掲示板
- 定義：文字の帯が一方向に流れ続ける表示。
- 使う場面：お知らせ、ニュースの見出し、ロゴの帯。
- 注意：5秒を超えて自動で動く場合は、止める手段を付ける（WCAG 2.2.2）。重要な情報を流すだけにしない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：W3C — Pause, Stop, Hide https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示と同時に自動で開始（ホバー中と停止ボタンで止まる）
- 変える値：文字の帯の translateX 0 → -50%（同じ内容を2つ並べ、継ぎ目なくつなぐ）
- 時間の例：1周20秒（帯の長さに合わせ、1秒あたり40〜60px程度）
- 動き方の例：等速（linear）
- 動きを減らす設定のとき：流さずに静止させ、内容を折り返して全文を表示する
- 技術：CSS + JavaScript
- 補足：流れる帯にだけ置いた情報は読み逃されるため、同じ内容を一覧やリンクでも示す。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-marquee">
  <div class="mo-track">
    <p>営業時間を変更しました ・ 新商品のお知らせ ・ 送料無料キャンペーン実施中</p>
    <p aria-hidden="true">営業時間を変更しました ・ 新商品のお知らせ ・ 送料無料キャンペーン実施中</p>
  </div>
</div>
<button type="button" class="mo-marquee-toggle">停止</button>
```

```css
.mo-marquee { overflow: hidden; white-space: nowrap; }
.mo-track { display: inline-flex; animation: mo-marquee 20s linear infinite; }
.mo-track p { margin: 0; padding-right: 3em; }
.mo-marquee:hover .mo-track, .mo-marquee.mo-paused .mo-track { animation-play-state: paused; }
@keyframes mo-marquee { to { transform: translateX(-50%); } }
@media (prefers-reduced-motion: reduce) {
  .mo-marquee { white-space: normal; }
  .mo-track { animation: none; }
  .mo-track p[aria-hidden], .mo-marquee-toggle { display: none; }
}
```

```js
const marquee = document.querySelector('.mo-marquee');
const btn = document.querySelector('.mo-marquee-toggle');
btn.addEventListener('click', () => {
  const paused = marquee.classList.toggle('mo-paused');
  btn.textContent = paused ? '再生' : '停止';
});
```
