# M-40 文字の波（Wave text）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：文字
- 別名：ウェーブテキスト
- 定義：文字ごとに時間差をつけ、波のように上下させ続ける表現。
- 使う場面：読み込み中の表示、遊びのある見出し。
- 注意：動き続ける文字は読みにくい。本文や操作の説明には使わない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Prismic — CSS Text Animations: 40 Creative Examples to Try https://prismic.io/blog/css-text-animations
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示と同時（読み込み中の表示なら、読み込みの開始時）
- 変える値：各文字の translateY 0 → -0.4em → 0 を、文字ごとの時間差をつけて繰り返す
- 時間の例：1周1.2秒、文字ごとの時間差80ms、3回で停止（5文字で約4秒）
- 動き方の例：ease-in-out
- 動きを減らす設定のとき：上下の動きを省き、文字を静止して表示する
- 技術：CSS + JavaScript
- 補足：読み込み表示に使う場合は、読み込みが終わった時点で動きを止めて文言を切り替える。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<h2 class="mo-wave">読み込み中</h2>
```

```css
.mo-wave span {
  display: inline-block;
  white-space: pre;
  animation: mo-wave 1.2s ease-in-out calc(var(--i) * 80ms) 3;
}
@keyframes mo-wave { 0%, 40%, 100% { transform: none; } 20% { transform: translateY(-0.4em); } }
@media (prefers-reduced-motion: reduce) { .mo-wave span { animation: none; } }
```

```js
const el = document.querySelector('.mo-wave');
const text = el.textContent;
el.setAttribute('aria-label', text); // 読み上げには元の文を渡す
el.textContent = '';
[...text].forEach((ch, i) => {
  const s = document.createElement('span');
  s.textContent = ch;
  s.setAttribute('aria-hidden', 'true');
  s.style.setProperty('--i', i);
  el.append(s);
});
```
