# M-67 読み進みの表示（Scroll progress indicator）

- 分野：動き・モーション／目的：読みやすさ・使いやすさを守る
- 動きの分類：スクロール
- 別名：読了インジケーター、プログレスバー
- 定義：ページをどこまで読んだかを、線の伸びなどで示す表示。
- 使う場面：長い記事、規約、マニュアル。
- 注意：目立たせすぎない。上端の細い線程度にする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Chrome for Developers — Animate elements on scroll with Scroll-driven animations https://developer.chrome.com/docs/css-ui/scroll-driven-animations#demo_reading_progress_indicator
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：ページをスクロールしたとき
- 変える値：上端の細い線の transform: scaleX を、読んだ割合に合わせて 0 → 1
- 時間の例：時間は決めず、スクロール量に連動させる
- 動き方の例：補間なし（スクロール位置をそのまま反映する）
- 動きを減らす設定のとき：スクロールに直接連動する表示なので、そのまま使ってよい。値の変化に transition を足さない
- 技術：CSS + JavaScript
- 補足：CSS の animation-timeline: scroll() でも作れる。使う場合は対象ブラウザの対応状況を確認する。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-progress" aria-hidden="true"></div>
<article class="mo-article"><h1>記事の見出し</h1><p>本文が続きます。</p></article>
```

```css
.mo-progress{position:fixed;top:0;left:0;width:100%;height:3px;background:#2563eb;transform:scaleX(0);transform-origin:0 50%;z-index:10}
.mo-article{min-height:300vh;max-width:40em;margin:auto;padding:24px}
```

```js
const bar=document.querySelector('.mo-progress');
function update(){
  const max=document.documentElement.scrollHeight-innerHeight;
  bar.style.transform=`scaleX(${max>0?scrollY/max:0})`;
}
addEventListener('scroll',update,{passive:true});
addEventListener('resize',update);
update();
```
