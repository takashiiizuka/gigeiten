# M-23 ディレイ（Delay）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：動きの原理
- 別名：なし
- 定義：動きの開始前に置く待ち時間。
- 使う場面：順序の表現。
- 注意：応答がないと誤認される長さを避ける。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — CSS animations https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Animations
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：例：保存ボタンを押したとき
- 変える値：主な応答（保存しました）は遅延 0ms で表示し、補足の文だけ transition-delay で 150ms 遅らせる
- 時間の例：遅延は 50〜150ms 程度。表示そのものは 200ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：移動と時間差をやめ、主な応答と補足を同時に表示する
- 技術：CSS + JavaScript
- 補足：操作の直後に出す最初の反応には遅延を置かず、遅延は順序を示す補足の要素に限って使う。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-save" type="button">保存</button>
<div class="mo-result">
  <p class="mo-first">保存しました</p>
  <p class="mo-second">変更は履歴から元に戻せます</p>
</div>
```

```css
.mo-result p { margin: 4px 0; opacity: 0; visibility: hidden; transform: translateY(4px);
  transition: opacity 200ms, transform 200ms cubic-bezier(0.2, 0, 0, 1), visibility 0s 200ms; }
.mo-result.is-shown p { opacity: 1; visibility: visible; transform: none; transition-delay: 0s; }
.mo-result.is-shown .mo-second { transition-delay: 150ms; } /* 補足だけ遅らせる */
@media (prefers-reduced-motion: reduce) {
  .mo-result p { transform: none; }
  .mo-result.is-shown .mo-second { transition-delay: 0s; }
}
```

```js
const result = document.querySelector('.mo-result');
document.querySelector('.mo-save').addEventListener('click', () => {
  result.classList.remove('is-shown');
  void result.offsetWidth; // 非表示の状態を一度確定させ、押すたびに再生する
  result.classList.add('is-shown');
});
```
