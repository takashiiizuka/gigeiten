# M-28 リデューストモーション（Reduced motion）

- 分野：動き・モーション／目的：読みやすさ・使いやすさを守る
- 動きの分類：動きの原理
- 別名：なし
- 定義：動きの軽減を望む設定に応じ、移動などを減らす設計。
- 使う場面：動きに負担を感じる利用者への対応。
- 注意：単に速くするだけでなく、静的な代替を考える。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — prefers-reduced-motion https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）
- v1の対応項目：M-09 prefers-reduced-motion（対応：一致。名称で自動照合）
  - v1の依頼例：prefers-reduced-motion: reduce では移動と拡大縮小を止めて、フェードと色の変化だけ残して。全アニメを0秒にはしないで。

## 作り方（例）

- きっかけ：OS やブラウザで動きを減らす設定がオンのとき（prefers-reduced-motion: reduce）
- 変える値：移動・拡大・回転・視差を止め、短い不透明度の変化か、その場での切り替えに置き換える
- 時間の例：置き換え後は 0〜150ms 程度
- 動き方の例：置き換え後は等速（linear）か減速
- 動きを減らす設定のとき：例：下から移動して出る通知を、移動なしで短くフェードして出る通知に置き換える
- 技術：CSS + JavaScript
- 補足：時間を短くするだけでは移動の負担は残るため、動きの種類そのものを静的な表現に置き換える。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<p class="mo-state"></p>
<button class="mo-notify" type="button">通知を表示</button>
<div class="mo-toast" role="status"></div>
```

```css
.mo-toast:not(:empty) { display: inline-block; margin-top: 8px; padding: 10px 14px; background: #1f2a44; color: #fff; border-radius: 6px;
  animation: mo-slide-up 300ms cubic-bezier(0.2, 0, 0, 1); }
@keyframes mo-slide-up { from { opacity: 0; transform: translateY(24px); } }
@keyframes mo-fade { from { opacity: 0; } }
@media (prefers-reduced-motion: reduce) {
  .mo-toast:not(:empty) { animation: mo-fade 150ms linear; } /* 移動をやめ、短い不透明度の変化だけ残す */
}
```

```js
const mq = matchMedia('(prefers-reduced-motion: reduce)');
const state = document.querySelector('.mo-state');
const toast = document.querySelector('.mo-toast');
const show = () => {
  state.textContent = `動きを減らす設定：${mq.matches ? 'オン（移動せずに表示）' : 'オフ（下から移動して表示）'}`;
};
mq.addEventListener('change', show); // 閲覧中に設定が変わっても追従する
show();
document.querySelector('.mo-notify').addEventListener('click', () => {
  toast.textContent = '';
  void toast.offsetWidth; // 空の状態を一度確定させ、押すたびに再生する
  toast.textContent = '保存しました';
});
```
