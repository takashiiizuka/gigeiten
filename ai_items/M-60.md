# M-60 プッシュ（Push）

- 分野：動き・モーション／目的：手順・流れを説明する
- 動きの分類：画面の転換
- 別名：押し出し
- 定義：次の場面が、前の場面を押し出すように入れ替わる転換。
- 使う場面：スライドの送り、手順の前後の移動。
- 注意：押し出す向きを、進む・戻るの意味とそろえる。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Adobe — Applying transitions to clips (Premiere Elements) https://helpx.adobe.com/premiere-elements/desktop/applying-transitions/applying-transitions-clips.html
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：「次へ」「前へ」ボタンを押したとき
- 変える値：場面を横に並べた帯の translateX 0% → -100%（1場面分）。前の場面と次の場面が同時に同じ向きへ動く
- 時間の例：500ms
- 動き方の例：標準（cubic-bezier(0.4, 0, 0.2, 1)）
- 動きを減らす設定のとき：押し出す動きを省き、即時に切り替える
- 技術：CSS + JavaScript
- 補足：「次へ」で左へ、「前へ」で右へ動かし、キーボードの左右キーやスワイプの向きともそろえる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-push">
  <div class="mo-push-track">
    <section>手順1</section><section>手順2</section><section>手順3</section>
  </div>
</div>
<button type="button" class="mo-push-btn" data-dir="-1">前へ</button>
<button type="button" class="mo-push-btn" data-dir="1">次へ</button>
```

```css
.mo-push { width: 360px; height: 200px; overflow: hidden; }
.mo-push-track { display: flex; height: 100%; transition: transform 500ms cubic-bezier(0.4, 0, 0.2, 1); }
.mo-push-track > section { flex: 0 0 100%; display: grid; place-items: center; font: 700 28px sans-serif; background: #e2e8f0; }
.mo-push-track > section:nth-child(even) { background: #cbd5e1; }
@media (prefers-reduced-motion: reduce) { .mo-push-track { transition: none; } }
```

```js
const track = document.querySelector('.mo-push-track');
const pages = [...track.children];
let index = 0;
function show() {
  track.style.transform = `translateX(${-100 * index}%)`;
  pages.forEach((p, i) => { p.inert = i !== index; }); // 見えていない場面は操作と読み上げの対象から外す
}
document.querySelectorAll('.mo-push-btn').forEach((btn) => btn.addEventListener('click', () => {
  index = Math.min(pages.length - 1, Math.max(0, index + Number(btn.dataset.dir)));
  show();
}));
show();
```
