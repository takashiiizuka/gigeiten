# M-08 ワイプ（Wipe transition）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：画面の転換
- 別名：なし
- 定義：境界が移動し、前後の画面や領域を切り替える表現。
- 使う場面：状態の切り替えを方向とともに示す。
- 注意：方向に誤った時間や階層の意味を与えない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — clip-path https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/clip-path
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：表示の状態を切り替える操作をしたとき
- 変える値：新しい面の clip-path: inset(0 100% 0 0) → inset(0 0 0 0)（境界が左から右へ移動する）
- 時間の例：300〜500ms
- 動き方の例：加減速（cubic-bezier(0.65, 0, 0.35, 1)）
- 動きを減らす設定のとき：境界の移動をやめ、150ms 程度の短いクロスフェードで切り替える
- 技術：CSS + JavaScript
- 補足：戻す操作では逆向きに動かし、方向と前後関係の意味を画面全体でそろえる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-switch" type="button" aria-pressed="false">夜の表示</button>
<div class="mo-wipe">
  <div class="mo-face">昼の表示</div>
  <div class="mo-face mo-next">夜の表示</div>
</div>
```

```css
.mo-wipe { display: grid; width: 280px; height: 120px; margin-top: 8px; }
.mo-face { grid-area: 1 / 1; display: grid; place-items: center; background: #f4e7c5; }
.mo-next { background: #1f2a44; color: #fff; clip-path: inset(0 100% 0 0);
  transition: clip-path 400ms cubic-bezier(0.65, 0, 0.35, 1); }
.mo-wipe.is-on .mo-next { clip-path: inset(0 0 0 0); }
@media (prefers-reduced-motion: reduce) {
  .mo-next { clip-path: none; opacity: 0; transition: opacity 150ms linear; }
  .mo-wipe.is-on .mo-next { opacity: 1; }
}
```

```js
const btn = document.querySelector('.mo-switch');
const wipe = document.querySelector('.mo-wipe');
btn.addEventListener('click', () => {
  const on = wipe.classList.toggle('is-on');
  btn.setAttribute('aria-pressed', String(on));
});
```
