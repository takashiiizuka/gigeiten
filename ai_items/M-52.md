# M-52 群れの動き（ボイド）（Flocking (boids)）

- 分野：動き・モーション／目的：手順・流れを説明する
- 動きの分類：粒子・生成
- 別名：ボイド、群知能
- 定義：個々が近くの仲間と「離れる・そろえる・集まる」だけで、群れとして動く表現。
- 使う場面：群衆や市場の動き、自律的な振る舞いの説明。
- 注意：動きが予測しにくい。説明に使うときは規則を文で添える。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Craig Reynolds — Boids https://www.red3d.com/cwr/boids/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：表示と同時（停止ボタン、画面外、タブが非表示のときは止める）
- 変える値：60個の位置と向き。半径50px以内の仲間を見て、18px未満なら離れる・平均の向きにそろえる・平均の位置へ寄る
- 時間の例：連続（速さは1フレームあたり1〜2px）
- 動き方の例：なし（毎フレームの3つの力の合計で速さが決まる）
- 動きを減らす設定のとき：規則で少し進めた配置を静止画で表示し、規則を文で示す（再生ボタンで動かせる）
- 技術：Canvas 2D
- 補足：3つの規則の強さ（例：0.08・0.05・0.002）の比で群れの印象が変わるため、1つずつ変えて確かめる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<canvas class="mo-boids" width="480" height="270" aria-hidden="true"></canvas>
<p>規則：近すぎる仲間から離れる／近くの仲間と向きをそろえる／近くの仲間の中心へ寄る</p>
<button type="button" class="mo-boids-toggle">停止</button>
```

```css
.mo-boids { display: block; max-width: 100%; background: #f0fdfa; }
```

```js
const cv = document.querySelector('.mo-boids'), ctx = cv.getContext('2d'), W = cv.width, H = cv.height;
const btn = document.querySelector('.mo-boids-toggle');
const rnd = (n) => Math.random() * n;
const boids = Array.from({ length: 60 }, () => ({ x: rnd(W), y: rnd(H), vx: rnd(2) - 1, vy: rnd(2) - 1 }));
function update() {
  for (const b of boids) {
    let n = 0, ax = 0, ay = 0, cx = 0, cy = 0, sx = 0, sy = 0;
    for (const o of boids) {
      const dx = o.x - b.x, dy = o.y - b.y, d = Math.hypot(dx, dy);
      if (o === b || d === 0 || d > 50) continue;      // 半径50pxの仲間だけを見る
      n++; ax += o.vx; ay += o.vy; cx += dx; cy += dy;
      if (d < 18) { sx -= dx / d; sy -= dy / d; }      // 離れる
    }
    if (n) { b.vx += (ax / n - b.vx) * 0.05 + (cx / n) * 0.002; b.vy += (ay / n - b.vy) * 0.05 + (cy / n) * 0.002; } // そろえる＋集まる
    b.vx += sx * 0.08; b.vy += sy * 0.08;
    const s = Math.hypot(b.vx, b.vy) || 1, v = Math.min(2, Math.max(1, s)); // 速さを1〜2に収める
    b.vx = (b.vx / s) * v; b.vy = (b.vy / s) * v;
  }
  for (const b of boids) { b.x = (b.x + b.vx + W) % W; b.y = (b.y + b.vy + H) % H; }
}
ctx.fillStyle = '#0f766e';
function draw() {
  ctx.clearRect(0, 0, W, H);
  for (const b of boids) {
    ctx.save(); ctx.translate(b.x, b.y); ctx.rotate(Math.atan2(b.vy, b.vx));
    ctx.beginPath(); ctx.moveTo(6, 0); ctx.lineTo(-4, 3); ctx.lineTo(-4, -3); ctx.fill(); ctx.restore();
  }
}
let running = !matchMedia('(prefers-reduced-motion: reduce)').matches, visible = true, raf = 0;
function loop() { update(); draw(); raf = requestAnimationFrame(loop); }
function sync() { cancelAnimationFrame(raf); if (running && visible && !document.hidden) raf = requestAnimationFrame(loop); }
if (!running) for (let i = 0; i < 120; i++) update(); // 動きを減らす設定：少し進めた配置を静止画で出す
btn.textContent = running ? '停止' : '再生';
btn.addEventListener('click', () => { running = !running; btn.textContent = running ? '停止' : '再生'; sync(); });
document.addEventListener('visibilitychange', sync);
new IntersectionObserver(([e]) => { visible = e.isIntersecting; sync(); }).observe(cv);
draw();
```
