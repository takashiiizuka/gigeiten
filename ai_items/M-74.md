# M-74 引っ張って更新（Pull to refresh）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：操作への反応
- 別名：プルトゥリフレッシュ
- 定義：一覧を下に引いて離すと、読み込んで新しい内容が加わる操作と表示。
- 使う場面：タイムライン、受信箱、通知の一覧。
- 注意：引いている量と、更新が始まる位置を見て分かるようにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Apple Developer — UIRefreshControl https://developer.apple.com/documentation/uikit/uirefreshcontrol
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：一覧を下に引いて離したとき。同じ更新を「更新する」ボタンでも行える
- 変える値：一覧の translateY を引いた量の 0.5 倍（上限 80px）。64px を超えたら表示を「離すと更新」に切り替え、更新中は 48px の位置で止める
- 時間の例：戻り 250〜300ms。更新中の表示は処理が終わるまで
- 動き方の例：引いている間は指に追従（補間なし）、戻りは減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：引いた量に合わせた表示は残し、戻るときの動きを省く
- 技術：CSS + JavaScript
- 補足：一覧がスクロールする場合は、先頭（scrollTop が 0）にあるときだけ引く操作を受け付ける。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-ptr">
  <p class="mo-ptr-hint" aria-live="polite">下に引いて更新</p>
  <ul class="mo-ptr-list"><li>資料が共有されました</li><li>会議の時刻が変わりました</li></ul>
</div>
<button class="mo-ptr-btn" type="button">更新する</button>
```

```css
.mo-ptr{position:relative;width:300px;height:220px;overflow:hidden;overscroll-behavior:contain;border:1px solid #cbd5e1;border-radius:8px;touch-action:pan-x;user-select:none}
.mo-ptr-hint{position:absolute;inset:0 0 auto;margin:0;padding:14px;text-align:center;font-size:14px;color:#475569}
.mo-ptr-list{position:relative;height:100%;margin:0;padding:0;list-style:none;background:#fff;transition:transform 280ms cubic-bezier(.2,0,0,1)}
.mo-ptr-list li{padding:14px;border-bottom:1px solid #e2e8f0}
.mo-ptr.is-drag .mo-ptr-list{transition:none}
@media (prefers-reduced-motion:reduce){.mo-ptr-list{transition:none}}
```

```js
const box=document.querySelector('.mo-ptr'),list=box.querySelector('.mo-ptr-list'),hint=box.querySelector('.mo-ptr-hint');
const TH=64;let y0=null,d=0,busy=false;
const shift=px=>{list.style.transform=px?`translateY(${px}px)`:'';};
const say=t=>{if(hint.textContent!==t)hint.textContent=t;};
box.addEventListener('pointerdown',e=>{if(busy)return;y0=e.clientY;d=0;box.classList.add('is-drag');box.setPointerCapture(e.pointerId);});
box.addEventListener('pointermove',e=>{
  if(y0===null)return;
  d=Math.min(80,Math.max(0,(e.clientY-y0)*.5)); // 引いた量の半分だけ動かす
  shift(d);say(d>=TH?'離すと更新':'下に引いて更新');
});
function end(){if(y0===null)return;y0=null;box.classList.remove('is-drag');if(d>=TH)refresh();else shift(0);}
box.addEventListener('pointerup',end);box.addEventListener('pointercancel',end);
document.querySelector('.mo-ptr-btn').addEventListener('click',refresh);
function refresh(){
  if(busy)return;busy=true;shift(48);say('更新中…');
  setTimeout(()=>{ // 実際はデータの取得が終わったときに実行する
    list.insertAdjacentHTML('afterbegin',`<li>新しい通知 ${new Date().toLocaleTimeString('ja-JP')}</li>`);
    shift(0);say('更新しました');busy=false;
  },1200);
}
```
