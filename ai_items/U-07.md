# U-07 ポップオーバー（Popover）

- 分野：UIパターン／目的：操作・体験を分かりやすくする
- 別名：なし
- 定義：関連する要素の近くに一時的に表示する領域。
- 使う場面：補足説明や軽い操作。
- 注意：閉じ方とフォーカスの挙動を確認する。
- 用意する情報（分野共通）：利用者の目的、操作の前後の状態、入力条件、エラー時の挙動。キーボードと狭い画面でも確認します。
- 出典：MDN — Popover API https://developer.mozilla.org/en-US/docs/Web/API/Popover_API
- 向いている媒体：LP・Webサイト（主）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）
