# M-30 ポップイン（Pop in）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：出現・退場
- 別名：バックイン、ズームイン
- 定義：小さく現れ、一度わずかに大きくなってから元の大きさに落ち着く出現。
- 使う場面：通知の数、バッジ、追加された項目。
- 注意：多用すると画面が騒がしくなる。重要な変化だけに使う。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Animate.css — A cross-browser library of CSS animations https://animate.style/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：通知の数やカートの点数が増えたとき、項目が追加されたとき
- 変える値：transform: scale(0.3) → scale(1.12) → scale(1)、opacity 0 → 1
- 時間の例：250〜350ms
- 動き方の例：各区間を減速（cubic-bezier(0.2, 0, 0, 1)）で補間し、行き過ぎはキーフレームの 60% 地点で作る
- 動きを減らす設定のとき：拡大をやめ、新しい数をその場で表示する
- 技術：CSS + JavaScript
- 補足：数の変化を知らせる要素など、注意を向けたい箇所に絞り、同じ画面で複数のポップインを同時に使わない。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<button class="mo-add" type="button">カートに追加</button>
<span class="mo-cart" aria-live="polite">カート <span class="mo-badge" hidden>0</span></span>
```

```css
.mo-badge { display: inline-grid; place-items: center; min-width: 20px; height: 20px; padding: 0 6px; border-radius: 10px; background: #d6336c; color: #fff; font-size: 12px; }
.mo-badge[hidden] { display: none; }
.mo-badge.is-pop { animation: mo-pop 300ms cubic-bezier(0.2, 0, 0, 1); }
@keyframes mo-pop { 0% { opacity: 0; transform: scale(0.3); } 60% { opacity: 1; transform: scale(1.12); } 100% { transform: scale(1); } }
@media (prefers-reduced-motion: reduce) {
  .mo-badge.is-pop { animation: none; }
}
```

```js
const badge = document.querySelector('.mo-badge');
let count = 0;
document.querySelector('.mo-add').addEventListener('click', () => {
  count += 1;
  badge.textContent = count;
  badge.hidden = false;
  badge.classList.remove('is-pop');
  void badge.offsetWidth; // 続けて押したときも再生し直す
  badge.classList.add('is-pop');
});
```
