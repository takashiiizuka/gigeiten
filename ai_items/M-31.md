# M-31 ローテートイン（Rotate in）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：出現・退場
- 別名：回転しながら出現
- 定義：回転しながら定位置に収まる出現。
- 使う場面：ロゴや記号の登場、遊びのある演出。
- 注意：回転は目で追いにくい。読ませる文章には使わない。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：Animate.css — A cross-browser library of CSS animations https://animate.style/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：ロゴや記号が表示されるとき
- 変える値：transform: rotate(-90deg) scale(0.8) → rotate(0) scale(1)、opacity 0 → 1
- 時間の例：400〜600ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：回転をやめ、150ms 程度の不透明度の変化だけで表示する
- 技術：CSS
- 補足：回転角は 90 度前後にとどめ、文章や読ませる文字を含む要素には使わない。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<div class="mo-mark" role="img" aria-label="ロゴ"></div>
```

```css
.mo-mark { width: 64px; height: 64px; border-radius: 12px;
  background: conic-gradient(#2b6cb0 0 25%, #9cc3e6 0 50%, #2b6cb0 0 75%, #9cc3e6 0);
  animation: mo-rotate-in 500ms cubic-bezier(0.2, 0, 0, 1) both; }
@keyframes mo-rotate-in { from { opacity: 0; transform: rotate(-90deg) scale(0.8); } }
@keyframes mo-fade-in { from { opacity: 0; } }
@media (prefers-reduced-motion: reduce) {
  .mo-mark { animation: mo-fade-in 150ms linear both; }
}
```
