# M-25 ホバーエフェクト（Hover effect）

- 分野：動き・モーション／目的：操作・体験を分かりやすくする
- 動きの分類：操作への反応
- 別名：なし
- 定義：ポインターが重なったときに見た目を変える表現。
- 使う場面：操作可能性の手がかり。
- 注意：タッチやキーボードでも情報と操作へ到達できるようにする。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：MDN — :hover https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/:hover
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-19、v2から）

## 作り方（例）

- きっかけ：ポインターが重なったとき（:hover）。キーボードのフォーカス（:focus-visible）でも同等の手がかりを出す
- 変える値：枠線の色、影、transform: translateY(-2px)
- 時間の例：150〜200ms
- 動き方の例：減速（ease-out）
- 動きを減らす設定のとき：浮き上がりの移動をやめ、色と影の変化だけにする
- 技術：CSS
- 補足：ホバー時の変化は @media (hover: hover) の中に書き、情報や操作はホバーしなくても届く場所に置く。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<a class="mo-card" href="#detail">商品Aの詳細<span>価格と在庫はホバーしなくても表示する</span></a>
```

```css
.mo-card { display: block; width: 240px; padding: 16px; border: 1px solid #ccd; border-radius: 8px; color: inherit; text-decoration: none;
  transition: transform 180ms ease-out, box-shadow 180ms ease-out, border-color 180ms ease-out; }
.mo-card span { display: block; margin-top: 4px; font-size: 13px; color: #555; }
@media (hover: hover) {
  .mo-card:hover { transform: translateY(-2px); box-shadow: 0 6px 16px rgb(0 0 0 / 0.12); border-color: #2b6cb0; }
}
.mo-card:focus-visible { outline: 3px solid #2b6cb0; outline-offset: 2px; }
@media (prefers-reduced-motion: reduce) {
  .mo-card, .mo-card:hover { transform: none; }
}
```
