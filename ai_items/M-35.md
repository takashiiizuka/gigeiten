# M-35 行のせり上がり（Line mask reveal）

- 分野：動き・モーション／目的：見た目・印象を整える
- 動きの分類：文字
- 別名：テキストリビール、行ごとのリビール
- 定義：行ごとに、見えない枠の下から文字がせり上がって現れる表現。
- 使う場面：ブランドサイトの見出し、映像のテロップ。
- 注意：行の区切りは画面幅で変わる。改行位置が変わっても成り立つかを確認する。
- 用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。
- 出典：GSAP — SplitText https://gsap.com/docs/v3/Plugins/SplitText/
- 向いている媒体：LP・Webサイト（主）、スライド・講演（副）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-27、2026.09.6から）

## 作り方（例）

- きっかけ：見出しが画面に入ったとき（IntersectionObserver で1回だけ）
- 変える値：各行の中身の translateY 110% → 0（行の枠を overflow: hidden で切り抜く）
- 時間の例：1行あたり700ms、行ごとの時間差80ms
- 動き方の例：減速（cubic-bezier(0.2, 0, 0, 1)）
- 動きを減らす設定のとき：せり上がりを省き、全行をその場で表示する
- 技術：CSS + JavaScript
- 補足：行を手で区切っておくと、狭い画面で1行が折り返しても、その行はまとまってせり上がる。
- 値とコードは例。案件の既存仕様・ブランドの動きの規定があれば、そちらを優先する。

```html
<h2 class="mo-lines">
  <span class="mo-line"><span>行ごとに</span></span>
  <span class="mo-line" style="--i: 1"><span>下からせり上がる見出し</span></span>
</h2>
```

```css
.mo-line { display: block; overflow: hidden; padding-bottom: 0.1em; }
.mo-line > span { display: block; }
.mo-lines.mo-ready .mo-line > span { transform: translateY(110%); }
.mo-lines.mo-in .mo-line > span {
  transform: none;
  transition: transform 700ms cubic-bezier(0.2, 0, 0, 1) calc(var(--i, 0) * 80ms);
}
```

```js
const el = document.querySelector('.mo-lines');
// 動きを減らす設定では何もしない（文字は最初から見えている）
if (!matchMedia('(prefers-reduced-motion: reduce)').matches) {
  el.classList.add('mo-ready');
  new IntersectionObserver(([e], io) => {
    if (e.isIntersecting) { el.classList.add('mo-in'); io.disconnect(); }
  }).observe(el);
}
```
