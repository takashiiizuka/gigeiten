# D-55 直接ラベル（Direct labeling）

- 分野：データの図表／目的：読みやすさ・使いやすさを守る
- 別名：ダイレクトラベリング、ダイレクトラベル、凡例なし、系列ラベル
- 定義：凡例を使わず、線や棒のすぐ横に系列名や値を書く方法。
- 使う場面：系列の少ない折れ線や棒グラフで、凡例との見比べを減らす。
- 注意：系列が多く重なるときは位置を調整するか、スモールマルチプルにする。色だけでなく名前でも区別する。
- 用意する情報：系列名（短い表記）と、線の端などに載せる値。
- 見本の読み方（架空の数値）：左は凡例と線を見比べる必要があり、右は線の端に名前を書いています。値は架空です。
- 出典：Datawrapper Blog — What to consider when using text in data visualizations https://www.datawrapper.de/blog/text-in-data-visualizations
- 向いている媒体：資料・提案書（主）、スライド・講演（主）、LP・Webサイト（副）、画像・バナー（副）、図解・グラフ（主）（AIの編集判断・未確認）
- 状態：収録済み（収録 2026-09-26、2026.09.3から）
- v1の対応項目：P-05 ダイレクトラベリング（対応：一致。ダイレクトラベリング＝直接ラベル（2026.09.3で戻した））
  - v1の依頼例：凡例は使わず、各系列の右端に直接ラベルを置いて（ダイレクトラベリング）。ラベルの文字色を線の色と一致させて。
