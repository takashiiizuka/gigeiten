# GIGEITEN（伎芸天）デザインと無料フォントの図鑑

資料・スライド・LP・画像・図解を作るときに、「何を作るか」から、使える図やレイアウト、書体、配色、注意点を選べる図鑑です。デザインの用語 335 項目、目的別40種類の図の早見表、無料フォントの索引 1,960 項目（実際の字形の見本 173 書体）を収めています。

データ版：2026.09.3

## 見る

- ブラウザで開く：（公開後に決まります）
- 手元に保存して使う：このリポジトリの `index.html` を保存し、Chrome・Edge・Safari で開く（インストール不要、オフラインで動く）

お気に入りと依頼の候補は、見ている人のブラウザにだけ保存されます。

## Claude Code などのAIから使う

AIが制作のときに図鑑を参照できるよう、AI向けの索引（`ai/`・`ai_items/`）と手順（`AI_GUIDE.md`）を入れています。HTMLを丸ごと読ませる必要はありません。

1. リポジトリを手元に置く（更新は `git pull`）

   ```bash
   git clone （公開後に決まります）
   ```

2. 自分の CLAUDE.md などに、次のように書き足す（パスは置いた場所に合わせる）

   ```text
   ## デザイン図鑑 GIGEITEN
   資料・スライド・LP・画像・図解の制作では、<置いた場所>/gigeiten/AI_GUIDE.md の手順で、
   必要な索引と項目だけを読んで表現を選ぶ。参照した項目と理由を制作メモに残す。
   ```

手元に置かずに、Web上のファイルを直接読ませることもできます（例：（公開後に決まります）/AI_GUIDE.md）。ただし、ツールによっては要約されて細部が落ちるため、手元に置く方法をおすすめします。

## 内容について

- 図の見本はこの図鑑のために作った模式図で、数値はすべて架空です。
- 各項目の出典は、定義や使い方を確かめるための資料です。「使う場面」「注意」などには編集上の判断を含みます。
- 同梱のフォントは、それぞれのライセンス（SIL Open Font License など）に従います。著作権表示とライセンス全文は `index.html` の中にあります。
- この図鑑の文章と見本図は、閲覧と制作の参考にすることは自由です。転載・再配布はご遠慮ください。
