# 動き・モーション（データ版 2026.09.7）

用意する情報（分野共通）：何を変化させるか、始点・終点、きっかけ、時間、動き方、停止方法。静止状態でも情報を伝えます。

- M-01 フェードイン（Fade in）〔フェード、フェイド〕｜分類：出現・退場｜使う場面：新しい内容の出現。｜注意：読ませる情報の表示を長く遅らせない。
- M-02 フェードアウト（Fade out）｜分類：出現・退場｜使う場面：不要になった補助情報の退場。｜注意：見えなくした要素を操作対象として残さない。
- M-03 スライドイン（Slide in）｜分類：出現・退場｜使う場面：パネルや関連情報の出現。｜注意：大きな移動や多数の同時移動を避ける。
- M-04 スケール（Scale transition）｜分類：出現・退場｜使う場面：要素の出現や選択状態。｜注意：内容の重要度や数値が変わったと誤認させない。
- M-05 スタガー（Stagger）〔順番、遅延、時間差〕｜分類：出現・退場｜使う場面：項目の順序やまとまりの提示。｜注意：項目数が増えても待ち時間が過大にならないようにする。
- M-06 クロスフェード（Crossfade）｜分類：画面の転換｜使う場面：同じ場所の内容の交換。｜注意：途中で文字が重なって読みにくくなりやすい。
- M-07 マスクリビール（Mask reveal）〔リビール、リヴィール〕｜分類：出現・退場｜使う場面：図版や見出しの出現。｜注意：隠れている間も読み上げ順を適切にする。
- M-08 ワイプ（Wipe transition）｜分類：画面の転換｜使う場面：状態の切り替えを方向とともに示す。｜注意：方向に誤った時間や階層の意味を与えない。
- M-09 線描画アニメーション（Line drawing animation）｜分類：線・図形｜使う場面：手順や接続の順序を説明する。｜注意：グラフでは描画速度をデータの速度と誤認させない。
- M-10 モーフィング（Morphing）｜分類：線・図形｜使う場面：関連する形や状態の連続性。｜注意：全く異なる意味の対象を同一物に見せない。
- M-11 共有要素トランジション（Shared-element transition）｜分類：画面の転換｜使う場面：一覧から詳細への移動。｜注意：内容の同一性とフォーカス移動を確保する。
- M-12 FLIP（First, Last, Invert, Play）｜分類：画面の転換｜使う場面：並び替えなどの位置変化。｜注意：変形の scale で補うため、途中で文字や角丸がゆがむことがある。
- M-13 スプリング（Spring animation）｜分類：動きの原理｜使う場面：直接操作に対する応答。｜注意：全てのスプリングが同じ時間で止まるわけではない。
- M-14 オーバーシュート（Overshoot）｜分類：動きの原理｜使う場面：弾力感のある短い応答。｜注意：位置や数値の最終値を誤認させない。
- M-15 パララックス（Parallax scrolling）｜分類：スクロール｜使う場面：物語的なページの演出。｜注意：前庭感覚への負担に配慮し、抑制できるようにする。
- M-16 スクロールトリガー（Scroll-triggered animation）｜分類：スクロール｜使う場面：セクションの出現。｜注意：スクロール位置が再生位置そのものを決める方式とは異なる。
- M-17 スクロール駆動（Scroll-driven animation）｜分類：スクロール｜使う場面：読了率や図解の段階的な説明。｜注意：対応ブラウザと動きを抑えた代替表示を用意する。
- M-18 進捗アニメーション（Progress animation）｜分類：状態・読み込み｜使う場面：処理の進行。｜注意：実際の進捗とアニメーション上の補間を区別する。
- M-19 カウントアップ（Count-up animation）｜分類：データ｜使う場面：数値更新への注意喚起。｜注意：最終値をすぐ読める手段を用意し、架空の増加を実績と見せない。
- M-20 データトランジション（Data transition）｜分類：データ｜使う場面：期間や条件を変更した結果の理解。｜注意：軸の変更と値の変更を混同させない。
- M-21 イージング（Easing）〔イーズ、速度、加速度〕｜分類：動きの原理｜使う場面：加速・減速の印象を調整する。｜注意：CSSの既定値は ease で、等速ではない。登場は減速、退場は加速を基本にする。
- M-22 デュレーション（Duration）｜分類：動きの原理｜使う場面：速度感の指定。｜注意：同じ時間でも移動距離が違えば印象は変わる。
- M-23 ディレイ（Delay）｜分類：動きの原理｜使う場面：順序の表現。｜注意：応答がないと誤認される長さを避ける。
- M-24 マイクロインタラクション（Microinteraction）｜分類：操作への反応｜使う場面：保存・切り替え・入力への応答。｜注意：装飾的なアニメーションだけを指すわけではない。
- M-25 ホバーエフェクト（Hover effect）｜分類：操作への反応｜使う場面：操作可能性の手がかり。｜注意：タッチやキーボードでも情報と操作へ到達できるようにする。
- M-26 フォーカス表示（Focus indicator）｜分類：操作への反応｜使う場面：位置を見失わず操作する。｜注意：outlineを消したままにせず、背景と区別できる輪郭を必ず見せる。
- M-27 退場トランジション（Exit transition）｜分類：出現・退場｜使う場面：削除やパネルを閉じる操作。｜注意：アニメーション中の二重操作やフォーカス喪失を防ぐ。
- M-28 リデューストモーション（Reduced motion）｜分類：動きの原理｜使う場面：動きに負担を感じる利用者への対応。｜注意：単に速くするだけでなく、静的な代替を考える。
- M-29 ブラーイン（Blur in）〔ぼかしから出現、フォーカスイン〕｜分類：出現・退場｜使う場面：見出しや写真の登場を、やわらかく見せる。｜注意：ぼかしは描画の負荷が高い。文字をぼかしたまま長く待たせない。
- M-30 ポップイン（Pop in）〔バックイン、ズームイン〕｜分類：出現・退場｜使う場面：通知の数、バッジ、追加された項目。｜注意：多用すると画面が騒がしくなる。重要な変化だけに使う。
- M-31 ローテートイン（Rotate in）〔回転しながら出現〕｜分類：出現・退場｜使う場面：ロゴや記号の登場、遊びのある演出。｜注意：回転は目で追いにくい。読ませる文章には使わない。
- M-32 バウンス（Bounce）〔バウンド、跳ねる〕｜分類：出現・退場｜使う場面：落ちてくる要素、楽しさを出したい場面。｜注意：跳ねる回数が多いと待ち時間になる。業務画面では控えめにする。
- M-33 タイプライター（Typewriter）〔タイピング、1文字ずつ〕｜分類：文字｜使う場面：見出しの導入、会話や入力の再現。｜注意：全文が出るまで読めない。長い文には使わず、読み上げでは全文が伝わるようにする。
- M-34 文字ごとの時間差（Per-character stagger）〔スプリットテキスト、SplitText〕｜分類：文字｜使う場面：タイトル、キャッチコピーの登場。｜注意：分割した文字が読み上げで1字ずつ読まれないよう、元の文を残す。
- M-35 行のせり上がり（Line mask reveal）〔テキストリビール、行ごとのリビール〕｜分類：文字｜使う場面：ブランドサイトの見出し、映像のテロップ。｜注意：行の区切りは画面幅で変わる。改行位置が変わっても成り立つかを確認する。
- M-36 テキストスクランブル（Text scramble）〔デコード、シャッフル〕｜分類：文字｜使う場面：テクノロジー系の見出し、数値や暗号の演出。｜注意：確定するまで読めない。短い語に限り、読み上げには最終の文字を渡す。
- M-37 キネティックタイポグラフィ（Kinetic typography）〔モーションタイポグラフィ、動く文字〕｜分類：文字｜使う場面：ブランド映像、会社紹介、音楽に合わせた映像。｜注意：読み切れる時間を残す。字幕として使う場合は表示時間を確保する。
- M-38 マーキー（流れる文字）（Marquee / ticker）〔ティッカー、テロップ、電光掲示板〕｜分類：文字｜使う場面：お知らせ、ニュースの見出し、ロゴの帯。｜注意：5秒を超えて自動で動く場合は、止める手段を付ける（WCAG 2.2.2）。重要な情報を流すだけにしない。
- M-39 マーカーの強調（Animated highlight）〔アンダーライン、手書きの注釈〕｜分類：文字｜使う場面：資料の結論、LPの要点。｜注意：1画面に1〜2か所まで。色だけに頼らず、文でも強調を示す。
- M-40 文字の波（Wave text）〔ウェーブテキスト〕｜分類：文字｜使う場面：読み込み中の表示、遊びのある見出し。｜注意：動き続ける文字は読みにくい。本文や操作の説明には使わない。
- M-41 流れる破線（Dash flow）〔マーチングアンツ、流れる線〕｜分類：線・図形｜使う場面：データや作業の流れ、接続中の状態、選択範囲。｜注意：向きの意味を凡例や矢印でも示す。速すぎるとちらつく。
- M-42 モーションパス（Motion path）〔パスアニメーション、経路に沿った動き〕｜分類：線・図形｜使う場面：配送や移動の経路、手順のつながり。｜注意：経路そのものも薄く見せると、動きの意味が伝わりやすい。
- M-43 軌道運動（Orbit）〔周回、公転〕｜分類：線・図形｜使う場面：中心と周辺の関係、エコシステムの説明。｜注意：回り続ける要素は注意を引き続ける。止める手段を用意する。
- M-44 パルス（波紋）（Pulse / ping）〔波紋、レーダー、ピン〕｜分類：線・図形｜使う場面：現在地、新着、録画中など、注目してほしい一点。｜注意：1画面に1か所まで。点滅に近い速さにしない。
- M-45 メタボール（液状の融合）（Metaballs / gooey effect）〔グーイー、リキッド〕｜分類：線・図形｜使う場面：メニューの展開、つながりや合流の演出。｜注意：形の境界がぼやけるので、押せる範囲を別に明示する。
- M-46 粒子の集合（Particle assembly）〔パーティクル、粒子で形成、集まる〕｜分類：粒子・生成｜使う場面：ロゴやタイトルの登場、多くの要素が一つにまとまる説明。｜注意：粒子の数が多いと重くなる。完成した形を静止画でも用意する。
- M-47 粒子への分解（Particle disintegration）〔ディスインテグレート、散る、崩れる〕｜分類：粒子・生成｜使う場面：ロゴの退場、消える・変わることの演出。｜注意：消える意味を持つので、残すべき情報には使わない。
- M-48 バースト（弾ける粒子）（Particle burst）〔いいねの弾け、エクスプロージョン〕｜分類：粒子・生成｜使う場面：いいね、お気に入り、完了などの短い反応。｜注意：0.5秒前後で終える。毎回の操作に付けると煩わしい。
- M-49 紙吹雪（Confetti）〔コンフェッティ、お祝い〕｜分類：粒子・生成｜使う場面：達成、購入完了、お祝いの画面。｜注意：一度きりにする。操作の邪魔にならないよう、手前の要素を押せる状態に保つ。
- M-50 点と線のネットワーク（Particle links）〔パーティクルリンク、星座〕｜分類：粒子・生成｜使う場面：ネットワーク、つながり、テクノロジーの背景。｜注意：背景に使うときは文字の読みやすさを先に確認する。
- M-51 フローフィールド（Flow field）〔流れ場、生成アート〕｜分類：粒子・生成｜使う場面：背景の生成アート、流れや風の表現。｜注意：描画が重い。画面外では止め、静止画でも成り立つようにする。
- M-52 群れの動き（ボイド）（Flocking (boids)）〔ボイド、群知能〕｜分類：粒子・生成｜使う場面：群衆や市場の動き、自律的な振る舞いの説明。｜注意：動きが予測しにくい。説明に使うときは規則を文で添える。
- M-53 ワープ（星の流れ）（Starfield / warp）〔スターフィールド、ハイパースペース〕｜分類：粒子・生成｜使う場面：場面転換、スピード感や未来感の演出。｜注意：画面全体が動くので、酔いやすい人に配慮し短く使う。
- M-54 きらめき（Sparkle）〔キラキラ、トゥインクル〕｜分類：粒子・生成｜使う場面：新着、特別感、ロゴの周り。｜注意：強い点滅にしない。瞬く数を少なく保つ。
- M-55 降る粒子（Falling particles）〔雪、雨、パーティクル〕｜分類：粒子・生成｜使う場面：季節の演出（雪・雨・花びら）、背景。｜注意：文字の上を粒子が横切ると読みにくい。量と範囲を絞る。
- M-56 ノイズの波（Noise-driven motion）〔パーリンノイズ、有機的な動き〕｜分類：粒子・生成｜使う場面：背景の動き、有機的な印象の演出。｜注意：背景として控えめにし、内容より目立たせない。
- M-57 アイリス（Iris transition）〔アイリスイン、円形ワイプ〕｜分類：画面の転換｜使う場面：映像の場面転換、注目点への導入。｜注意：古典的な印象が強い。多用しない。
- M-58 スプリット（分割の開き）（Split / barn doors）〔観音開き、バーンドア〕｜分類：画面の転換｜使う場面：場面の大きな切り替え、発表の演出。｜注意：開く向きに意味を持たせるなら、全体でそろえる。
- M-59 ブロックディゾルブ（Block dissolve）〔ディゾルブ、ピクセル転換、ディザ〕｜分類：画面の転換｜使う場面：映像の場面転換、時間の経過。｜注意：細かい粒が画面全体でちらつく。短い時間で終える。
- M-60 プッシュ（Push）〔押し出し〕｜分類：画面の転換｜使う場面：スライドの送り、手順の前後の移動。｜注意：押し出す向きを、進む・戻るの意味とそろえる。
- M-61 ズームトランジション（Zoom transition）〔クロスズーム、ズームイン転換〕｜分類：画面の転換｜使う場面：階層を深く入る移動、場面の転換。｜注意：拡大は酔いやすい。動きを減らす設定では切り替えにする。
- M-62 共有軸の遷移（Shared axis）〔シェアードアクシス〕｜分類：画面の転換｜使う場面：手順の前後、タブの左右の移動。｜注意：軸の向き（左右・上下・奥行き）を画面の関係と一致させる。
- M-63 フェードスルー（Fade through）〔フェードスルー遷移〕｜分類：画面の転換｜使う場面：関係の薄い画面どうしの切り替え（下部タブなど）。｜注意：つながりを示したい画面には、共有要素の遷移を使う。
- M-64 ピン留め（Pinning）〔スクロール固定、スティッキー区間〕｜分類：スクロール｜使う場面：製品の特長の順番紹介、手順の説明。｜注意：固定区間が長いとスクロールが空回りに感じる。区間の長さを抑える。
- M-65 横スクロール演出（Horizontal scroll section）〔横スクロール、水平スクロール〕｜分類：スクロール｜使う場面：事例の一覧、年表、工程。｜注意：縦に読む前提が崩れる。今どこにいるかを表示する。
- M-66 スクロリーテリング（Scrollytelling）〔スクロールで語る〕｜分類：スクロール｜使う場面：データ報道、調査報告、製品の仕組みの説明。｜注意：図だけ・文章だけでも意味が通るようにする。印刷や静止画の代替を用意する。
- M-67 読み進みの表示（Scroll progress indicator）〔読了インジケーター、プログレスバー〕｜分類：スクロール｜使う場面：長い記事、規約、マニュアル。｜注意：目立たせすぎない。上端の細い線程度にする。
- M-68 リップル（Ripple）〔インクリップル、タッチフィードバック〕｜分類：操作への反応｜使う場面：ボタン、リスト項目、カードなどの押下。｜注意：波紋が文字の読みやすさを下げない濃さにする。
- M-69 マグネティック（Magnetic hover）〔吸い付くボタン、マグネットボタン〕｜分類：操作への反応｜使う場面：ブランドサイトの主要ボタン、遊びのある操作。｜注意：タッチ操作では起きない。押せる範囲が動いて押しにくくならないようにする。
- M-70 カーソル追従（Cursor follower）〔カスタムカーソル、カーソルストーカー〕｜分類：操作への反応｜使う場面：ブランドサイト、作品集の演出。｜注意：標準のポインターを隠さない。操作の対象が分かりにくくならないようにする。
- M-71 3Dチルト（Perspective tilt）〔チルト、パララックスカード〕｜分類：操作への反応｜使う場面：商品カード、作品の一覧。｜注意：傾きは小さく。タッチ操作や動きを減らす設定では止める。
- M-72 慣性（Inertia / momentum）〔モメンタム、フリック〕｜分類：操作への反応｜使う場面：スクロール、カルーセル、地図の移動。｜注意：止まる位置が予測しにくい。区切りの位置に吸い付かせる場合は明示する。
- M-73 シェイク（Shake）〔首振り、横揺れ〕｜分類：操作への反応｜使う場面：パスワードの誤り、入力エラー。｜注意：揺れだけでは理由が分からない。誤りの内容を文で示す。
- M-74 引っ張って更新（Pull to refresh）〔プルトゥリフレッシュ〕｜分類：操作への反応｜使う場面：タイムライン、受信箱、通知の一覧。｜注意：引いている量と、更新が始まる位置を見て分かるようにする。
