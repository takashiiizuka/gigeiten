# 文字・タイポグラフィ（データ版 2026.09.6）

用意する情報（分野共通）：言語、本文の量、見出し階層、閲覧距離、使用可能な書体。端末やフォントによる差も確認します。

- T-01 セリフ体（Serif）｜使う場面：見出しや長文の表情を調整する。｜注意：明朝体に近い役割を持ち、和欧混植で組み合わせやすいが、分類としては別のもの。
- T-02 サンセリフ体（Sans serif）｜使う場面：UIや説明文。｜注意：書体名だけで可読性は決まらない。
- T-03 明朝体（Mincho）｜使う場面：和文の見出しや読み物。｜注意：細い線が小サイズや低解像度で消えないか確認する。
- T-04 ゴシック体（Gothic / Japanese sans serif）｜使う場面：資料の本文やUI。｜注意：ウエイトや字面によって読みやすさが変わる。
- T-05 等幅書体（Monospaced typeface）｜使う場面：コード・識別子・桁を揃える表示。｜注意：和欧混植では各文字が同幅になるとは限らない。
- T-06 フォントウエイト（Font weight）｜使う場面：見出し・本文・強調の差をつける。｜注意：細すぎる文字でコントラストを失わない。
- T-07 タイプスケール（Type scale）｜使う場面：ページ全体の文字の階層。｜注意：単一の倍率が全媒体で最適という規則はない。
- T-08 行間（Line height / Leading）〔行送り〕｜使う場面：長文の読みやすさを整える。｜注意：文字サイズ・行長・言語に応じて調整する。
- T-09 字間（Letter spacing / Tracking）｜使う場面：大見出しや短いラベル。｜注意：和文本文や長文で過度に広げない。
- T-10 カーニング（Kerning）｜使う場面：ロゴや大きな欧文見出し。｜注意：文字列全体の字間とは区別する。
- T-11 行長（Measure / Line length）｜使う場面：長文の本文幅の設計。｜注意：英語の目安（45〜90字）を日本語に当てはめない。和文の横組は1行40字程度までが目安とされる。
- T-12 禁則処理（Line breaking rules）｜使う場面：日本語の本文と見出し。｜注意：手動改行だけで調整すると画面幅変更で崩れる。
- T-13 ぶら下げ組み（Hanging punctuation）｜使う場面：字間を詰めたり空けたりする行の調整を減らす。｜注意：CSSの hanging-punctuation は一部のブラウザでしか効かない。
- T-14 ルビ（Ruby annotation）｜使う場面：読み方が難しい用語の説明。｜注意：小さすぎるルビと行間の衝突を避ける。
- T-15 ベースライン（Baseline）｜使う場面：文字サイズやアイコンの位置を揃える。｜注意：g・pなどは線より下へ伸び、和文の字面も下にはみ出す。和欧混植では位置を目で確かめる。
- T-16 xハイト（X-height）｜使う場面：同じサイズの書体の見かけを比べる。｜注意：数値上のフォントサイズだけでは大きさを比較できない。
- T-17 ライニング数字（Lining numerals）｜使う場面：見出しや数値表示。｜注意：等幅数字とは別の性質。
- T-18 オールドスタイル数字（Oldstyle numerals）｜使う場面：欧文の本文になじませる。｜注意：表の数値比較には向かない場合がある。
- T-19 等幅数字（Tabular numerals）｜使う場面：金額・時刻・変化するKPIの桁揃え。｜注意：使用フォントが対応している必要がある。
- T-20 可変フォント（Variable font）｜使う場面：細かい見た目や表示条件への対応。｜注意：使用できる軸はフォントによって異なる。
- T-21 ドロップキャップ（Drop cap / Initial letter）｜使う場面：雑誌的な記事の導入。｜注意：読み順やブラウザ対応を確認する。
- T-22 流動的タイポグラフィ（Fluid typography）｜使う場面：大見出しを複数幅で整える。｜注意：最小・最大値とズーム時の可読性を確認する。
- T-23 フォントペアリング（Font pairing）｜使う場面：役割の違いと統一感を作る。｜注意：使用書体の数を増やすだけでは洗練されない。
- T-24 アイブロウ（Eyebrow / Kicker）｜使う場面：記事のカテゴリや章の位置付け。｜注意：本文の重要な主張を小さい文字だけで伝えない。
- T-25 リード文（Lead / Standfirst）｜使う場面：読む価値と文脈の提示。｜注意：見出しを長く繰り返すだけにしない。
- T-26 キャプション（Caption）｜使う場面：図の意味と条件を補足する。｜注意：出典だけで意味の説明を代用しない。
- T-27 アセンダー・ディセンダー（Ascender / Descender）｜使う場面：字形の違いや行間の検討。｜注意：ベースラインや大文字の高さとは異なる。
- T-28 カウンター（Counter）｜使う場面：小さい文字や太い書体の読みやすさの確認。｜注意：太くして空間をつぶさない。
- T-29 ウィドウ・オーファン（Widows / Orphans）｜使う場面：長文の印刷や段組み。｜注意：定義は文脈で揺れる。CSSの widows・orphans は、段やページの境目に残す最小の行数を指定する。
- T-30 ジオメトリックサンセリフ（Geometric sans serif）｜使う場面：見出しの表情の指定。｜注意：ヒューマニストやグロテスクなどとの境界は書体によって曖昧。
