# UIパターン（データ版 2026.09.3）

用意する情報（分野共通）：利用者の目的、操作の前後の状態、入力条件、エラー時の挙動。キーボードと狭い画面でも確認します。

- U-01 ボタン（Button）｜使う場面：保存・再生・絞り込み。｜注意：移動用リンクとの役割を分ける。
- U-02 リンク（Link）｜使う場面：ページや出典への移動。｜注意：リンクの文言から移動先が分かるようにする。
- U-03 タブ（Tabs）｜使う場面：関連情報を並列に切り替える。｜注意：全内容を比較したいときは隠すことが不利になる。
- U-04 アコーディオン（Accordion）｜使う場面：補足やFAQ。｜注意：重要情報を全て閉じ込めない。
- U-05 モーダルダイアログ（Modal dialog）｜使う場面：確認や詳細編集。｜注意：フォーカス管理、閉じる手段、元の位置への復帰が必要。
- U-06 ドロワー（Drawer）｜使う場面：メニューや設定。｜注意：モーダルか非モーダルかを決め、操作を設計する。
- U-07 ポップオーバー（Popover）｜使う場面：補足説明や軽い操作。｜注意：閉じ方とフォーカスの挙動を確認する。
- U-08 ツールチップ（Tooltip）｜使う場面：アイコンの補足。｜注意：必須情報やタッチで必要な説明をこれだけに置かない。
- U-09 パンくずリスト（Breadcrumb）｜使う場面：深い階層のサイト。｜注意：閲覧履歴そのものとは区別する。
- U-10 ステッパー（Stepper）｜使う場面：申込や設定ウィザード。｜注意：将来のステップへ移動できるか明示する。
- U-11 ページネーション（Pagination）｜使う場面：長い検索結果。｜注意：現在のページと総量を示す。
- U-12 無限スクロール（Infinite scrolling）｜使う場面：連続的なフィード閲覧。｜注意：位置の復元やフッターへの到達を妨げやすい。
- U-13 もっと見る（Load more）｜使う場面：量の多い一覧を段階的に見る。｜注意：残りの件数や現在の表示量を示す。
- U-14 ファセット検索（Faceted search）｜使う場面：商品や用語の探索。｜注意：条件の解除と該当件数を分かりやすくする。
- U-15 オートコンプリート（Autocomplete (editable combobox)）｜使う場面：名称や住所の入力補助。｜注意：キーボード操作と候補読み上げを設計する。
- U-16 チェックボックス（Checkbox）｜使う場面：複数選択。｜注意：複数から一つだけ選ばせる場合は、ラジオボタンの方が明確。
- U-17 ラジオボタン（Radio group）｜使う場面：排他的な条件選択。｜注意：同じグループを視覚と意味の両方でまとめる。
- U-18 スイッチ（Switch）｜使う場面：即時に反映する設定のオン・オフ。｜注意：現在状態か実行後の状態かが曖昧なラベルを避ける。
- U-19 スライダー（Slider）｜使う場面：音量やプレビュー速度。｜注意：厳密な値には数値入力も用意する。
- U-20 セレクト（Select）｜使う場面：選択肢が多い単一選択。｜注意：候補が少なければ一覧表示の方が選びやすい場合がある。
- U-21 テキスト入力（Text input）｜使う場面：名前や検索語。｜注意：プレースホルダーをラベルの代わりにしない。
- U-22 フォームバリデーション（Form validation）｜使う場面：申込や登録。｜注意：何が問題でどう直せるかを具体的に伝える。
- U-23 エラーサマリー（Error summary）｜使う場面：長いフォームの修正。｜注意：該当する入力欄への移動手段を用意する。
- U-24 トースト（Toast / Snackbar）｜使う場面：保存完了などの補助的な通知。｜注意：重要なエラーや必要な操作をすぐ消さない。
- U-25 アラート（Alert）｜使う場面：エラーや変更の通知。｜注意：頻発すると重要な通知が埋もれる。
- U-26 スケルトンスクリーン（Skeleton screen）｜使う場面：データ読込中の待ち時間。｜注意：実際のコンテンツと誤認させず、動きを抑える設定に対応する。
- U-27 プログレスバー（Progress bar）｜使う場面：進捗が測れる処理。｜注意：測れない処理に架空の進捗率を表示しない。
- U-28 空の状態（Empty state）｜使う場面：初回利用や検索結果なし。｜注意：原因と次の行動を分けて伝える。
- U-29 データテーブル（Data table）｜使う場面：正確な値の比較。｜注意：見出しと単位、桁揃えを設計する。
- U-30 ツリービュー（Tree view）｜使う場面：フォルダや分類の操作。｜注意：単純なナビゲーションに複雑な操作を持ち込まない。
- U-31 カルーセル（Carousel）｜使う場面：横に連なる事例の閲覧。｜注意：自動切替は停止できるようにし、重要内容を隠さない。
- U-32 コマンドパレット（Command palette）｜使う場面：機能が多いアプリの操作短縮。｜注意：初心者が発見できる通常の導線も残す。
- U-33 チップ（Chip）｜使う場面：タグ・絞り込み条件の表示。｜注意：押せるのか削除できるのかを明確にする。
- U-34 バッジ（Badge）｜使う場面：未読数や更新状態。｜注意：色だけで状態を伝えず、数字や記号も添える。
- U-35 メガメニュー（Mega menu）｜使う場面：情報量の多いサイトの案内。｜注意：キーボード操作や意図しない開閉に注意する。
- U-36 アバター（Avatar）｜使う場面：投稿者や担当者の識別。｜注意：顔写真がない場合も識別できる名前を添える。
- U-37 KPIカード（KPI card / Stat tile / Big number）〔ビッグナンバー、BAN、大きな数字、数字の強調〕｜使う場面：ダッシュボードの主要な成果。｜注意：単位、対象期間、比較基準がないと意味を読み違える。
- U-38 CTA（Call to action）｜使う場面：資料請求や申込などの主要な導線。｜注意：行動後に何が起きるか具体的に伝える。
- U-39 セグメンテッドコントロール（Segmented control）｜使う場面：短い並列の選択肢。｜注意：タブと似ていても役割が同じとは限らない。
- U-40 社会的証明（Social proof）〔お客様の声、利用者の声、レビュー、導入事例〕｜使う場面：LPや商品ページで、初めての人の不安を減らす。｜注意：実在し確認できる声と数値だけを、許可を得て使う。広告であることを隠さず、期間や条件を添える。
