# 色・配色（データ版 2026.09.3）

用意する情報（分野共通）：ブランド色、背景色、系列や状態の意味。文字と背景、隣接した系列を実際の色の組み合わせで確認します。

- C-01 色相（Hue）｜使う場面：系列やブランドの色の方向を選ぶ。｜注意：色相だけで情報を区別しない。
- C-02 明度（Lightness）｜使う場面：情報の強弱や階層。｜注意：同じ数値でも色空間をまたいで直接比較しない。
- C-03 彩度・クロマ（Saturation / Chroma）｜使う場面：強調色と背景色を調整する。｜注意：両者をあらゆる色空間で同じ値として扱わない。
- C-04 単色配色（Monochromatic palette）｜使う場面：落ち着いた統一感。｜注意：系列数が多いと区別が難しい。
- C-05 類似色配色（Analogous palette）｜使う場面：自然なつながりのある印象。｜注意：隣接要素の区別を明るさやラベルで補う。
- C-06 補色配色（Complementary palette）｜使う場面：対比や強調。｜注意：使う色相環によって補色の組が変わる。
- C-07 三色配色（Triadic palette）｜使う場面：複数の役割を明確に分ける。｜注意：三色を同じ面積で使う必要はない。
- C-08 アクセントカラー（Accent color）｜使う場面：主操作や重要な数値の強調。｜注意：あらゆる場所に使うと強調にならない。
- C-09 セマンティックカラー（Semantic color）｜使う場面：UIの状態を伝える。｜注意：色だけで意味を伝えず文字や形も添える。
- C-10 カテゴリ配色（Categorical palette）｜使う場面：商品や部署の系列。｜注意：色に大小や順序の意味を持たせない。
- C-11 連続配色（Sequential palette）｜使う場面：ヒートマップや率の地図。｜注意：値の順序と見かけの明暗が対応するようにする。
- C-12 発散配色（Diverging palette）｜使う場面：平均との差や増減。｜注意：中心値の意味と範囲を明示する。
- C-13 コントラスト比（Contrast ratio）｜使う場面：文字の読みやすさを確認する。｜注意：AA基準は通常の文字で4.5:1、大きな文字（18pt以上、太字は14pt以上）で3:1。ロゴや装飾の文字は対象外。
- C-14 色覚多様性に配慮した配色（Colorblind-safe palette / CUD palette）｜使う場面：複数系列の図表。｜注意：特定のパレットだけで全ての識別性を保証できない。
- C-15 グラデーション（Gradient）｜使う場面：背景や連続値の表現。｜注意：装飾用の変化をデータ量と誤認させない。
- C-16 透明度（Opacity / Alpha）｜使う場面：重なりや控えめな要素。｜注意：背景との合成後にコントラストを確認する。
- C-17 OKLCH（OKLCH color space）｜使う場面：配色の系列を調整する。｜注意：同じLでもWCAGコントラストが等しいとは限らない。
- C-18 ダークモード（Dark mode）｜使う場面：閲覧環境や利用者の好みへの対応。｜注意：単純な色反転では図表の意味や階層が崩れる。
- C-19 RGB（RGB color model）｜使う場面：画面の色を指定する。｜注意：数値は色空間やプロファイルと合わせて解釈する。
- C-20 HEXカラー（Hexadecimal color notation）｜使う場面：色を正確なコードで渡す。｜注意：HEX自体は独立した色空間の名前ではない。
- C-21 HSL（HSL color model）｜使う場面：直感的に色みを調整する。｜注意：Lが同じでも知覚的な明るさが同じとは限らない。
- C-22 ティント・シェード（Tint / Shade）｜使う場面：配色の段階を整える。｜注意：デジタルでの混色は色空間にも依存する。
