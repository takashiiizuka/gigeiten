# 表現スタイル（データ版 2026.09.6）

用意する情報（分野共通）：用途、読者、ブランド、実際に使う内容や画像。スタイル名に加えて文字・色・余白を指定します。

- S-01 フラットデザイン（Flat design）｜使う場面：簡潔なUIや図解。｜注意：クリックできる場所の手がかりを失わない。
- S-02 スキューモーフィズム（Skeuomorphism）｜使う場面：なじみのある操作の比喩。｜注意：外見だけでは使い方が伝わるとは限らない。
- S-03 ミニマリズム（Minimalism）｜使う場面：内容に集中するページ。｜注意：必要な情報や操作の発見性まで削らない。
- S-04 グラスモーフィズム（Glassmorphism）〔ガラス、ガラスモーフィズム〕｜使う場面：重なったUIの層の表現。｜注意：背景が変わっても文字を読めるようにする。
- S-05 ニューモーフィズム（Neumorphism）｜使う場面：柔らかい立体感の実験。｜注意：低コントラストの境界や状態表示に注意する。
- S-06 ネオブルータリズム（Neobrutalism）〔ニューブルータリズム〕｜使う場面：強い個性を出すWeb表現。｜注意：可読性と操作の一貫性を優先する。
- S-07 ブルータリズム（Brutalism in web design）｜使う場面：構造を前面に出す表現。｜注意：使いにくさを必須の特徴と解釈しない。
- S-08 マテリアルデザイン（Material Design）｜使う場面：一貫したUIを作る。｜注意：単に影を付ける見た目の名前ではない。
- S-09 アイソメトリック（Isometric projection）｜使う場面：立体構成を一定の投影で見せる。｜注意：透視図と違い、遠くでも同じ尺度で描く。ゲームなどの「アイソメ」は2:1の近似が多い。
- S-10 デュオトーン（Duotone）｜使う場面：画像の色調を統一する。｜注意：重要な色の情報を失わない。
- S-11 スイススタイル（Swiss style / International Typographic Style）｜使う場面：秩序あるタイポグラフィの方向性。｜注意：Helveticaを使うことだけを意味しない。
- S-12 ラインアート（Line art）｜使う場面：図やアイコンの表情を統一する。｜注意：細い線が縮小で消えないよう確認する。
