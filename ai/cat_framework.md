# 分析・資料の枠組み（データ版 2026.09.6）

用意する情報（分野共通）：分析の目的、対象、評価軸、証拠となる情報。確認できた事実と仮説を区別して用意します。

- F-01 SWOT分析（SWOT analysis）〔スウォット、強み、弱み〕｜使う場面：戦略の前提を整理する。｜注意：四つの欄を埋めるだけで戦略が決まるわけではない。
- F-02 PESTLE分析（PESTLE analysis）〔PEST分析、PEST、外部環境分析〕｜使う場面：事業を取り巻く変化の把握。｜注意：事実・予測・自社への影響を区別する。
- F-03 ファイブフォース（Five forces）｜使う場面：業界構造と収益性の検討。｜注意：自社の五つの強みを挙げる図ではない。
- F-04 バリューチェーン（Value chain）｜使う場面：競争優位や改善箇所の検討。｜注意：企業内の活動を見る枠組み。企業間の調達・生産・配送の流れを扱うサプライチェーンとは区別する。
- F-05 BCGマトリクス（Growth–share matrix）〔PPM、プロダクトポートフォリオ〕｜使う場面：事業ポートフォリオの議論。｜注意：標準的な図は高シェアが左。軸と市場の定義を明示する。
- F-06 ビジネスモデルキャンバス（Business Model Canvas）｜使う場面：事業モデルの全体像。｜注意：各要素の整合性と未検証の仮説を確認する。
- F-07 バリュープロポジションキャンバス（Value Proposition Canvas）｜使う場面：顧客と提案価値の適合の検討。｜注意：顧客の悩みや利得を推測だけで確定しない。
- F-08 RICE（Reach × Impact × Confidence ÷ Effort）〔優先順位〕｜使う場面：施策を共通の前提で比較する。｜注意：数値化しても見積もりの不確実性は消えない。
- F-09 インパクト・工数マトリクス（Impact–effort matrix）｜使う場面：着手候補の比較。｜注意：効果や工数の尺度を候補間で揃える。
- F-10 重み付き意思決定表（Weighted decision matrix）｜使う場面：複数条件での選択。｜注意：点数の尺度と重みで結論が変わるため感度も確認する。
- F-11 狩野モデル（Kano model）｜使う場面：機能の価値を検討する。｜注意：分類は利用者や時間によって変化し得る。
- F-12 PDCA（Plan–Do–Check–Act）〔改善〕｜使う場面：改善の進め方を共有する。｜注意：実行しただけで改善できたと判断しない。
- F-13 なぜなぜ分析（Five whys）｜使う場面：原因仮説の検討。｜注意：必ず五回で真因に到達する規則ではない。証拠が必要。
- F-14 ダブルダイヤモンド（Double Diamond）｜使う場面：問題探索から解決案の検証までの説明。｜注意：実際の活動は一方向だけとは限らない。
- F-15 OKR（Objectives and Key Results）｜使う場面：組織の方向と成果の共有。｜注意：作業の列挙をそのまま成果指標にしない。
- F-16 RACI（Responsible / Accountable / Consulted / Informed）｜使う場面：関係者間の責任の明確化。｜注意：説明責任（A）は各作業に一人だけにする。肩書で自動的に割り当てず合意する。
- F-17 MoSCoW（Must / Should / Could / Won't this time）｜使う場面：スコープ調整。｜注意：Won'tは永久に不要という意味ではない。
- F-18 アクションタイトル（Action title / Message title）〔コンサル、資料、見出し、メッセージ〕｜使う場面：結論が追いやすい資料。｜注意：図表が実際に裏付ける範囲の主張にする。
- F-19 アサーション・エビデンス（Assertion–evidence approach）〔コンサル、提案、プレゼン、証拠〕｜使う場面：一枚ごとの論点を明確にする。｜注意：図があるだけでは証拠にならない。出典と条件が必要。
- F-20 コホート分析（Cohort analysis）｜使う場面：継続利用や定着の比較。｜注意：期間・分母・継続の定義を揃える。
- F-21 TAM（Total addressable market）｜使う場面：市場機会の大きさを検討する。｜注意：対象・期間・数量か金額かを定義する。
- F-22 SAM（Serviceable available market）｜使う場面：地域・提供範囲などを絞った機会。｜注意：TAMから恣意的な割合だけで算出しない。
- F-23 SOM（Serviceable obtainable market）｜使う場面：現実的な獲得可能性の検討。｜注意：期間と根拠を示す。確定した売上ではない。
- F-24 AARRR（Acquisition, Activation, Retention, Referral, Revenue）｜使う場面：サービスの成長の課題を探す。｜注意：必ずこの順に全利用者が進む単一の漏斗ではない。
- F-25 アイゼンハワーマトリクス（Eisenhower matrix）｜使う場面：時間や作業の優先順位。｜注意：重要と緊急の判断基準を明確にする。
- F-26 リーンキャンバス（Lean Canvas）｜使う場面：新規事業の検証計画。｜注意：ビジネスモデルキャンバスとは項目が異なる。
- F-27 ジョブ理論（Jobs to Be Done / JTBD）｜使う場面：顧客理解と価値の検討。｜注意：属性だけで需要を説明せず、状況も調べる。
- F-28 ステークホルダーマップ（Stakeholder map）｜使う場面：協働や合意形成の計画。｜注意：一つの決まった図形ではない。使用する軸を明記する。
- F-29 アンゾフの成長マトリクス（Ansoff matrix）｜使う場面：市場浸透・市場開拓・製品開発・多角化の議論。｜注意：分類だけで成功確率や投資判断は決まらない。
- F-30 マーケティングの4P（Marketing mix / Four Ps）｜使う場面：顧客へ提供する条件の整合。｜注意：売り手側から見た枠組み。顧客側から見る4Cや、サービス業向けの7Pで補う場合もある。
- F-31 MECE（Mutually exclusive, collectively exhaustive）｜使う場面：論点やカテゴリの分解。｜注意：対象範囲と分解軸が未定義なら、漏れがないか判定できない。
- F-32 エグゼクティブサマリー（Executive summary）〔サマリー、要約、概要、冒頭の要点〕｜使う場面：忙しい意思決定者に読んでもらう提案書・報告書の1ページ目。｜注意：本文にない内容を足さない。本文を書き終えてから、本文の順序に沿って書く。
